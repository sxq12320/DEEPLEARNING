# Archive

This directory contains retained legacy material that is not part of the active citrus workflow.

- `legacy_root_scripts/`: old standalone scripts superseded by code in active projects.
- `legacy_notebooks/`: exploratory notebooks retained for reference.
- `invalid_outputs/`: generated outputs known to use an incorrect or obsolete input source.

Do not use files here as formal experiment inputs or paper results. Verify their provenance before restoring anything.
