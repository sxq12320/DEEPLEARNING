# 服务器重新训练运行方法

这些脚本只读取服务器已有数据，不会修改 `/data/sxq/datasets/orange_yolo`。YOLO/COCO/semantic 等派生格式会写到 `/data/sxq/results/002_retrain/_prepared/citrus_prepared`，训练和测试结果写到 `/data/sxq/results/002_retrain/`。

## 1. 复制代码到服务器

把本地 `E:\mastercode\FWQ\code` 整个文件夹复制到服务器，例如：

```bash
/data/sxq/code
```

服务器数据保持原样：

```bash
/data/sxq/datasets/orange_yolo
```

## 2. YOLO 基线

进入 YOLO 环境，并安装本项目 Ultralytics：

```bash
cd /data/sxq/code/ultralytics-main-new
pip install -e .
```

运行全部 YOLO 基线：

```bash
cd /data/sxq/code/baseline_choice
python run_yolo_baselines.py
```

默认会训练并测试：

- YOLOv8n-Seg
- YOLO11n-Seg
- YOLO12n-Seg
- YOLO26n-Seg

结果位置：

```bash
/data/sxq/results/002_retrain/yolo
/data/sxq/results/002_retrain/evaluation
```

## 3. Torchvision Mask R-CNN

进入 Torchvision 环境后运行：

```bash
cd /data/sxq/code/baseline_choice
python run_maskrcnn.py
```

结果位置：

```bash
/data/sxq/results/002_retrain/torchvision_maskrcnn
```

## 4. U-Net + Watershed

进入 U-Net 环境后运行：

```bash
cd /data/sxq/code/baseline_choice
python run_unet.py
```

结果位置：

```bash
/data/sxq/results/002_retrain/unet_watershed
```

## 5. RTMDet-Ins / SOLOv2 / MMDetection Mask R-CNN

先确认 MMDetection 源码在：

```bash
/data/sxq/code/mmdetection
```

然后进入 MMDetection 环境运行：

```bash
cd /data/sxq/code/baseline_choice
python run_mmdet.py
```

如果你的 MMDetection 路径不是 `/data/sxq/code/mmdetection`，只改 `run_mmdet.py` 顶部的 `SERVER_MMDET_ROOT`。

## 6. RF-DETR Seg

进入 RF-DETR 环境后运行：

```bash
cd /data/sxq/code/baseline_choice
python run_rfdetr.py
```

## 7. 查看指标

每个脚本完成后会在控制台打印关键指标。更完整的结果看：

```bash
/data/sxq/results/002_retrain/evaluation/*/metrics.json
```

重点记录：

- `mask_ap_50_95`
- `mask_ap_50`
- `mask_ap_75`
- `mask_precision`
- `mask_recall`
- `params_m`
- `model_latency_ms_per_image`
- `peak_vram_mb`

正式论文表格只使用这次新数据重训后的 `002_retrain` 结果，不再混用之前的 `001_*` 结果。
