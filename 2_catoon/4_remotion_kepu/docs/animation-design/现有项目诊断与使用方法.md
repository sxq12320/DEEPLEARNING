# 现有项目诊断与使用方法

你的问题可以明显改善，但一句“去 AI 味、做得高级一点”无法让每个模型每期都设计得完美。更有效的办法，是把设计过程固定下来，把核心分镜留给每个选题重新设计。

## 这次看到了什么

检查范围：项目入口、公共视觉组件、201 / 215 / 239 等集的相关实现、已有的 201 / 239 / 244 帧图，以及文档库中保温杯、哈欠、自动驾驶等文案。属于抽查，不代表逐片审完全部视频。

| 观察 | 对观看的影响 | 建议 |
| --- | --- | --- |
| `KepuVideo.tsx` 的分节画面主要是大标题和关键词，辅以虚线环与粒子 | 旁白解释机制时，画面主要重复概念 | 把镜头围绕一次具体变化组织起来 |
| 较新的集数已有主题插画，但 239 的抽查帧同时包含两个框、底部框、贴片、标签、长字幕 | 每个区域都在解释，观众难以确定先看哪里 | 按口播顺序揭示信息，每个时刻只强调当前步骤 |
| 201 抽查帧把整句几十字口播放进字幕，字幕占据较大区域；244 的抽查帧主要信息集中在顶部，主体区域留白很大 | 观众忙于读字；关键动作缺少足够视觉权重 | 短句字幕、调整景别，给主角和关键接触点让出空间 |
| 公共 `Stamp` / `Chip` 采用类似弹性入场；部分场景频繁使用周期摆动 | 动作容易形成机械重复的视觉节奏 | 入场只是辅助手段，把时间用于接触、传递、变化和结果 |
| `make_episode.py` 先按文稿小节生成配音与句级时间；动画按小节组织 | 文章结构容易直接变成镜头结构，一段声音可能只对应一个长镜头 | 配音小节可以保留；镜头在小节内按解释动作细分 |
| 两个目录的集数编号对应不同主题 | 自动化很容易读错文案、音频或动画 | 核对标题和正文；输出用主题标识 |

具体例子：项目 `timeline_201.json` 是“含羞草为什么一碰就合”，文档库的 201 是“端到端开车像老司机”；项目 239 是“醒来为什么秒忘梦”，文档库的 239 是“机器人触觉皮肤”。这不是判断哪个库错了，而是说明编号不能当关联键。

这些证据支持我的设计判断：目前主要问题是文字负担、注意力安排和动作的解释价值。单纯换背景色、换模型、加纹理或增加特效，通常不足以解决这些问题。

## 建议采用的制作方式

每期只先定一个观众要看懂的核心问题，再让画面呈现其因果链。例如：

| 选题 | 关键画面应该做什么 |
| --- | --- |
| 保温杯 | 同一个杯子切到双层壁；看见真空间隙、辐射仍能跨越、表面处理减少换热，以及残留漏热路径 |
| 含羞草 | 接触位置明确；信号随后传递；叶片围绕支点响应；局部结构说明膨压变化。示意要保留机制边界 |
| 保温 / 保冷 | 保持结构相同，只改变内外冷热关系，让热流方向反转 |
| 视觉错觉 | 固定显示条件并提供前后或有无背景的对照；真实检验错觉是否成立 |
| AI 上下文 | 使用一段具体输入，展示超出可用范围的信息如何影响回答；注明流程只是解释性示意 |
| 机器人触觉皮肤 | 物体按压凝胶 → 凝胶形变 → 内部成像 → 解释接触信息；不要只画一个机械手和“触觉”标签 |

适合你长期复用的是字体、配色逻辑、轮廓与材质规则、字幕、标注、运动工具、音频时间表和检查流程。每期需要重新设计的是开场小事件、主角、因果动作、景别、对照方式与结尾回扣。

不必坚持全部素材都用代码画。简单剖面和精确箭头适合 SVG，复杂人物与场景适合分层插画或合法素材；需要空间关系时才考虑 3D。Remotion 可以组织这些内容，其官方动画方法要求根据帧驱动运动，并不规定只能制作文字卡片。[Remotion 官方动画文档](https://www.remotion.dev/docs/animating-properties)

## 每期如何使用

第一次，把 `01_科普动画Agent总提示词.md` 全文给 Agent，并填输入区。以后在同一个项目，让 Agent 读取该文件，再发送 `03_每期任务与审片提示词.md` 中的简短任务模板。项目已增加 `AGENTS.md`，引导支持该约定的 Agent 读取规范；其他 Agent 仍需在任务中明确指定文件。

先用一两个不同类别的选题验证这套方法，再根据真实成片调整规范。不要一开始就批量重写全部 51 个 Composition。你后续只需要选题和文案；Agent 应自动完成设计、实现、导出与检查，遇到关键缺失信息才询问。

“风格统一”不意味着每集同一背景、同一分栏、同一弹跳。统一的是视觉语言；讲原理的画面仍然由选题决定。

## 本次示范

`04_保温杯_动画示范.mp4` 使用你的文档库第 109 篇作内容起点，压缩为约 43 秒，1920×1080 / 30fps，带合成中文旁白与短句字幕。新 Composition 名为 `ThermosRedesign`，已加入现有项目。

这个示范展示六个解释阶段：日常问题、外壳揭示剖面、真空间隙、辐射传热、残留漏热、保冷方向。它提供一个简洁的机制演示方向，不是把整个文案库改成这六个相同镜头。

示范对原文做了必要的科学措辞调整：“三条路全部堵死”改为“减慢传热”，真空的作用限定为减少气体传导与对流，保留辐射与杯口漏热。没有使用“保冷一定比保温更强”“散热速度固定拖慢十倍”等缺少条件的量化断言。保温杯结构作用参考 [昆士兰大学物理博物馆](https://physicsmuseum.uq.edu.au/vacuum-flask) 与 [科罗拉多大学保温瓶对照实验](https://physicslabs.colorado.edu/demos/thermodynamics/heat-and-the-first-law/heat-transfer-applications/thermos-set/)。不同实物设计仍有差别，动画是非等比例示意。

可运行源码、素材、分镜和验证记录放在 `06_保温杯Remotion源码`。原项目的已有动画、文案和成片保留。验证的实际结果见源码包内 `verification.md`。
