# 保温杯示范分镜

核心解释：通过结构减慢内外传热，既能保温也能保冷。

源文案：文档库《109_保温杯的隔热魔法.md》。这是约43秒的机制节选，未保留整篇文章。

| 阶段 / 真实时间 | 解释动作 | 口播与字幕 | 示意边界 |
| --- | --- | --- | --- |
| 日常问题 / 0.00–5.50s | 杯盖从打开到盖紧，随后保留同一只杯子。标题与问题同屏。 | 没插电的保温杯；为什么能让热水慢点变凉？ | 蒸汽线仅是热水情境的视觉提示，不是传热测量。 |
| 揭示结构 / 5.50–11.40s | 外壳逐渐揭去，露出双层壁和内胆，标注指向实际位置。 | 它不制造热量；答案，藏在双层杯壁里 | 外壳透明化是剖面示意，非实物使用动作。 |
| 真空与辐射 / 11.40–19.73s | 放大双层壁的间隙，以制造时抽走空气解释真空；随后出现跨越间隙的辐射方向。 | 中间接近真空；减少气体传导和对流；可热辐射仍能穿过真空 | 粒子、壁厚和速度非等比例；真空减少气体传导和对流，并不隔断辐射。 |
| 低辐射率表面 / 19.73–25.50s | 强调面向间隙的金属表面，辐射箭头变少且减弱，仍保留一个方向。 | 低辐射率的金属表面；进一步减少辐射换热 | 箭头条数和透明度只表示定性减少，不能读成具体节能百分比。 |
| 残留漏热 / 25.50–34.00s | 回到整杯剖面，热流从内部沿杯口杯盖方向向外；落到减慢传热这一解释。 | 杯口和杯盖仍会漏热；所以，保温是减慢传热；不是让传热停止 | 箭头概括净热流，不是单一微观物体的实际轨迹，也未展示全部漏热途径。 |
| 保冷 / 34.00–43.23s | 结构保持相同，液体从暖色变为冷色，箭头从较暖外界反向进入。 | 装冷水也是同一原理；只是热量从外面向里面传；换个方向，一样保冷 | 这里只表示外界比杯内暖的条件；不声称保冷必定比保温强。 |
