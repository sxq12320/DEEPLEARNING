# 每期任务与审片提示词

## 每期发送给制作 Agent

以下模板配合总提示词使用，不需要每次重新讨论方法。

```text
请读取项目 AGENTS.md 和 docs/animation-design/科普动画Agent总提示词.md，
按其中的制作流程，把下面文案制作成一支科普动画并交付可播放成片。

项目：E:\mastercode\2_catoon\4_remotion_kepu
文案：C:\Users\33836\Desktop\others\doc\{{具体文件名}}
主题：{{填写}}
输出标识：{{主题拼音或英文slug，不直接沿用文档编号}}
比例：{{沿用项目16:9，或明确指定9:16}}
目标时长：{{例如60–90秒；没有偏好则按精简后的实际口播}}
视觉方向：{{默认沿用设计规范；需要时写具体特征}}
文案权限：保留原文，允许另存精简口播并修正明显错误，记录关键修正。
输出：独立的新Composition、MP4、可维护源码、分镜和简短验证记录。

先核对主题，不能只靠编号匹配文件。先确定解释动作，再写Remotion代码。
核心机制需要在真实对象的变化中呈现。不要把整段口播做成关键词弹跳课件。
必要中间文件写入项目后继续工作，不需要逐阶段请求确认。
请实际渲染并查看关键帧；具备连续播放与试听能力时也检查节奏、声音和同步。
任何无法进行的检查都如实列出，不要声称已经完成。
```

## 修改已有动画

```text
请读取本项目的动画设计规范，检查{{Composition名 / 源码路径}}。
先列出最多5个有具体帧号或源码证据的问题，再保存改进分镜并完成改造。
保留旧版本，输出新的Composition和视频。
重点：文字负担、关键动作是否真的解释机制、注意力顺序、手机可读性、
转场连续性与科学边界。改善分镜后再增加装饰。
类型检查通过之后还要导出并查看实际帧图。不要只做颜色和spring参数替换。
```

## 交给有视频查看能力的审片 Agent

这个提示词可由同一个 Agent 使用，也可单独交给另一个 Agent。没有要求自动创建额外 Agent。

```text
请检查提供的科普成片、最终口播和分镜。
不要根据作者的设计描述判断质量，也不要用“总体很高级”或自评分数代替证据。

先用一句话复述你从成片看懂的核心原理。
然后给出最多5个最值得修正的问题，优先级从高到低。
每条写：时间点、实际看到/听到的内容、对理解的影响、具体修改方法。

检查：
1. 事实或比喻有没有被画成错误机制；条件与不确定性是否丢失。
2. 画面有没有真的展示因果变化，而只在重复旁白。
3. 输入、传递、响应的时序和位置是否清楚。
4. 字幕是否遮挡、太长或抢走关键动作的注意力。
5. 镜头和节奏是否帮助理解；手机尺寸是否看清关键内容。

分别检查静音观看和只听旁白，但仅在工具确实支持时声称做过。
不能连续播放或试听时，明确说明哪些判断仅来自关键帧或源码。
最终列出必须修正的问题和可选的审美调整，不要求机械重写全部画面。
```

## 有问题时给制作 Agent 的反馈

```text
请保留已完成且有效的部分，只修正以下有证据的问题：{{贴审片反馈}}。
对于理解障碍，优先改动作、景别、时序或文案，别只加说明标签。
修改后实际渲染受影响片段，更新验证记录和最终MP4。
```
