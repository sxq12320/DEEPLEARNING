## L02 机构能不能动、怎么动？——自由度与机构组成原理

**知识点清单**
1. 机构具有确定运动的条件；最小阻力定律（p14-16）
2. 平面机构自由度公式的推导（p16）
3. 原动件数 = F 的判定：F≤0 不能动 / F>0 且原动件数=F 确定运动 / 原动件数<F 运动不确定 / >F 破坏
4. 计算自由度三大陷阱：复合铰链、局部自由度、虚约束（p18-21，虚约束六种典型情形）
5. 机构的组成原理：基本杆组（阿苏尔杆组）、Ⅱ级组/Ⅲ级组、机构的级别（p21-24）
6. 结构分析步骤：去虚约束/局部自由度 → 拆杆组
7. \*§2-8 型综合只做 1 分钟提及

**要推导的公式（动画，逐步推导）**
- **F = 3n − 2P_L − P_H**：从 n 个活动构件 3n 个自由度出发，低副扣 2、高副扣 1，逐项扣除的动画推导（p16）
- 杆组条件：3n − 2P_L = 0 → n=2,P_L=3 为Ⅱ级组（p22）

**要动画演示的机构（每个都现场算 F）**
- 铰链四杆机构 F=1（标准算例）
- 复合铰链陷阱：三构件共铰处 P_L=2 不是 1
- 局部自由度陷阱：凸轮滚子从动件（滚子自转不影响输出）
- 虚约束陷阱：平行四边形机构加中间平行杆（E 处虚约束）；机车车轮联动
- 反例：F=0 的桁架"假机构"、F=2 单原动件的乱动演示
- 大算例：教材典型复杂机构拆Ⅱ级杆组全过程

**校对清单锚点**：F 公式 (p16)；虚约束情形列表 (p19-20)；杆组定义 (p22)

## L10 机器中的暗力量——摩擦、效率与自锁

**知识点清单**
1. 力分析任务；构件惯性力的确定（质量代换概念）（p55-58）
2. 移动副摩擦：摩擦角 φ、总反力方向、斜面滑块正/反行程受力（p58-60）
3. 槽面摩擦与当量摩擦系数 f_v（p59）
4. 螺旋副摩擦：矩形螺纹 = 斜面缠绕、拧紧/放松力矩（p60-61）
5. 转动副摩擦：摩擦圆 ρ = f_v·r、总反力切于摩擦圆；轴颈摩擦力矩（p61-62）
6. 考虑摩擦的机构受力分析实例（p62-64）；不考虑摩擦的动态静力分析概要（p64-69）
7. 机械效率三种表达：功/功率/力比形式 η = P_r/P_d；**串联 η=∏η_i、并联效率**推导（p75-78）
8. **自锁**：定义、移动副 α≤φ、转动副力臂≤ρ、螺旋副 λ≤φ_v；η≤0 判据；自锁的利用（螺旋千斤顶、楔块）与避免（p78-82）

**要推导的公式（动画）**
- 摩擦角 φ = arctan f；总反力偏转方向"永远阻碍相对运动"（p58）

- 螺旋副拧紧力矩 M = G·d₂/2·tan(λ+φ_v)（把螺纹展开成斜面的动画）（p60-61）
- 摩擦圆半径 ρ = f_v r 推导（p61）
- 串联/并联总效率公式推导（功率流框图动画）（p76-77）
- 自锁条件三种形式的统一性：反行程 η' ≤ 0（p78-80）

**要动画演示的机构**
- 斜面上的滑块：α 从小到大，自锁 → 滑动的临界演示（φ 锥可视化）
- 螺旋千斤顶：为什么松手不会掉（λ<φ_v 自锁演示）

- 偏心夹具/楔块自锁的工程应用
- 多级传动链效率连乘的"功率漏斗"动画

**校对清单锚点**：斜面公式 (p59-60)；螺旋副力矩 (p60-61)；摩擦圆 (p61)；自锁判据 (p78-80)

## L11 让机器跑得稳——平衡与速度波动调节

**知识点清单**
1. 平衡的目的与分类：转子平衡 vs 机构平衡（p85-86）
2. **刚性转子静平衡**：条件 ∑F=0、单平面质径积矢量法计算（p86-87）
3. **刚性转子动平衡**：条件 ∑F=0 且 ∑M=0、任选两平衡基面分解、"动平衡包含静平衡"（p87-88）
4. 平衡实验：静平衡架、动平衡机原理；许用不平衡量概念（p88-92）；\*平面机构的平衡简介（p92-95）
5. 机械运转三阶段：起动/稳定运转/停车；作用在机械上的驱动力与阻力特性（p99-101）
6. **等效力学模型**：等效转动惯量 J_e、等效力矩 M_e 的推导（动能等效/功率等效）（p101-105）
7. 运动方程式求解概要（p105-109）
8. 周期性速度波动：平均角速度 ω_m、**不均匀系数 δ = (ω_max−ω_min)/ω_m**；**飞轮转动惯量 J_F = W_max/(δ·ω_m²)** 推导（盈亏功 W_max 的确定：能量指示图）（p109-114）
9. 非周期性波动与调速器概念（p114-115）；全课收尾：机械原理知识地图串讲 + 第 13/14 章展望

**要推导的公式（动画）**
- 静平衡方程 m_b r_b = −∑m_i r_i 矢量多边形解法（p86-87）
- 动平衡：任一不平衡质量分解到两基面的等效分解推导（p87-88）
- 等效转动惯量推导：∑½m_i v_i² + ½J_i ω_i² = ½J_e ω²（速比只与位置有关是前提）（p102-103）
- δ 定义与 ω_max² − ω_min² = 2W_max/J 的能量关系 → **J_F 公式完整推导**（p110-112）

**要动画演示的机构**
- 洗衣机脱水抖动 → 加平衡块后平稳（静不平衡直观案例）
- "静平衡但动不平衡"的经典演示：同轴两侧对称质量高速旋转的力偶摆动
- 动平衡机工作原理动画
