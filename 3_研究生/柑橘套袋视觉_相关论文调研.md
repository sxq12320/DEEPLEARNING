## 0. 一句话判断（先看）

1. **你的直觉有坚实文献支撑**：绿果藏绿叶 = **伪装目标检测（Camouflaged Object Detection, COD）**，而 COD 领域**大量用频域/边缘/纹理先验引导 RGB 主干**——方法母题就是你想的那套。
2. **但"先验引导双分支"本身是成熟范式**（边缘/纹理/频域/灰度引导的双分支到处都是）→ **不能单把它当创新点**。
3. **制胜框架** = 把**未熟柑橘显式建模为伪装目标** + 引入 COD 式**频域/纹理先验** + **面向套袋**（OBB/果梗/可套袋性）。三者交集目前**基本空白**，这才是你的缺口。
4. **必须对标的直接竞品**：Sapkota 2024（未熟绿果实例分割）、Polar-Net（绿果实例分割）。

## 6. 创新定位与建议

**你的想法在文献里的位置**：
- ✅ 方向对、有大量支撑（COD 频域 + 先验引导双分支 + 频域增强 YOLO）。
- ⚠️ "先验引导 RGB 主干"、"频域模块"、"灰度/边缘引导"**单拎出来都不新**——都有成熟工作。
- ✅ **空白在交集**：把**未熟柑橘当伪装目标**、用 **COD 式频域/纹理先验**、做**实例分割 + 面向套袋**（OBB/果梗/可套袋性）。这个交集目前几乎没人做。

**制胜叙事**（论文①）：
> *未熟柑橘与叶片同色同纹理，构成典型伪装场景；我们借鉴伪装目标检测的频域感知思想，以频域/纹理为先验引导 RGB 主干，在密集遮挡下实现高精度实例分割，并面向套袋输出朝向/可套袋性。*

**下一步精读顺序**（先读这 5 篇打底）：
1. Frequency Perception Network for COD（母题）
2. Sapkota 2024（直接竞品，看它没解决什么）
3. 灰度引导双分支（水下，2026）（看你想法的现成实现）
4. Multidimensional freq+spatial fusion for COD（融合设计）
5. WE-YOLO / FEMT-YOLO（YOLO+频域怎么落地）

**核实清单**：读完确认——① COD 频域方法是否已被用于**柑橘/绿果实例分割**？（若无=你的缺口坐实）② 灰度/频域先验引导在**农业果实**上有没有人做？
