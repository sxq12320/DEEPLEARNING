## 4. 数据驱动的真正难点

| 难度 | 数量 | 比例 | 方法要求 |

## 7. PR 曲线诊断

活动 fork 的 `compute_ap()` 明确把曲线尾部补成：

```python
mrec = np.concatenate(([0.0], recall, [recall[-1] if len(recall) else 1.0], [1.0]))
mpre = np.concatenate(([1.0], precision, [0.0], [0.0]))
```

因此图上 recall=1 后贴近 0 是 AP 积分的标准哨兵端点，不是“所有真实阈值的 precision 都等于 0”。真正需要解决的是：

1. `R` 仅约 0.69–0.74，微小/低对比目标没有进入候选集合；
2. 为追求极高 recall 而降低阈值时，叶片纹理和低质量候选大量进入，precision 快速下降；
3. B09 等质量加权提高了 precision，却进一步压低 recall，证明排序校准不能替代候选生成；
4. 单类曲线没有类别不平衡问题，但存在前景极稀疏、同色背景和邻果拓扑问题。

## 8. 损失/头部真实性审计

| 当前实现 | 实际做了什么 | 没有做什么 |
|---|---|---|
| VFL | 使用 TAL 的定位感知 `target_scores` | 不是 mask-IoU 质量目标 |
| NWD | 只在小框的 box regression 中混合 | 没有替换 TAL label assignment、NMS 或完整 RKA |
| boundary aux | 监督所有实例边界的 union | 不保存实例 ID，不能单独约束邻果分离 |
| query aux | 二值小目标中心热图 | 不是 pairwise repulsion/实例排他损失 |
| topology target | 含邻实例 separator 状态 | 与本课题最贴近，但必须看 split/merge 专项指标 |
| mask-quality head | 回归 mask IoU 并乘分类分数 | 可能改善排序，也可能过滤难例；当前无三种子证据 |
