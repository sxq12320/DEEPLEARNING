## 第一部分：机械基础重修课程计划（一个月）

### 1.1 重修目标

你在硕士阶段做的是科研（柑橘幼果实例分割、YOLO模型改进），但就业目标是制造业企业和自动化机器人公司。这意味着你需要重新掌握机械专业的**核心基础课**，才能在面试中回答技术问题，也能在入职后快速上手。

**重修目标**：
- 掌握机械设计的核心概念（齿轮、轴承、连杆、弹簧、紧固件等）
- 理解材料力学和机械原理的基本分析方法
- 熟悉机电一体化系统的组成和工作原理
- 了解机器人学基础（运动学、动力学、控制）
- 能够读懂机械图纸、进行简单的结构设计

**预期成果**：
- 能够独立完成一个简单的机械结构设计（如小型传动机构、夹具设计）
- 面试时能够回答"机械设计基础"相关的技术问题
- 理解工业机器人、自动化产线的基本机械结构

**Day 1：机械制图入门——国标与三视图**

- **学习目标**：能看懂一张普通零件图的所有符号；能用 SolidWorks 输出一个符合国标的工程图
- **上午（看）**：
  - GB/T 14689—2008 图幅：A0(841×1189) / A1 / A2 / A3(297×420) / A4(210×297)；留装订边 25mm，其余 10mm；标题栏右下角
  - 比例（GB/T 14690）：原值 1:1；缩小 1:2、1:5、1:10；放大 2:1、5:1
  - 字体（GB/T 14691）：汉字长仿宋体，高宽比 √2 ≈ 1.414；数字用斜体 15°
  - 图线（GB/T 4457.4）：粗实线 0.7mm、细实线 0.35mm、虚线、点画线、双点画线、波浪线
  - 三视图投影规律：**长对正、高平齐、宽相等**
  - 剖视图：全剖（表达内部空腔）、半剖（对称零件，一半外形一半内形）、局部剖（局部内部）
  - 表面粗糙度（GB/T 131）：Ra 值——粗加工 Ra 50/25/12.5；半精加工 Ra 6.3/3.2/1.6；精加工 Ra 0.8/0.4/0.2；超精加工 Ra 0.1/0.05
- **下午（练）**：
  - SolidWorks：新建零件 → 草图（L 键直线、圆）→ 标注尺寸 → 拉伸凸台 → 倒角 → 异型孔向导
  - 任务：画一根 φ20×80 的光轴，一端倒角 C2，中间一个 φ8 通孔
  - 生成工程图：文件→从零件制作工程图→选 A4 横向→投三视图→标注尺寸→插入粗糙度符号
- **晚上（复习+口述）**：
  - 口述：什么是"长对正、高平齐、宽相等"？
  - 口述：Ra3.2 和 Ra0.8 哪个更光滑？分别对应什么加工？
  - 口述：A3 图纸尺寸多少？留装订边多少？
- **教材页码**：《机械设计》P1–P10 绪论章；《互换性与测量技术》第1章

**Day 2：公差与配合——基孔制/基轴制与 GD&T**

- **学习目标**：看懂 H7/g6 这类配合代号；能算出最大/最小间隙与过盈
- **上午（看）**：
  - 公差带：上偏差 ES / 下偏差 EI（孔大写）；es / ei（轴小写）
  - 标准公差 IT 等级 IT01–IT18，共 20 级；IT5 配合常用，IT7 一般机械
  - 配合制度：
    - **基孔制**（H）：孔的基本偏差固定为 H（下偏差 = 0），靠改变轴的偏差得到间隙/过渡/过盈
    - **基轴制**（h）：轴的基本偏差固定为 h（上偏差 = 0）
  - 三类配合：
    - 间隙配合：H7/g6（滑动）、H7/f6（转动）、H7/d6（松）
    - 过渡配合：H7/k6（一般定位）、H7/m6（较紧）
    - 过盈配合：H7/p6（轻压）、H7/s6（重压、需热装）
  - 形位公差（GD&T）：直线度—、平面度▱、圆度○、圆柱度⛹、平行度∥、垂直度⊥、同轴度◎、位置度⌖、跳动↗
- **下午（练）**：
  - 算题：φ25 H7/g6，查表 H7 = 25⁺⁰·⁰²¹，g6 = 25₋₀·₀₂₀⁻⁰·₀₀₇
    - 最大间隙 = 0.021 − (−0.007) = 0.028 mm
    - 最小间隙 = 0 − (−0.020) = 0.020 mm
  - SolidWorks 工程图：给轴和孔加尺寸公差（选"套合"→H7/g6）
  - 加一个形位公差：轴的圆柱度 0.005
- **晚上（口述）**：
  - 基孔制和基轴制各适用于什么场合？（答：基孔制——孔用定值刀具如铰刀，大批量；基轴制——用冷拔轴不再加工，或同一轴上多种配合）
  - H7/g6 是什么配合？最大间隙多少？
  - 什么时候用过渡配合？
- **教材页码**：《互换性与测量技术》第2、3章

**Day 3：机械设计准则与失效形式**

- **学习目标**：建立"设计=满足准则的反失效过程"的思维框架
- **上午（看）**：
  - 设计基本准则：**强度、刚度、寿命、可靠性、工艺性、经济性**
  - 失效形式（每种零件都对应几种）：
    - 断裂：静载断裂、疲劳断裂（最常见，占 80%）
    - 变形：弹性变形过量、塑性变形
    - 表面失效：磨损（磨粒/粘着/疲劳/腐蚀）、胶合、点蚀、腐蚀
    - 破坏正常工作条件：打滑（带传动）、共振、泄漏
  - 强度条件通式：**σ ≤ [σ] = σ_lim / S**
    - σ_lim 对塑性材料 = 屈服强度 σ_s；对脆性材料 = 抗拉强度 σ_b
    - S 为安全系数，一般 S = 1.2–1.5（塑性）、S = 2–3（脆性）
  - 疲劳破坏曲线（S-N）：应力循环次数 N > 10⁶–10⁷ 后进入水平段，对应疲劳极限 σ_(-1)
  - 设计流程：需求 → 方案 → 运动学 → 动力学 → 结构 → 校核 → 优化 → 出图
- **下午（练）**：
  - 分析扳手：失效形式 = 力作用处弯曲疲劳 + 开口磨损；材料选 40Cr 调质
  - 分析钢丝钳：铰链孔磨损 + 刃口崩刃；材料 T8 淬火
  - SolidWorks 设计一个 M8 螺栓的简化模型（六角头 + 螺杆 + 螺纹），用螺纹特征
- **晚上（口述）**：
  - 机械设计的基本准则有哪些？
  - 疲劳破坏有什么特点？（答：应力低于 σ_s，无塑性变形征兆，断口分光滑区+粗糙区）
  - 塑性材料和脆性材料的极限应力分别取什么？
- **教材页码**：《机械设计》第2章 失效与准则

**Day 4：螺纹连接设计**

- **学习目标**：能算螺栓预紧力、能选防松方式、能设计螺栓组
- **上午（看）**：
  - 螺纹分类：普通螺纹 M（牙型角 60°）、管螺纹 G/R（55°）、梯形螺纹 Tr（30°，传动用）、矩形螺纹（效率最高但难加工）
  - 螺栓受力：
    - **预紧力 F'**：拧紧时产生，F' = T / (0.2·d) （T 为拧紧力矩，d 为螺纹公称直径）
    - 剩余预紧力 F'' = F' − (1−K)·F，K 为刚度系数（金属垫 K≈0.2–0.3）
    - 总拉力 F0 = F' + K·F（F 为工作载荷）
  - 防松方法：
    - 摩擦防松：弹簧垫圈、双螺母、自锁螺母
    - 机械防松：开口销、止动垫片、串联钢丝
    - 永久防松：点焊、冲边、粘接
  - 螺栓组设计：对称布置；受力最大螺栓先算；对受倾覆力矩的法兰，最外排螺栓受力最大
  - 强度校核：σ = 1.3·F0/A_s ≤ [σ]，1.3 是考虑扭转剪应力的系数
- **下午（练）**：
  - 算题：液压缸盖用 6 个 M12 螺栓，缸内压 p=2 MPa，缸径 D=100mm，求每个螺栓工作载荷 F 和总拉力 F0
    - 工作载荷 F = p·π·D²/4 / 6 = 2×π×100²/4/6 ≈ 2618 N
    - 剩余预紧 F'' = 1.5·F = 3927 N（压力容器密封要求）
    - 总拉力 F0 = F + F'' = 6545 N
  - SolidWorks 装配体：画两个法兰盘 + 6 个螺栓 + 垫圈 + 螺母，做同心配合
- **晚上（口述）**：
  - 螺栓的总拉力 = 预紧力 + 工作载荷，对吗？（答：不完全对，是 F0 = F' + K·F）
  - 防松分哪几类？为什么压力容器要求残余预紧力大？
  - 受倾覆力矩的螺栓组，哪个螺栓受力最大？
- **教材页码**：《机械设计》第5章 螺纹连接，P70–P95

**Day 5：轴系设计**

- **学习目标**：能设计一根阶梯轴，完成弯扭合成强度校核
- **上午（看）**：
  - 轴的分类：心轴（只受弯，不传扭，如自行车前轴）、转轴（既受弯又受扭，最常见）、传动轴（只受扭，如汽车传动轴）
  - 材料：45 钢正火（一般）、40Cr 调质（重要）、20Cr 渗碳（受冲击）、38CrMoAlA 氮化（高精度）
  - 轴的结构设计原则：
    - 零件装拆方便 → 阶梯轴
    - 轴向固定：轴肩+轴环、套筒、圆螺母、弹性挡圈、紧定螺钉
    - 周向固定：键、花键、销、过盈
    - 工艺结构：退刀槽（宽 b≈3p，p 螺距）、砂轮越程槽、倒角 C
  - **弯扭合成强度校核**（第三强度理论）：
    - σ_ca = √(M² + (αT)²) / W ≤ [σ_(-1)]
    - W = πd³/32（圆轴抗弯截面系数）
    - α 是扭矩折算系数：扭矩平稳 α=0.3，脉动 α=0.6，对称循环 α=1.0
    - [σ_(-1)] 对 45 钢调质 ≈ 60 MPa
  - 疲劳校核（精确校核）：安全系数 S = S_σ·S_τ / √(S_σ² + S_τ²) ≥ [S] = 1.5
- **下午（练）**：
  - 算题：转轴危险截面受弯矩 M=200 N·m，扭矩 T=150 N·m，扭矩脉动（α=0.6），材料 45 钢调质 [σ_(-1)]=60MPa，求最小轴径
    - 当量弯矩 M_e = √(200² + (0.6×150)²) = √(40000 + 8100) ≈ 219.5 N·m
    - d ≥ ∛(32·M_e / (π·[σ])) = ∛(32×219500 / (π×60×10⁶)) = ∛(0.0000372) ≈ 0.0334 m = 33.4 mm
    - 圆整取 d=35mm
  - SolidWorks 画阶梯轴：φ35×120，两端 φ25 轴承位，中间 φ35 齿轮位，轴肩 φ40
- **晚上（口述）**：
  - 心轴、转轴、传动轴的区别？
  - 轴上零件的轴向和周向固定各有哪些方法？
  - α 折算系数为什么对对称循环取 1.0？（答：弯曲是静载或脉动，扭转常对称循环）
- **教材页码**：《机械设计》第10章 轴，P210–P235

**Day 6：滚动轴承与润滑**

- **学习目标**：能选轴承型号、算寿命、选润滑方式
- **上午（看）**：
  - 类型代号：6=深沟球轴承（最常用，能受径向+小轴向）、7=角接触球轴承（受径向+单向大轴向）、3=圆锥滚子轴承（径向+轴向，可分离）、5=推力球轴承（只受轴向）、N=圆柱滚子轴承（只受径向，高刚性）
  - 后缀含义：C3 游隙大、RS 一面接触橡胶密封、2RS 双面、ZZ 防尘盖
  - 尺寸系列：如 6208，6 是类型，2 是尺寸系列（宽度0+直径2），08 是内径代号 = 08×5 = 40mm
  - **寿命计算**（L10 寿命，可靠度 90%）：
    - L10 = (C/P)^ε（百万转），球轴承 ε=3，滚子轴承 ε=10/3
    - C 为基本额定动载荷（样本查），P 为当量动载荷
    - P = X·Fr + Y·Fa（X 径向系数，Y 轴向系数，查表）
  - 寿命小时数：Lh = 10⁶·L10 / (60·n)
  - 润滑：
    - 脂润滑：d·n < 2×10⁵（d 轴承内径 mm，n 转速 rpm）
    - 油润滑：d·n > 2×10⁵ 用油浴、飞溅、喷油、油雾
    - 润滑脂选 NLGI 稠度号：2 号最常用
  - 密封：毡圈（低速）、橡胶油封（高速）、迷宫密封（高速高温）
- **下午（练）**：
  - 算题：深沟球轴承 6208（C=22800N），纯径向载荷 Fr=2500N，转速 n=1450rpm，求 L10 寿命和小时寿命
    - P = Fr = 2500N
    - L10 = (22800/2500)^3 = 9.12^3 ≈ 759 百万转
    - Lh = 10⁶×759 / (60×1450) ≈ 8725 h
  - SolidWorks 调标准件库：插入 6208 轴承 + 轴承座
- **晚上（口述）**：
  - 深沟球轴承和角接触球轴承的区别？
  - 轴承 6208 的内径多少？（答：40mm）
  - L10 寿命什么意思？（答：10% 失效概率，90% 可靠度下的寿命）
  - 怎么判断用脂润滑还是油润滑？
- **教材页码**：《机械设计》第11章 滚动轴承，P240–P275

**Day 8：平面机构结构分析**

- **学习目标**：会算任意平面机构的自由度，识别虚约束/局部自由度/复合铰链
- **上午（看）**：
  - 构件 = 运动单元，零件 = 制造单元；一个构件可含多个零件
  - 运动副：
    - 低副（面接触）：转动副（铰链）、移动副（滑块）；约束数 = 1，自由度贡献 = 1
    - 高副（点/线接触）：齿轮副、凸轮副；约束数 = 2，自由度贡献 = 2
  - **自由度公式**：F = 3n − 2P_l − P_h
    - n = 活动构件数（不含机架）
    - P_l = 低副数，P_h = 高副数
  - 三种特殊情况：
    - **复合铰链**：k 个构件汇交一处，转动副数 = k−1
    - **局部自由度**：滚子绕自身轴的转动，不影响整体运动，算 F 时减 1
    - **虚约束**：不起实际约束作用的重复约束，算 F 时不计入（如多支点支撑轴、对称结构）
- **下午（练）**：
  - 算题 1：铰链四杆机构，4 个构件（1机架+3活动），4 个转动副
    - F = 3×3 − 2×4 − 0 = 1（一个原动件即可确定运动）
  - 算题 2：凸轮机构带滚子，凸轮+滚子+推杆+机架 = 3 活动构件，1 高副（凸轮-滚子），1 转动副（滚子-推杆），1 移动副（推杆-机架），1 转动副（凸轮-机架）
    - 原始 F = 3×3 − 2×3 − 1 = 2
    - 减去局部自由度 → F = 1
  - SolidWorks Motion：建一个曲柄滑块机构，做运动仿真
- **晚上（口述）**：
  - 自由度公式？复合铰链的转动副数怎么算？

**Day 12：材料力学基础——拉压/扭转/弯曲**

- **学习目标**：掌握四种基本变形的应力应变公式，会算弯扭组合
- **上午（看）**：
  - **拉压**：σ = N/A；ε = ΔL/L；胡克定律 σ = E·ε，E 钢材 ≈ 200 GPa
  - **剪切**：τ = Q/A（名义剪应力，铆钉、销钉）；挤压 σ_bs = F/(d·t)
  - **扭转**（圆轴）：
    - 扭矩 T 与功率、转速关系 T = 9550·P/n (N·m)
    - 剪应力 τ_ρ = T·ρ/I_p，最大在表面 τ_max = T/W_p
    - 极惯性矩 I_p = πd⁴/32，抗扭截面系数 W_p = πd³/16
  - **弯曲**（梁）：
    - 正应力 σ = M·y/I_z，最大在上下表面 σ_max = M/W
    - 抗弯截面系数 W = I_z/y_max；矩形 W = bh²/6，圆形 W = πd³/32
    - 剪应力 τ = Q·S_z*/(I_z·b)，矩形最大 τ_max = 1.5·Q/A
  - **强度理论**：
    - 第一（最大拉应力）：σ1 ≤ [σ]，脆性材料
    - 第三（最大剪应力）：σ1−σ3 ≤ [σ]，塑性材料
    - 第四（形状改变比能）：√(0.5[(σ1−σ2)²+(σ2−σ3)²+(σ3−σ1)²]) ≤ [σ]，塑性更精确
  - **弯扭组合**（第三理论）：σ_e = √(σ² + 4τ²) = √((M/W)² + 4(T/W_p)²)
- **下午（练）**：
  - 算题：传动轴 M=300 N·m，T=200 N·m，d=40mm，材料[σ]=80MPa
    - σ = M/W = 300×10³ / (π×40³/32) = 47.7 MPa
    - τ = T/W_p = 200×10³ / (π×40³/16) = 15.9 MPa
    - σ_e = √(47.7² + 4×15.9²) = √(2275 + 1011) = 57.3 MPa ≤ 80 ✓
- **晚上（口述）**：
  - 四种基本变形的应力公式？
  - 第三和第四强度理论分别适用于什么材料？
  - 弯扭组合的当量应力公式？

**Day 18：控制系统基础**

**Day 19：机器人学基础——运动学**

- **学习目标**：会用 DH 参数法求机械臂正运动学
- **上午（看）**：
  - 机器人组成：机械臂、控制器、示教器、末端执行器；6 轴工业机器人最常见（6 个旋转关节）
  - 关节类型：旋转 R（绕轴转）、移动 P（沿轴伸缩）
  - 自由度 = 独立运动数；6 轴机器人在 3D 空间 6 自由度刚好够位姿
  - 位姿 = 位置(x,y,z) + 姿态(R,P,Y) = 6 维
  - 齐次变换矩阵 T（4×4）：
    ```
    T = [ R  p ]
        [ 0  1 ]
    ```
    R 是 3×3 旋转矩阵，p 是 3×1 平移
  - 旋转矩阵：绕 X 旋转 θ → Rx(θ)，绕 Y → Ry，绕 Z → Rz；矩阵乘法顺序与旋转顺序有关
  - **DH 参数法**（4 参数描述两连杆关系）：
    - a 连杆长度、α 连杆扭角、d 两连杆距离、θ 关节角
    - 标准 DH：A_i = Rot_z(θ_i)·Trans_z(d_i)·Trans_x(a_i)·Rot_x(α_i)
    - 改进 DH（MDH）：坐标系固结在前一杆，更适合闭环
  - 正运动学：T_0n = A_1·A_2·...·A_n
- **下午（练）**：
  - 算 2 自由度平面机械臂：l1=100,l2=80，θ1=30°,θ2=45°
    - x = l1·cos(θ1) + l2·cos(θ1+θ2) = 100·0.866 + 80·cos(75°) = 86.6 + 20.7 = 107.3
    - y = l1·sin(θ1) + l2·sin(θ1+θ2) = 50 + 77.3 = 127.3
  - Python（numpy）写通用 DH 正运动学函数，画 3D 末端轨迹
- **晚上（口述）**：
  - DH 参数 4 个量分别是什么？
  - 正运动学和逆运动学的区别？
  - 6 轴机器人为什么有 6 个自由度？

**Day 20：机器人学——逆运动学与动力学**

- **学习目标**：理解逆运动学难点，了解动力学和轨迹规划
- **上午（看）**：
  - 逆运动学：已知末端位姿 T，求各关节角
    - 解析解：特殊结构（如相邻 3 轴交一点——球形腕）可解析；6 轴标准臂多可解析
    - 数值解：雅可比迭代法，通用但慢、可能多解/无解
  - 雅可比矩阵 J：J = ∂T/∂q，把关节速度映射到末端速度 v = J·q̇
    - 奇异点：det(J)=0 处失去某方向运动能力，肘伸直/腕对齐是典型奇异
  - 动力学：
    - 牛顿-欧拉法：前向递推速度加速度，后向递推力/力矩，适合数值
    - 拉格朗日法：列能量方程，得 D(q)·q̈ + C(q,q̇)·q̇ + G(q) = τ
  - 轨迹规划：
    - 点到点：梯形速度曲线（加速-匀速-减速）
    - 连续轨迹：用样条插值保证位置+速度+加速度连续
    - 空间轨迹：直线、圆弧、B 样条
- **下午（练）**：
  - 2 自由度平面臂逆运动学：l1=100,l2=80，目标(x=120,y=80)
    - cos(θ2) = (x²+y²−l1²−l2²)/(2·l1·l2) = (14400+6400−10000−6400)/(16000) = 4400/16000 = 0.275
    - θ2 = ±acos(0.275) ≈ ±74°（肘上肘下两解）
  - 下载一个开源机器人仿真器（如 PyBullet）跑一个 UR5 模型，画末端轨迹
- **晚上（口述）**：
  - 什么是雅可比矩阵？什么是奇异点？
  - 牛顿-欧拉法和拉格朗日法各有什么特点？
  - 轨迹规划的梯形速度曲线是什么？

**Day 23：有限元分析（ANSYS Workbench）基础**

- **学习目标**：完成一个静力学分析，会看应力云图判断安全
- **上午（学）**：
  - FEA 三步：前处理（几何→材料→网格→约束载荷）→求解→后处理
  - 单元类型：四面体（默认）、六面体（精度高，规则几何）、壳单元（薄板）、梁单元（细长）
  - 网格：疏密过渡，应力集中处加密；收敛性测试（加密一倍应力变化 <5% 即收敛）
  - 材料属性：E（弹性模量）、ν（泊松比，钢 0.3）、ρ（密度）、σ_s
  - 约束：固定、圆柱支撑、远程位移、无摩擦支撑
  - 载荷：力、压力、力矩、重力加速度、温度
  - 结果：等效应力（von Mises，按第四理论）、总变形、安全系数 = σ_s / σ_max
- **下午（练）**：
  - 悬臂梁分析：长 200×宽 20×高 30 的 45 钢梁，一端固定，另一端受 1000N 集中力
    - 网格 2mm
    - 求解后看 σ_max ≈ 6·F·L/(b·h²) = 6×1000×200/(20×900) = 66.7 MPa
    - 安全系数 = 355/66.7 ≈ 5.3
  - 用 SolidWorks Simulation 也可（界面更友好）
- **晚上（口述）**：FEA 三步？von Mises 应力按第几强度理论？网格加密的意义？

**Day 25：液压与气动系统**

- **学习目标**：读懂气路图/油路图，能选气缸型号
- **上午（看）**：
  - 液压系统：泵（齿轮/叶片/柱塞，压力 7–32MPa）→阀（溢流、换向、节流）→缸/马达→油箱
  - 气动系统：空压机→气源处理件（过滤+减压+油雾，AW/FRL 三联件）→电磁阀→气缸
  - 方向阀"位数-通数"：如 5/2 阀 = 5 位 2 通（实为 5 口 2 位，气动常用）
  - 基本回路：
    - 换向：换向阀控制气缸前进后退
    - 调速：单向节流阀控制伸出速度（排气节流比进气节流稳）
    - 增压：增压缸 1:2 等比增压
    - 同步：两缸用同步马达或机械同步
  - 气缸选型：理论推力 F = π/4·D²·P，D 缸径，P 工作压力
    - 缸径 40 气缸 0.5MPa → 推力 = 0.785×40²×0.5 = 628N，留 50% 余量 → 选 50 缸径

#### 核心原则

1. **每天至少 5 小时**：上午理论 + 下午实操 + 晚上复习，缺一不可
2. **笔记要用自己的话写**：抄书不如用自己的话重新表述一遍，这能检验你是否真正理解了
3. **每个知识点配一个实践**：机械是工科，光看不练等于没学
4. **口述是最好的复习**：想象对面坐着一个面试官，你能不能 3 分钟讲清楚一个概念？
5. **建立错题本**：算错的题、口述卡壳的地方，记录下来反复看
6. **用思维导图串联**：每周画一张大图，把本周知识点串成一条线

#### 面试答题模板（STAR 法）

面试中问到项目时，用 STAR 法组织语言：

- **S**ituation（情境）：背景是什么？
- **T**ask（任务）：你要解决什么问题？
- **A**ction（行动）：你做了什么？用了什么方法？
- **R**esult（结果）：结果如何？量化指标？

示例：
> "我的柑橘幼果分割项目（S），需要在<5M参数下提升mask mAP（T），我设计了低光照增强前端HVIEnhance和多极注意力模块C2MANO（A），mask mAP50-95从0.642提升到0.678（R）。"

#### 1.5 重修阶段常见易错点与陷阱速查（事无巨细版）

> 这一节是 30 天学习过程中**最容易记错、算错、口述卡壳**的地方，按主题归类。每次复习时扫一遍，能避免"看的时候都懂、一做题就错"的窘境。

##### A. 机械制图与公差

1. **A0 图纸尺寸记反**：A0 = 841×1189，**不是** 1189×841（长边 1189 在前是错的，国标写法是"宽×长"=841×1189）。A 系列每档对折：A1=594×841，A2=420×594，A3=297×420，A4=210×297。记忆口诀："**A4 是 A3 的一半，长边对折成短边**"。
2. **装订边方向**：留装订边 25mm 在**左边**（X 方向起始），其余三边 10mm。**横向图纸（landscape）时装订边在短边**——很多人画横向图时把装订边放错位置。
3. **Ra 值大小方向**：Ra 越小越光滑。常错在"以为 Ra 大=精加工"。记忆：**Ra = 轮廓算术平均偏差，凸凹越多数值越大，越粗糙**。Ra0.8 是精车/精铣，Ra0.4 是磨削，Ra0.025 是研磨/超精加工。
4. **H7/g6 配合性质判断**：基孔制 H（孔 EI=0），轴 g 的 es 为负 → 轴永远比孔小 → **间隙配合**。判断口诀：**看轴的基本偏差代号**——a~h 间隙（h 是零间隙临界）、j~n 过渡、p~zc 过盈。常错在把 H7/k6 当间隙配合（其实是过渡）。
5. **形位公差基准**：位置度、同轴度、跳动**必须有基准**（A/B/C 基准字母）；形状公差（直线度、平面度、圆度、圆柱度）**无基准**。面试常问"圆度和圆柱度的区别"——圆度是**单一截面**的圆，圆柱度是**整个圆柱面**的形状误差。
6. **配合公差带图**画法：零线以上是孔（ES/EI 正），零线以下是轴（es/ei 负）。**孔公差带在轴之上=间隙，重叠=过渡，孔在轴之下=过盈**。

##### B. 螺纹连接（最容易出计算题的章节）

1. **总拉力公式 F0 = F' + K·F，不是 F0 = F' + F**。这是面试**最高频错点**。原因：螺栓和被连接件是**弹性系统**，加载后螺栓伸长 Δ、被连接件回弹 Δ，二者耦合导致螺栓只承受工作载荷的一部分（K·F），而不是全部。K=螺栓刚度/(螺栓刚度+被连接件刚度)，金属件 K≈0.2~0.3。
   - 推论：**刚度越大（如重型法兰），K 越小，螺栓受力越小**——这也是为什么重载连接预紧后螺栓总拉力增加不多。
2. **残余预紧力 F'' = F0 − F = F' − (1−K)·F**。压力容器要求 F'' ≥ (1.5~1.8)·F 防漏，所以预紧力要大。
3. **1.3 系数的来源**：拧紧时扳手力矩 = 螺纹摩擦力矩 + 螺母支承面摩擦力矩 + **螺纹斜面提升阻力**。校核拉伸强度时 σ = 1.3·F0/A_s，1.3 是把**扭转剪应力**折算到拉伸的系数（按第四强度理论 √(σ²+4τ²)≈1.3σ）。**面试追问**："为什么不直接算 τ？"——答：工程上为简化，把扭转折算进拉伸用一个综合系数，避免分别校核。
4. **螺栓个数与受力分布**：受倾覆力矩 M 的法兰，螺栓受力按线性分布，**最外排距中性轴最远的螺栓受力最大** F_max = M·r_max / Σr_i²。常错在"平均分配"。
5. **预紧力控制方法**：扭力扳手（受摩擦影响大，误差 ±20%）、**转角法**（拧紧到贴合后再转一定角度，误差小）、**液压拉伸器**（最准，直接拉螺栓，大法兰用）、螺栓伸长量测量（最精确）。

##### C. 轴系与轴承

1. **轴径估算初值公式**：d_min = A₀·∛(P/n)，A₀ 是材料系数（45 钢调质 A₀≈112，40Cr A₀≈103）。这是**初步估算**，不是最终校核。常错在直接用估算值定轴径而不做弯扭合成校核。
2. **弯扭合成中 α 的取值**：
   - α 是把**扭转应力**折算成**弯曲对称循环应力**的系数。
   - 扭矩平稳（如电机直连）→ τ 是静应力 → α=0.3（折算后变小，因为静应力危害小于对称循环）。
   - 扭矩脉动（如单方向带载）→ τ 是脉动循环 → α=0.6。
   - 扭矩对称（正反转）→ τ 是对称循环 → α=1.0。
   - **常错**：α 取反了，把平稳工况取 1.0。判断口诀："**扭转越接近对称循环，α 越接近 1**"。
3. **轴承内径代号**：6208 → 08×5=40mm。**00=10mm，01=12mm，02=15mm，03=17mm，04 及以上=代号×5**。常错在把 6204 当成 204mm 内径（实际 20mm）。
4. **L10 寿命的"10%"**：L10 表示**10% 失效概率**，即 90% 可靠度下的寿命。不是"寿命是 10"。常追问"L10 和基本额定寿命什么关系"——答：基本额定寿命 L10 就是 90% 可靠度下的寿命，是轴承样本的标准指标。
5. **当量动载荷 P 的判断**：纯径向 Fr 时 P=Fr（深沟球）；有轴向 Fa 时查 e 值（Fa/Fr 与 e 比较）决定 X、Y。**角接触球轴承必须成对使用**——单只只能受单向轴向，常错在单只设计。

##### D. 齿轮与轮系

1. **模数标准化原因**：模数 m=p/π，齿轮加工刀具按模数系列标准化（滚刀、插齿刀），**不同模数要不同刀具**，所以标准化才能互换和降低成本。面试常问"为什么不是齿距标准化"——答：齿距 p=πm 含无理数 π，加工测量不方便，用 m 取代后 m 是有理数。
2. **行星轮系转化机构法步骤**（务必按顺序）：
   - 给整个系统加 −ω_H（行星架角速度），**行星架变成静止机架**。
   - 列转化机构中太阳轮和齿圈的传动比 i_13^H = (ω1−ω_H)/(ω3−ω_H) = ±z3/z1（外啮合负、内啮合正）。
   - 代入已知转速求解未知转速。
   - **常错**：忘了给整个系统加 −ω_H，直接用 i_13 = z3/z1（这是错的，因为原系统行星架在动）。
3. **复合轮系拆分原则**：先找**行星架**，与行星架固连的轮系是周转轮系部分；不经过行星架的是定轴轮系部分。**分别列方程再联立**。
4. **蜗杆自锁条件**：导程角 γ < 当量摩擦角 ρ_v。**自锁的蜗杆只能由蜗杆带动蜗轮，不能反向**。常追问："为什么起重机能用蜗杆防止重物下落？"——答：自锁蜗杆断电后无法被蜗轮反驱，重物不会下落。
5. **齿轮失效形式与传动类型对应**：闭式（润滑好）→ **齿面点蚀**为主；开式（有杂质）→ **齿面磨损**为主；高速重载 → 胶合；低速重载 → 塑性变形。面试必考对应关系。

##### E. 材料力学

1. **第三、第四强度理论适用**：
   - 第一（最大拉应力）：脆性材料（铸铁、陶瓷）。
   - 第二（最大拉应变）：少用。
   - 第三（最大剪应力 σ1−σ3）：塑性材料，偏保守。
   - 第四（形状改变比能）：塑性材料，更精确，**FEA 的 von Mises 应力就是第四理论**。
   - 常错：对塑性材料用第一理论。判断口诀："**脆性看拉、塑性看剪**"。
2. **弯扭组合当量应力**：
   - 第三理论：σ_e = √(σ² + 4τ²)。
   - 第四理论：σ_e = √(σ² + 3τ²)。
   - **常错**：把 4τ² 写成 τ²（漏了系数）。记忆：第三是 4，第四是 3。
3. **抗弯/抗扭截面系数**：
   - 圆轴 W = πd³/32（抗弯），W_p = πd³/16（抗扭），**W_p = 2W**。
   - 矩形 W = bh²/6（抗弯）。
   - 常错：把 W 和 W_p 搞混。
4. **疲劳极限 σ_(-1) 的下标**：-1 表示**对称循环**（应力比 R=-1）。σ_0 是脉动循环（R=0），σ_b 是静载。常错在不知道下标含义。

##### F. 机电一体化与机器人

1. **开环 vs 闭环的精度来源**：
   - 开环精度 = 步进电机分辨率 + 传动精度，**无反馈修正**，误差会累积。
   - 闭环精度 = 编码器反馈 + 控制器修正，**精度高但有稳定性问题**（可能振荡）。
   - 常追问："步进电机为什么是开环但还能定位？"——答：靠**脉冲数**控制转角（每脉冲固定步距角），不反馈但理论上准确，缺点是**堵转丢步**无法发现（除非加位置反馈）。
2. **PID 调参**：
   - P 增大 → 响应快但超调大、稳态误差减小但不消除。
   - I 增大 → 消除稳态误差，但响应变慢、易超调振荡。
   - D 增大 → 抑制超调，但放大噪声。
   - **调参顺序**：先 P（到临界不振荡），再加 I（消稳态），最后小量 D（压超调）。常错在"一上来就加 D"。
   - 口诀："**先比例后积分，微分最后慢慢加**"。
3. **伺服三环**：电流环（最内，毫秒级）→ 速度环（中，10ms 级）→ 位置环（最外，控制位置）。**外环带宽低于内环**，否则振荡。常追问："为什么不是位置环最内？"——答：电流是最快的物理量（电气时间常数小），必须先快控好才能稳定外环。
4. **DH 参数 4 个量的物理意义**（务必记牢）：
   - **a**：两相邻关节轴线的**最短距离**（连杆长度）。
   - **α**：两关节轴线的**夹角**（扭角）。
   - **d**：沿关节轴线方向，前一连杆 i-1 与后一连杆 i 的**偏置距离**。
   - **θ**：绕关节轴线的**转角**（旋转关节是变量，移动关节 d 是变量）。
   - 常错：把 a 和 d 搞混。判断："**a 是垂直于轴的距离（连杆本身长度），d 是沿轴的距离（偏置）**"。
5. **奇异点**：det(J)=0 处，机械臂失去某方向运动能力。典型：肘伸直（奇异）、腕三轴共线（奇异）。常追问："奇异点会发生什么？"——答：末端某些方向无法移动、关节速度趋于无穷、控制困难，规划轨迹要**避开奇异区**。

#### 2.5.5 简历包装——如何把科研项目讲成"机械故事"

你的科研是 AI 视觉，但投机械岗。**关键是把项目重新包装成"机械+AI 系统"而非纯算法**。三个话术转换：

|---|---|
| "我做了 YOLO 模型改进，提升分割精度" | "我研发了套袋机器人的**视觉感知模块**，输出幼果位姿给机械臂运动规划" |

| "模型 4.2M 参数" | "模型轻量化至 4.2M，**适配嵌入式部署，满足产线实时性**" |

**核心思路**：每个 AI 成果后面**加一句"工程意义"**——"这个提升对机械系统有什么用"。这样面试官会觉得你不是只会调参的算法党，而是**懂工程的复合型人才**。

#### 2.6.4 技术面问答范例（含追问套路）

> 机械面试的追问有固定套路。下面给出 5 个高频题的**标准回答 + 面试官常见追问 + 应对**。

##### 范例 1：基孔制与基轴制

**问**：什么是基孔制和基轴制？各适用什么场合？

**标准回答**：
> 基孔制是孔的基本偏差固定为 H（下偏差 EI=0），通过改变轴的偏差来获得
> 不同配合；基轴制是轴的基本偏差固定为 h（上偏差 es=0），通过改变孔的
> 偏差来获得配合。

**追问 1**：为什么一般优先用基孔制？
> 因为孔加工多用定值刀具（钻头、铰刀、拉刀），刀具按基本尺寸系列化，
> 改变轴的偏差只需要换一把车刀，成本更低；而轴加工用通用刀具即可调整。

**追问 2**：什么时候必须用基轴制？
> 三种情况：①用冷拔钢不再加工的轴；②同一轴上多个不同配合的孔
> （如活塞销与连杆、活塞的配合）；③与标准件配合（如轴承外圈与座孔）。

**追问 3**：H7/g6 是什么配合？最大最小间隙多少？（给你 φ25 H7/g6）
> 间隙配合。H7 = 25⁺⁰·⁰²¹⁰，g6 = 25₋₀·₀₂₀⁻⁰·₀₀₇。
> 最大间隙 = ES − ei = 0.021 − (−0.007) = 0.028 mm；
> 最小间隙 = EI − es = 0 − (−0.020) = 0.020 mm。

**应对策略**：基孔制/基轴制是**100% 必考**，连同配合代号计算一起准备，能算到具体间隙值是加分项。

##### 范例 2：螺栓总拉力

**问**：螺栓总拉力怎么算？

**标准回答**：
> F0 = F' + K·F。其中 F' 是预紧力，F 是工作载荷，K 是螺栓的相对刚度，
> K = 螺栓刚度/(螺栓刚度+被连接件刚度)，金属件 K≈0.2~0.3。

**追问 1**：为什么不是 F0 = F' + F？
> 因为螺栓和被连接件是弹性耦合系统。加载后螺栓伸长 Δ，被连接件压缩量
> 同步减少 Δ，回弹释放一部分预紧力作用在螺栓上，所以螺栓只承受工作载荷
> 的 K 倍，不是全部。

**追问 2**：1.3 系数是什么？
> 是强度校核时把扭转剪应力折算到拉伸的综合系数。拧紧时扳手力矩除产生
> 拉伸还产生扭转，按第四强度理论 σ_e = √(σ²+4τ²)，工程上简化为 1.3σ，
> 所以 σ = 1.3·F0/A_s ≤ [σ]。

**追问 3**：压力容器为什么要求残余预紧力大？
> 压力容器有密封要求，工作时介质压力会使结合面有分离趋势，残余预紧力
> 不足会泄漏。一般要求 F'' ≥ 1.5~1.8·F。

**应对**：螺栓公式**最高频**，F0=F'+K·F 是核心，**不要写成 F'+F**（这是最典型错误）。1.3 系数和压力容器要求是高频追问。

##### 范例 3：轴承寿命

**问**：滚动轴承寿命怎么计算？

**标准回答**：
> 基本额定寿命 L10 = (C/P)^ε，单位百万转。C 是基本额定动载荷，P 是当量
> 动载荷，ε 对球轴承是 3、对滚子轴承是 10/3。小时寿命 Lh = 10⁶·L10/(60·n)。
> P = X·Fr + Y·Fa，X、Y 查手册。

**追问 1**：L10 什么意思？
> L10 表示可靠度 90%、即 10% 失效概率下的寿命，是轴承样本的标准指标。

**追问 2**：6208 轴承内径多少？
> 08 是内径代号，08×5 = 40mm。

**追问 3**：球轴承 ε=3，滚子轴承 ε=10/3，为什么滚子轴承 ε 大？
> 滚子轴承是线接触，应力分布更均匀，疲劳寿命随载荷下降更慢，所以 ε
> 更大，同样 C/P 下寿命更长。

**应对**：寿命公式 + 内径代号 + ε 含义三连问，务必背熟。

##### 范例 4：机器人 DH 参数

**问**：DH 参数 4 个量分别是什么？

**标准回答**：
> a 是相邻两关节轴线的最短距离（连杆长度）；α 是两关节轴线的夹角
> （扭角）；d 是沿关节轴线的偏置距离；θ 是绕关节轴线的转角。旋转关节
> θ 是变量，移动关节 d 是变量。

**追问 1**：标准 DH 和改进 DH 的区别？
> 标准 DH 坐标系固结在后一杆，改进 DH 坐标系固结在前一杆。改进 DH 对
> 闭环机构和球形腕处理更方便，现代机器人学多用 MDH。

**追问 2**：正运动学和逆运动学的区别？
> 正运动学：已知关节角求末端位姿，T = A1·A2·...·An，唯一解；
> 逆运动学：已知末端位姿求关节角，可能多解、无解，奇异点附近数值困难。

**追问 3**：什么是奇异点？
> 雅可比矩阵行列式为零的点，机械臂在该位姿失去某方向运动能力，典型
> 是肘伸直、腕三轴共线。

**应对**：DH 4 参数必须背熟物理意义（**a 垂直轴、d 沿轴**），奇异点定义和典型例子要会举。

##### 范例 5：你的科研项目（必问）

**问**：介绍一下你的柑橘分割项目。

**标准回答（STAR 90 秒）**：
> 【S】柑橘套袋机器人需要精准识别幼果位置和轮廓来指导机械臂抓取，传统
> 人工套袋效率低。我的任务是做视觉感知模块。
> 【T】要在 <5M 参数约束下提升 mask 分割精度。
> 【A】我设计了三个模块：低光增强前端 HVIEnhance、多极注意力 C2MANO、
> 凹陷边界损失 COB Loss。
> 【R】mask mAP50-95 从 0.642 提升到 0.678，参数 4.2M，FPS 120，满足
> 实时性和嵌入式部署要求。

**追问 1**：为什么选 YOLO11n 而不是更大的模型？
> 工程约束是嵌入式部署，YOLO11n 参数小、速度快，在精度和速度间取得
> 平衡；更大的模型精度略高但速度跟不上产线实时要求。

**追问 2**：HVIEnhance 为什么用 HVI 色彩空间？
> HVI 色彩空间把亮度和色调解耦，在低光照下色调保持稳定，比 RGB 或
> HSV 更适合处理低光偏色问题，这是针对果园实际光照场景的选择。

**追问 3**：COB Loss 和普通 Boundary Loss 区别？
> 普通 Boundary Loss 只惩罚边界距离，COB Loss 针对**凹陷边界**
> （柑橘果柄凹陷处）加权惩罚，强化难分割区域的梯度。

**追问 4（机械岗追问）**：这个项目和机械有什么关系？
> 我的视觉模块输出幼果的位姿和轮廓，直接喂给机械臂的运动规划和夹爪
> 力控——分割的轮廓决定了夹爪的避障路径，分割的位姿决定了机械臂的
> 抓取点。整个系统是视觉感知+机械执行的闭环。

**应对**：科研项目必被深挖。**准备 5 个追问的预案**，特别是**"和机械什么关系"**——这是你从 AI 转机械岗的核心说服点。

- **机械岗占比**：极高，**人形机器人公司机械是核心岗**（关节、骨架、外壳全是机械）。2024 年起人形机器人爆发，需求暴增。
- **文化**：创业公司氛围，**弹性加班**（无强制 996，但项目期通宵常见），团队年轻（平均 28 岁），技术驱动。
- **机械岗真实工作**：关节模组（电机+谐波+编码器一体化）、轻量化骨架（碳纤维/铝合金）、外壳（注塑/3D 打印）、**运动学仿真**（DH 参数、轨迹规划）。
- **面试风格**：3 轮——**技术面 1（机械基础+项目）→ 技术面 2（运动学/动力学深挖，会出动手题）→ 创始人/CTO 面（看你是不是真的热爱机器人）**。**重点考察机器人运动学**（正逆解、DH 参数、雅可比），你的 Day 19-20 必须扎实。
- **加分项**：有 ROS/MoveIt 经验、有机器人比赛（RoboMaster/RoboCup）经验、有强化学习控制经验。
- **薪资**：应届硕士 18-28K×13-15 薪 + 期权（创业公司期权价值待定）。**比海康略高，但稳定性差**。
- **投递策略**：**简历必须突出机器人方向**（即使你做的是视觉分割，也要包装成"机器人视觉感知"——把柑橘分割和机械臂抓取联系起来）。建议做一个小项目：用 Python 控制 2-3 关节机械臂做轨迹规划（Day 21、29），写进简历。
- **避坑**：人形机器人公司**节奏快、变动大**，6 个月项目方向可能调 3 次，适合**想快速成长、能抗压**的人；想要稳定的不建议。

##### ④ 吉利汽车（杭州滨江区 + 宁波杭州湾）

- **机械岗占比**：整车厂机械岗极多——**车身、底盘、内外饰、动力总成**四大方向各招一批。
- **文化**：传统车企文化，**层级清晰、流程规范**，加班视项目阶段（项目期加班多、量产后平稳）。**有完善的应届生培养体系**（"高潜计划"等）。
- **机械岗真实工作**：钣金车身设计、底盘悬架调校、内外饰件（注塑件）结构、**NVH（噪声振动）分析**、**有限元分析**（碰撞、模态）。
- **面试风格**：3 轮——**专业笔试（汽车机械基础+英语）→ 技术面（汽车构造+项目）→ HR 面**。**汽车构造**是必考（变速器、悬架、制动系统原理），你需要在 30 天计划外补 1 周汽车构造。
- **薪资**：应届硕士 13-20K×13-14 薪 + 项目奖金，**极氪**（吉利高端子品牌）薪资更高（16-25K）。
- **投递策略**：吉利秋招名额多、**对江南大学认可度高**（浙江高校优先）。**极氪**作为高端线值得重点投。地点宁波杭州湾（离杭州市区 1 小时车程，要接受通勤/外派）。
- **避坑**：传统车企机械岗**晋升慢**（评职称体系），3 年内难独立带项目；新能源车企（极氪/零跑）节奏更快、机会更多。

##### ⑤ 中控技术（杭州滨江，DCS/工业自动化龙头）

- **机械岗占比**：相对少——**过程自动化**为主，机械岗偏向**仪表结构、机柜、装配工艺**。
- **文化**：技术氛围浓厚，**DCS（集散控制系统）国产龙头**，业务稳定，加班相对适中。
- **薪资**：应届 12-18K×13 薪。
- **投递策略**：**自动化工程师/机械工程师**岗都投，中控更看中**控制系统+机械**交叉背景，你的 PLC+PID 基础（Day 18、26）是加分项。
- **面试**：技术面会问**自动化产线设计**（从传感器→PLC→执行器全链路）。

### D. 心理建设与压力管理（求职期必修）

> 求职是一场持续 8-10 个月的马拉松。**心理崩溃比知识不足更致命**——见过太多人投 20 家没回音就放弃，最后仓促签约不满意的公司。这一节专治求职焦虑。

#### D.1 接受"机械基础薄弱"这个事实，但不自卑

你的现状：硕士做 AI 视觉，机械基础因为本科没好好学而有短板。**这是事实，不是耻辱**。

正确的态度：
- **不回避**——面试官问机械基础，不会就坦诚说"这块我硕士阶段没深入，但我正在系统补强，目前已完成 XX"，比硬编好得多。
- **不自卑**——你有 AI 交叉背景，这是传统机械硕士没有的优势。你不是"机械差的机械硕士"，你是"懂 AI 的机械硕士"，定位不同。
- **用行动证明**——30 天重修 + 2 个机械项目（减速器、夹爪）就是你的"补强证据"，面试时拿出来。

#### D.2 应对"投了没回音"的焦虑

秋招期最折磨人的是**石沉大海**——投了 30 家，只有 3 家回复。

真相和对策：
- **应届简历通过率本来就 10-20%**——投 30 家回 3-5 家是正常，不是你差。
- **简历没过初筛**多半是关键词不匹配——回头按 2.11.4 的 JD 拆解法补关键词。
- **笔试挂了**是基础不牢——回头刷 30 天的算题。
- **面试挂了**是表达/项目深挖不够——录下自己的模拟面试反复听。
- **不要停下来**——投递是概率游戏，**投得够多才有 offer**。每天保持投 2-3 家的节奏，不要因为连续被拒就停。
- **建立反馈循环**——每挂一次面试，当晚复盘"哪个问题答得不好"，记到错题本，下次不再错。

#### D.3 应对"别人都拿 offer 了"的同辈压力

秋招 10-11 月，朋友圈开始晒 offer，你会焦虑。

理性认知：
- **提前批 offer 不代表最终归属**——很多人提前批拿了又毁，最终去了别家。
- **你的时间线是 2027 秋招，2028 毕业**——比同年 6 月毕业的早半年准备，**你有时间优势**。
- **offer 质量比数量重要**——仓促签的差公司，比没 offer 更难受（毁约金 + 错过更好的）。
- **关掉朋友圈秋招季**——必要时屏蔽晒 offer 的同学 1-2 个月，保护心态。

#### D.4 压力期的时间管理与作息

求职期的作息建议（避免熬夜导致状态崩盘）：

| 时段 | 活动 | 要点 |
|---|---|---|
| 7:30-8:00 | 起床+早餐 | 不熬夜的前提是早睡 |
| 8:30-11:30 | 投简历+刷题+补短板 | 上午精力好，做硬核任务 |
| 11:30-13:30 | 午餐+午休 | 必须午休 30 分钟 |
| 13:30-17:00 | 面试/SW 实操/项目 | 下午做需要专注的事 |
| 17:00-18:30 | 运动（跑步/健身） | **每天 30 分钟运动是抗焦虑的神药** |
| 18:30-20:00 | 晚餐+放松 | 离开屏幕 |
| 20:00-22:00 | 复盘+准备明日面试 | 整理今日错题、明日 JD |
| 23:00 前 | 睡觉 | **睡不够会面试状态差**，比多看 1 小时书损失大 |

**运动**是求职期**最被低估的抗压手段**——每天 30 分钟跑步/健身，能显著降低皮质醇（压力激素），让面试时头脑清醒。**不要因为"忙"就不运动**，越忙越要运动。

#### D.5 面试当天的状态管理

- **面试前 1 天**：早睡，**不临时抱佛脚背新东西**（记不住反而焦虑）。把要讲的自我介绍和 5 个项目追问**过一遍**即可。
- **面试前 2 小时**：吃轻食（别吃太饱犯困），喝咖啡/茶提神。
- **面试前 30 分钟**：找个安静地方，**深呼吸 3 次**，对自己说"我准备充分，正常发挥就好"。
- **面试中紧张时**：说话慢一点，**喝口水**争取思考时间；不会的问题坦诚说"这块我不太熟，但我的理解是 XX，请面试官指正"。
- **面试后**：**立刻记录所有被问的问题**（趁记忆新鲜），答得不好的当晚补。这是最宝贵的题库。

#### D.6 拿到 offer 后的决策

拿到多个 offer 时，决策维度（按权重排序）：

| 维度 | 权重 | 说明 |
|---|---|---|
| 成长性（平台/培养） | 30% | 应届**第一份工作看成长**，好平台 3 年后跳槽溢价远超起薪差 |
| 业务方向匹配 | 20% | 是否机器人/AI+机械这种你感兴趣的复合方向 |
| 薪资总包 | 20% | 月薪×薪数+年终+签字费+期权，**不只看月薪** |
| 加班强度 | 15% | 996 还是 965，影响健康和生活 |
| 地点 | 10% | 杭州优先，异地要考虑安家 |
| 稳定性 | 5% | 创业公司 vs 大厂，应届建议**先去大厂或成熟公司** |

**决策矩阵示例**：

| offer | 成长 | 方向 | 薪资 | 加班 | 地点 | 总分 |
|---|---|---|---|---|---|---|
| 海康（结构） | 9 | 7 | 8 | 5 | 10 | 7.9 |
| 宇树（机器人） | 10 | 10 | 8 | 4 | 10 | 8.4 |
| 吉利（底盘） | 7 | 6 | 7 | 6 | 8 | 6.8 |

按权重打分，**不要只看薪资**。应届选**宇树**（成长+方向匹配）长期收益最高，即使加班重、薪资略低。

### E. 常见问题 FAQ

#### E.1 关于重修

**Q1：30 天真能重修完机械基础吗？会不会太赶？**
> 30 天能建立**框架和面试级掌握**，但不能达到资深工程师水平。目标是"面试能答、入职能上手基础"，不是"精通"。深度掌握靠入职后 2-3 年项目实战。如果觉得赶，可以延长到 45 天（每天任务减半）。

**Q2：没有 SolidWorks 授权怎么办？**
> 三个选择：①学校机房通常有授权（去学校用）；②教育版（学生邮箱免费申请 SolidWorks Student）；③FreeCAD 开源替代（功能弱但免费，够练习基础建模）。**作品集尽量用 SW**——企业默认用 SW。

**Q3：教材必须买实体书吗？**
> 不必。电子版（PDF）够用，但**公差表、轴承表、齿轮模数表要打印纸质**方便随时查。机械设计手册（闻邦椿）有电子版，选型速查必备。

**Q4：算题总是算错怎么办？**
> 三步：①记公式（用记忆卡片）；②抄例题（机械设计、材料力学课后例题）；③变式自练（改数字重算）。错题本记下**错在哪一步**，不是抄答案。算错的题当晚重算，3 天后再算一次。

**Q5：口述面试题自己一个人练有效吗？**
> 有效，但**最好录音回听**。自己说的时候感觉良好，听录音会发现卡顿、啰嗦、逻辑乱。更理想是找同学互相模拟面试（每周 1 次）。

#### E.2 关于就业

**Q6：杭州机械岗真的多吗？会不会僧多粥少？**
> 杭州是**长三角制造业+机器人重镇**，机械岗数量充足（海康、大华、宇树、吉利、零跑等都在招）。竞争确实激烈（浙大、东南、南理工、江大、浙工大等高校毕业生都在抢），但你的**机械+AI 交叉背景**在机器人公司是稀缺的，比纯机械硕士有差异化优势。

**Q7：江南大学在杭州求职认可度如何？**
> 江大是 211，在长三角认可度高。杭州本地企业（海康、宇树、吉利）对江大有偏好（浙江高校优先）。但和浙大比有差距——**浙大简历是加分项，江大是中性项**，靠项目和实习补齐。

**Q8：实习和秋招冲突怎么办？**
> 暑期实习（7-9 月）和秋招提前批（7-8 月）时间重叠。策略：①实习公司**就是秋招目标**的，优先实习（转正率高）；②实习公司不是秋招目标，或实习转正不确定的，**秋招提前批优先**（早拿 offer 保底）。**实习期间也可以请假面试**，一般公司允许。

**Q9：AI 背景投机械岗会被歧视吗？**
> 在**传统制造企业**（如海康安防主业）可能被质疑"会不会画图"，但在**机器人公司**（宇树、节卡）是**加分项**——他们要的就是懂 AI 的机械人。投递时**区分企业类型**：传统制造侧重机械基础补强，机器人公司侧重 AI+机械交叉。

**Q10：女生投机械岗有影响吗？**
> 客观说，传统重型机械（如机床、重工）对女生有隐性偏好男生（现场调试体力）。但在**机器人公司、消费电子结构、机器视觉**方向（杭州主流），性别影响小。建议投机器人/视觉/消费电子结构岗，避开纯现场调试岗。

**Q11：第一份工作选大厂还是创业公司？**
> 应届**建议先大厂或成熟公司**（海康、吉利、埃斯顿）。理由：①培养体系完善；②履历背书；③见过的流程规范。2-3 年后再考虑去创业公司（宇树类）挑大梁。例外：如果你**极热爱机器人且能抗压**，直接去宇树这种明星创业公司也行，成长快但风险高。

**Q12：毁约三方要赔多少？**
> 一般违约金 3000-5000 元（看三方协议条款），少数大厂 1-2 万。**签约前看清违约金**。毁约要趁早（秋招毁约比春招毁约机会成本小）。

**Q13：春招还有好机会吗？**
> 有，但**比秋招少、薪资可能略低**。春招主要是：①秋招没招满的企业补录；②新成立业务线招人；③毁约释放的 HC。**把秋招当主战场**，春招是补录保底，别指望春招拿到第一梯队 offer。

#### E.3 关于持续学习

**Q14：入职后机械基础怎么继续补？**
> 三条路：①跟着项目实战（最快，但依赖项目质量）；②考**机械工程师认证**（注册机械工程师、SolidWorks CSWP 认证）倒逼学习；③读在职工程博士（如果想深造，但一般没必要）。

**Q15：机器人方向长期看有前景吗？**
> 人形机器人在 2024-2026 年爆发（特斯拉 Optimus、宇树、Figure），是**未来 10 年的黄金赛道**。你的机械+AI 背景正是这个赛道最缺的复合人才。**坚定投机器人方向**，长期收益高。

```
2026.07-08  ── 30天机械重修 + SW/ANSYS 入门

                ↓
2027.01-03  ── 暑期实习投递 + 面试准备
                ↓
2027.04-06  ── 暑期实习（目标转正）
                ↓
2027.07-08  ── 秋招提前批（主投第一梯队）
                ↓
```
