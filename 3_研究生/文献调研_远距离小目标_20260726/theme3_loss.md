# 主题3：损失函数改进文献（目标检测/分割）

课题背景：YOLO11n-seg 柑橘幼果实例分割；远处果实极小（小目标）、远处模糊果实为估计性标注（低质量框）。
核实方式：全部条目经 Semantic Scholar Graph API（/paper/batch + /paper/{id}）核实，DOI/arXiv ID 均为 API 返回值，无编造。共 18 篇。
YOLO11 基线损失：box = CIoU + DFL；cls = BCE；seg mask = 逐像素 BCE（Ultralytics `utils/loss.py` 中 `BboxLoss` / `v8SegmentationLoss`）。

---

## A. IoU 族回归损失（改 box 分支）

### 1. DIoU / CIoU
- 标题：Distance-IoU Loss: Faster and Better Learning for Bounding Box Regression
- 第一作者：Zhaohui Zheng；年份：2020（arXiv 2019）；venue：AAAI 2020
- DOI：10.1609/AAAI.V34I07.6999；arXiv:1911.08287
- 核心思想：在 IoU 基础上加入中心点归一化距离惩罚（DIoU），再加长宽比一致性项（CIoU），加速收敛并改善不重叠情形的回归。
- 适用性：YOLO11 默认即 CIoU，是本课题的基线与对照组，必引。
- 接入方式：无需改动；作为消融实验 baseline。

### 2. EIoU / Focal-EIoU
- 标题：Focal and Efficient IOU Loss for Accurate Bounding Box Regression
- 第一作者：Yi-Fan Zhang；年份：2022（arXiv 2021）；venue：Neurocomputing
- DOI：10.1016/j.neucom.2022.07.042；arXiv:2101.08158
- 核心思想：把 CIoU 的长宽比项拆为宽、高各自的真实差值惩罚（EIoU），并用 Focal-L1 式加权聚焦高 IoU 高质量样本（Focal-EIoU，静态聚焦机制）。
- 适用性：是 Wise-IoU 明确对标改进的前身（静态 FM），可作对照；其"聚焦高质量样本"的取向与本课题低质量标注场景相反，正好构成论证反例。
- 接入方式：替换 `bbox_iou` 中 CIoU=True 分支为 EIoU 计算，作为消融对照。

### 3. SIoU
- 标题：SIoU Loss: More Powerful Learning for Bounding Box Regression
- 第一作者：Zhora Gevorgyan；年份：2022；venue：arXiv
- arXiv:2205.12740（DOI:10.48550/arXiv.2205.12740）
- 核心思想：引入回归向量夹角（angle cost），使预测框先沿最近坐标轴漂移再回归距离/形状，减少自由度、加快收敛。
- 适用性：农业检测改进论文的常见对照项；对小目标收敛速度有一定帮助，但无噪声鲁棒性论述。
- 接入方式：同上，`bbox_iou` 增加 SIoU 分支，作消融对照。

### 4. Wise-IoU（重点，与本课题痛点直接契合）
- 标题：Wise-IoU: Bounding Box Regression Loss with Dynamic Focusing Mechanism
- 第一作者：Zanjia Tong；年份：2023；venue：arXiv
- arXiv:2301.10051（DOI:10.48550/arXiv.2301.10051）
- 核心思想：提出动态非单调聚焦机制（FM）：用"离群度"（outlier degree，= 当前框回归损失 / 损失的滑动均值）而非 IoU 评估 anchor 质量，动态分配梯度增益。
- **论文中关于低质量标注的准确转述（据摘要原文核实）**：
  1. 现有 BBR 损失大多"假设训练数据中的样本是高质量的"，一味强化损失的拟合能力；但"如果盲目对低质量样本强化 BBR，将损害定位性能"（"If we blindly strengthen BBR on low-quality examples, it will jeopardize localization performance."）。
  2. WIoU 的梯度增益分配策略"在降低高质量 anchor 竞争力的同时，也削减低质量样本产生的有害梯度"（"reduces the competitiveness of high-quality anchor boxes while also reducing the harmful gradient generated by low-quality examples"），使模型聚焦普通质量样本，提升整体性能。
  3. 与 Focal-EIoU 的静态 FM 相比，其 FM 是动态的：随训练中损失滑动均值变化，质量划分标准自适应更新（v3 版本）。
  - 注意：论文语境中"低质量样本"指训练集中天然存在的低质量/难例（含标注不准的框产生的异常大回归损失），并未专门做"人为噪声标注"实验——写论文时应转述为"其机制天然抑制异常大梯度、因而对不精确标注具有鲁棒性"，不要夸大为"专为噪声标注设计"。
- 适用性：与"远处模糊果实凭估计标注、框可能不准"的痛点高度契合——估计性错框在训练中表现为离群大损失，WIoU v3 会自动压低其梯度增益，避免网络过拟合噪声框。
- 接入方式：主改进项。替换 `BboxLoss.forward` 中 CIoU 为 WIoU v3（需维护 IoU 损失滑动均值 buffer，momentum≈1-1e-2，注意与 EMA/AMP 兼容）；建议与 Inner-IoU 或 Focaler-IoU 组合形成"XX-WIoU"式复合损失以凑创新点。

### 5. Inner-IoU
- 标题：Inner-IoU: More Effective Intersection over Union Loss with Auxiliary Bounding Box
- 第一作者：Hao Zhang；年份：2023；venue：arXiv
- arXiv:2311.02877（DOI:10.48550/arXiv.2311.02877）
- 核心思想：用比例因子 ratio 生成缩放的"辅助框"计算 IoU：ratio<1 加速高 IoU 样本收敛，ratio>1 有利低 IoU 样本，是可叠加到任意 IoU 损失上的插件。
- 适用性：小目标 IoU 对偏移极敏感，辅助框可缓和梯度；常与 WIoU/SIoU 组合（Inner-WIoU），适合作为组合创新的部件。
- 接入方式：在 `bbox_iou` 内按 ratio 缩放两框后计算 IoU，再套用 WIoU 聚焦系数。

### 6. Shape-IoU
- 标题：Shape-IoU: More Accurate Metric considering Bounding Box Shape and Scale
- 第一作者：Hao Zhang；年份：2023；venue：arXiv
- arXiv:2312.17663（DOI:10.48550/arXiv.2312.17663）
- 核心思想：让距离/形状惩罚项按 GT 框自身的形状与尺度加权，聚焦框本身属性而非仅与 GT 的相对关系，对小目标更公平。
- 适用性：柑橘幼果近似圆形、远近尺度差异大，Shape-IoU 的尺度自适应权重有针对性；可作对照或组合项。
- 接入方式：`bbox_iou` 增加 Shape-IoU 分支；或其加权思想并入 WIoU 复合损失。

### 7. MPDIoU
- 标题：MPDIoU: A Loss for Efficient and Accurate Bounding Box Regression
- 第一作者：Siliang Ma；年份：2023；venue：arXiv
- arXiv:2307.07662（DOI:10.48550/arXiv.2307.07662）
- 核心思想：直接最小化预测框与 GT 框左上/右下两角点距离（以图像对角线归一化），统一覆盖重叠与不重叠情形，简化几何惩罚。
- 适用性：实现简单、常见于 YOLO 改进论文对照组；对小目标角点距离敏感度高，需实验验证。
- 接入方式：`bbox_iou` 增加 MPDIoU 分支，作消融对照。

### 8. Focaler-IoU
- 标题：Focaler-IoU: More Focused Intersection over Union Loss
- 第一作者：Hao Zhang；年份：2024；venue：arXiv
- arXiv:2401.10525（DOI:10.48550/arXiv.2401.10525）
- 核心思想：对 IoU 值做线性区间映射 [d,u] 重构损失，通过区间选择自由聚焦困难样本或简单样本，可叠加到 GIoU/DIoU/CIoU/EIoU/SIoU 上。
- 适用性：小而模糊的远处果实属困难样本，区间聚焦可调；与 WIoU 组合（Focaler-WIoU）是现成的组合创新路径。
- 接入方式：在 IoU 计算后加区间线性映射，再入 WIoU 聚焦框架；[d,u] 作超参消融。

### 9. Powerful-IoU（PIoU / PIoU v2）
- 标题：Powerful-IoU: More straightforward and faster bounding box regression loss with a nonmonotonic focusing mechanism
- 第一作者：Can Liu；年份：2024（在线 2023-11）；venue：Neural Networks (vol. 170)
- DOI：10.1016/j.neunet.2023.11.041
- 核心思想：以目标框尺寸自适应的惩罚因子 P 替代最小外接框惩罚（避免 anchor 被"撑大"），PIoU v2 再叠加单超参的非单调聚焦层聚焦中等质量 anchor。
- 适用性：期刊正式发表的非单调聚焦损失，与 WIoU 同思路但更简洁，是强对照/替代方案；尺寸自适应惩罚对极小果实有利。
- 接入方式：`bbox_iou` 实现 PIoU v2，与 WIoU v3 做同台消融，择优为主方案。

### 10. Unified-IoU
- 标题：Unified-IoU: For High-Quality Object Detection
- 第一作者：Xiangjie Luo；年份：2024；venue：arXiv
- arXiv:2408.06636（DOI:10.48550/arXiv.2408.06636）
- 核心思想：训练过程中动态转移对高/低质量预测框的关注权重（类似退火），前期关注低质量框保证收敛、后期偏向高质量框提升高精度指标（如 AP75）。
- 适用性：与本课题"标注本身不可靠"的前提部分冲突（其目标是高质量框），主要作近年 IoU 综述性引用与对照。
- 接入方式：仅文献综述引用；如需可作消融对照。

## B. 小目标专用度量

### 11. NWD（Normalized Gaussian Wasserstein Distance）
- 标题：A Normalized Gaussian Wasserstein Distance for Tiny Object Detection
- 第一作者：Jinwang Wang；年份：2021；venue：arXiv
- arXiv:2110.13389（无期刊 DOI，以 arXiv ID 为准）
- 核心思想：把边框建模为二维高斯分布，用归一化 Wasserstein 距离替代 IoU 度量相似性；对微小目标的位置偏差不敏感、且对无重叠框仍有平滑梯度。论文明确指出 IoU 对 tiny object 的微小位置偏移过度敏感，且该敏感性会放大"标注抖动"的影响。
- 适用性：直击"远处果实极小 + 标注框可能不准"两个痛点——NWD 对几像素的框偏移宽容，等于天然容忍估计性标注误差。
- 接入方式：回归损失用 `L = α·L_IoU族 + (1-α)·L_NWD`（α≈0.5）混合；进阶：把 TaskAlignedAssigner 的匹配度量也换成 NWD（分配端对小目标影响更大）。

## C. 分类 / 样本加权损失（改 cls 分支）

### 12. Focal Loss
- 标题：Focal Loss for Dense Object Detection
- 第一作者：Tsung-Yi Lin；年份：2017（TPAMI 版 2020）；venue：ICCV 2017 / IEEE TPAMI
- DOI：10.1109/TPAMI.2018.2858826；arXiv:1708.02002
- 核心思想：(1-p)^γ 调制因子降低大量易分负样本的损失权重，使训练聚焦难例，解决单阶段检测器前景-背景极端不平衡。
- 适用性：奠基性引用；注意其"聚焦难例"在噪声标注下会放大错标样本梯度——这正是引出 WIoU/GHM 论述的铺垫。
- 接入方式：文献综述引用；YOLO11 cls 分支默认 BCE，可试 γ 小值 Focal 变体作对照。

### 13. VariFocal Loss
- 标题：VarifocalNet: An IoU-aware Dense Object Detector
- 第一作者：Haoyang Zhang；年份：2021；venue：CVPR 2021
- DOI：10.1109/CVPR46437.2021.00841；arXiv:2008.13367
- 核心思想：非对称 Focal 加权：负样本按 p^γ 降权、正样本以 IoU 感知的软标签（IACS）加权，训练分类分支预测"分类×定位"联合质量。
- 适用性：正样本按 IoU 软加权 = 低 IoU（可能是错标）的正样本权重自动降低，对估计性标注有隐性鲁棒效果；Ultralytics 代码库中已有 `VarifocalLoss` 实现（默认未启用），接入成本极低。
- 接入方式：cls 分支 BCE → VariFocal（复用库内实现），与 box 端 WIoU/NWD 形成"分类+回归"双端改进叙事。

### 14. Slide Loss（YOLO-FaceV2）
- 标题：YOLO-FaceV2: A Scale and Occlusion Aware Face Detector
- 第一作者：Ziping Yu；年份：2022（期刊版 Pattern Recognition，S2 venue 显示）；arXiv:2208.02019
- 核心思想：以样本 IoU 的均值 μ 为自适应阈值，对 μ 附近的"边界难例"用指数函数 Slide 加权强化，易样本低权、难样本高权。
- 适用性：农业 YOLO 改进论文高频引用；但对错标样本同样会加权（视为难例），与噪声鲁棒目标有张力，建议只作对照或谨慎组合。
- 接入方式：cls BCE 乘 Slide 权重函数（以 batch 内 IoU 均值为阈值），作消融对照。

### 15. GHM（梯度协调机制）
- 标题：Gradient Harmonized Single-stage Detector
- 第一作者：Buyu Li；年份：2019；venue：AAAI 2019
- DOI：10.1609/aaai.v33i01.33018577；arXiv:1811.05181
- 核心思想：统计梯度模长分布，按"梯度密度"反比重加权：既压制海量易样本，也压制梯度极大的离群样本——论文明确指出后者"很可能是外点/错标样本（outliers）"，一味聚焦它们反而损害性能。
- 适用性：为"不该盲目聚焦难例、错标即离群"提供了早于 WIoU 的理论依据，是论文立论的关键引用；GHM-C（分类）与 GHM-R（回归）均可参考。
- 接入方式：主要作理论支撑引用；如实现，对 cls 分支按梯度密度分桶加权。

## D. 分割边界 / 区域损失（改 seg mask 分支）

### 16. Boundary Loss
- 标题：Boundary loss for highly unbalanced segmentation
- 第一作者：Hoel Kervadec；年份：2019（MIDL 2019；扩展版 Medical Image Analysis 2021）
- DOI：10.1016/J.MEDIA.2020.101851；arXiv:1812.07032
- 核心思想：用水平集距离图把边界间距离积分转化为逐像素可微损失，直接优化轮廓间距离，对极不平衡的小前景稳定。
- 适用性：远处幼果 mask 仅数十像素、前景占比极低，与其"高度不平衡小前景"的设定吻合；可改善小果实 mask 边缘质量。
- 接入方式：`v8SegmentationLoss` 的 mask BCE 上加权叠加 Boundary Loss（预计算 GT mask 距离变换图，权重从小到大 rebalance 调度）。

### 17. Tversky Loss（Dice 系列，简要）
- 标题：Tversky Loss Function for Image Segmentation Using 3D Fully Convolutional Deep Networks
- 第一作者：S. Salehi；年份：2017；venue：MLMI@MICCAI 2017
- DOI：10.1007/978-3-319-67389-9_44；arXiv:1706.05721
- 核心思想：Dice 的泛化：以 α/β 分别控制 FP/FN 惩罚权重，缓解小目标分割中 FN 主导的失衡（β>α 提升召回）。
- 适用性：简要引用即可——代表"区域重叠型损失"一支；小幼果 mask 易漏分，β>α 的 Tversky 可提召回。
- 接入方式：mask 分支 BCE + λ·Tversky（β≈0.7）组合，作 seg 端轻量消融。

## E. 标签噪声鲁棒（对"估计标注"痛点）

### 18. Learning From Noisy Anchors
- 标题：Learning From Noisy Anchors for One-Stage Object Detection
- 第一作者：Hengduo Li；年份：2020；venue：CVPR 2020
- DOI：10.1109/cvpr42600.2020.01060；arXiv:1912.05086
- 核心思想：指出基于 IoU 硬阈值的正负样本二元划分本身引入标签噪声，提出用定位精度+分类置信度构成的"cleanliness"软标签对样本连续加权，降低噪声监督的影响。
- 适用性：为"标注框不准 → 监督信号含噪 → 需软化/降权"提供顶会依据，与 WIoU 的梯度降权互为印证；YOLO11 的 TAL 分配本身已是软化思想的延续，可在论文中串联论述。
- 接入方式：主要作理论支撑引用；其 cleanliness 加权思想可类比到 TAL 分配分数对 cls/box 损失的加权上。

## 组合建议（供选题/实验设计参考）

- 主方案叙事线：低质量估计标注（WIoU v3 动态降权离群梯度）+ 极小目标（NWD 混合度量 / Inner 或 Shape 尺度项）+ 分割小前景（Boundary/Tversky 辅助 mask 损失）+ cls 端 VariFocal——四处改动均有直接文献依据且互不冲突。
- 消融矩阵建议：CIoU(基线) / SIoU / EIoU / MPDIoU / Shape-IoU / PIoU v2 / WIoU v3 / WIoU v3+NWD / WIoU v3+NWD+Inner。
- 立论引用链：Focal(聚焦难例) → GHM(难例中含错标离群点，不应盲目聚焦) → Noisy Anchors(标注噪声需软监督) → WIoU(动态非单调聚焦，削减低质量样本有害梯度) → 本文场景（远处果实估计标注）。
