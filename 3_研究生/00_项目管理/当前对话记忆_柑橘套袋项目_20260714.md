# 当前对话记忆：柑橘套袋视觉项目

## 项目定位

当前项目是硕士课题“柑橘套袋视觉”。第一篇论文聚焦 RGB 图像下的柑橘幼果实例分割，目标是快速形成可投稿成果；第二篇论文计划做柑橘果梗点精准定位，并以前一篇的果实实例/ROI 为基础。

当前优先级：

1. 第一篇论文尽快成型：幼果实例分割。
2. 方法方向坚持“轻量化 + 高精度”。
3. 创新点聚焦视觉算法难点，而不是泛泛而谈遮挡、小目标。
4. 不要把 RGB-D、机器人控制、多任务姿态头等方向混入第一篇。

## 标签漏标审查脚本

已新增一键审查脚本：

```text
E:\mastercode\ultralytics-main-new\audit_yolo_seg_labels.py
```

功能：

1. 加载当前训练权重：

```text
E:\mastercode\ultralytics-main-new\1_results\001_yolo11n_seg_AdamW\weights\best.pt
```

2. 对 train、val、test 全部 941 张图做前向预测。
3. 生成三栏对比图：
   - 左：原图
   - 中：绿色 GT 标签
   - 右：红色模型预测
4. 自动输出全部对比图。
5. 自动输出数量不一致的图片集合，方便检查漏标或漏检。

运行方式：

```powershell
cd E:\mastercode\ultralytics-main-new
python audit_yolo_seg_labels.py
```

当前脚本默认：

```python
SPLIT = "all"
OUTPUT_DIR = Path(r"E:\mastercode\ultralytics-main-new\1_results\001_yolo11n_seg_AdamW\label_audit_all")
RETINA_MASKS = False
INFERENCE_CHUNK_SIZE = 32
SAVE_ALL_IMAGES = True
SAVE_COUNT_MISMATCH_DIR = True
```

`RETINA_MASKS=False` 是为了避免高分辨率图像在 4GB GPU 上显存/内存爆掉。

`INFERENCE_CHUNK_SIZE=32` 是为了避免一次性加载 941 张图造成 `MemoryError`。

## 检查标签时的判断原则

看 `count_mismatch` 文件夹即可，不用先看全部 941 张。

判断方式：

1. 红色预测中有明显幼果，但绿色 GT 没有：优先怀疑漏标。
2. 绿色 GT 有，但红色预测没有：更可能是模型漏检。
3. 红色把一个果实拆成多个实例：可能是模型过分割。
4. 红色把多个相邻果实合成一个：可能是模型粘连/合并错误。
5. 叶片或枝条遮挡导致绿色标注边界不完整时，需要结合原图判断是否标注合理。
