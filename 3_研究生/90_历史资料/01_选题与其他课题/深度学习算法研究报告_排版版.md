# 课题一：食用菌切割点视觉定位算法

## 1.1 课题背景与科学问题

### 研究背景

食用菌产业年产量超4000万吨，但采后切割工序高度依赖人工。核心挑战：**如何在复杂视觉环境下，用深度学习精确解算蘑菇切割位姿**。

### 核心痛点

| 痛点 | 表现 | 技术挑战 |
|------|------|---------|
| 反光与特征模糊 | 蘑菇表面高光镜面反射 | 边缘特征模糊 |
| 密集遮挡粘连 | 传送带上蘑菇堆叠 | 实例边界黏连 |
| 切割点定义模糊 | 菌盖/菌柄交界渐变 | 非结构化形变 |
| 多品种差异 | 香菇vs平菇形态不同 | 需差异化策略 |

### 科学问题

**如何从反光、遮挡且形态各异的2D/2.5D图像中，鲁棒地提取实例轮廓与内部结构语义，进而高精度解算出具有明确物理意义的切割位姿（坐标+角度）？**

## 1.4 注意力机制

### CBAM (ECCV 2018)

**原理**: 通道注意力 → 空间注意力，依次增强特征

```python
# 通道注意力
Mc(F) = σ(MLP(AvgPool(F)) + MLP(MaxPool(F)))

# 空间注意力  
Ms(F') = σ(Conv7×7([AvgPool(F'); MaxPool(F')]))
```

**集成位置**: C2f模块最后一个残差块之后

**抗反光机理**:
- 通道注意力：增强弱纹理通道，抑制高光通道
- 空间注意力：聚焦交界区域，抑制反射区域

### SimAM (ECCV 2020)

**特点**: 无参数，通过能量函数计算神经元重要性

```python
# 能量函数
y = x_minus_mu_sq / (4 * (sum/n + λ)) + 0.5
att = sigmoid(y)
output = x * att
```

### 对比

| 特性 | CBAM | SimAM |
|------|------|-------|
| 参数量 | 有 | 无 |
| 计算开销 | 中等 | 极低 |
| 适用场景 | GPU | 边缘设备 |
| 抗反光效果 | 强 | 中等 |

## 1.5 可变形卷积与损失函数

### DCNv2/v3

**原理**: 学习偏移量，使卷积核自适应调整形状

```
标准卷积: y(p) = Σ w_k · x(p + p_k)
可变形卷积: y(p) = Σ w_k · x(p + p_k + Δp_k) · Δm_k
```

**集成位置**: Neck部分C2f模块

**抗遮挡机理**: 自适应跳过遮挡区域，捕捉不规则边界

### SIoU Loss

**优势**: 引入向量角度概念，收敛速度+30%，定位精度+2-3%

## 1.6 多任务头设计

### 架构

```
共享Backbone
    ├── 实例分割头 → Mask（"在哪里"）
    └── Cap-Stem语义分割头 → 菌盖/菌柄标签（"怎么切"）
```

### Cap-Stem语义分割头

```python
class CapStemSegHead(nn.Module):
    def __init__(self, in_channels, num_classes=3):
        # 3类: 背景, 菌盖, 菌柄
        self.decoder = nn.Sequential(
            Conv(in_channels, 64, 3, 1),
            nn.Upsample(scale_factor=2),
            Conv(64, 32, 3, 1),
            nn.Upsample(scale_factor=2),
            Conv(32, 16, 3, 1),
        )
        self.seg_head = nn.Conv2d(16, num_classes, 1)
```

### 联合损失函数

```
L_total = L_instance + λ · L_semantic
L_semantic = Dice Loss + Focal Loss
```

**Dice+Focal应对面积失衡**: 菌盖占70-80%，菌柄占20-30%

| 5 | **petal5** | 花瓣另一尖端 | 看得到就标 |

### 雌雄花鉴别

```
雌花：底部有球形膨大（子房）→ 标注
雄花：花柄细长无膨大 → 跳过
```

### 标注流程

```
1. 画矩形框 → label: closed female / blooming female
2. 标stigma → label: stigma
3. 按顺序标petal1-5 → label: petal
4. 每朵花group_id相同
5. 每张图group_id从1重新开始
```

```json

```
