> 定稿方向（2026-06-26）：温室番茄（串/樱桃番茄）采摘视觉 —— **检测 + 实例分割 + 采摘点关键点**；分类子任务 = 外观品质（正常/裂果/畸形）或果实朝向（**不做成熟度**）。

## 一、方向定位与两篇拆分

| | 小论文 1（识别层） | 小论文 2（定位层） |
|---|---|---|
| 任务 | 番茄实例分割 + 外观品质分类（正常/裂果/畸形） | 番茄检测 + 采摘点关键点（+朝向） |
| 主网络 | 实例分割 + 分类多任务头 | 检测 + 关键点多任务（YOLO-Pose 式） |
| 核心卖点 | 遮挡鲁棒分割（amodal/形状先验）+ 细粒度外观分类 | 检测-关键点统一 + 遮挡/朝向建模 |
| 主指标 | mask mAP、分类 Acc/F1、遮挡子集掉点 | box mAP、关键点 OKS mAP、采摘点像素误差 |
| 数据 | 公开集(LaboroTomato)+自标外观类别 | 公开图像上自标采摘点/朝向 |

两篇共享同一作物、同一数据采集、同一机器人载体，但**研究问题/网络/指标完全不同**，不构成自我抄袭。

## 四、算法改进"菜单"（维度4：架构怎么设计，避免增量）

按"主创新挑 1 个做深 + 次要点 1–2 个搭配"组织，别堆浅改动。

### 小论文 1（实例分割 + 外观分类）可选主创新
1. **遮挡 amodal 补全分割**：在实例分割基础上预测被遮挡的完整掩码（借鉴 CGA-ASNet [C2]、形状先验 [C3]）。番茄重叠/叶遮严重，审稿人买账。
2. **检测-分割-分类统一多任务头**：单模型同时出掩码 + 外观类别（正常/裂果/畸形），共享特征、设计任务平衡损失。
3. **裂果/畸形细粒度分类**（文献稀缺子项）：引入对称性/几何特征（借鉴 [D1] 草莓畸形对称性量化）做番茄畸形量化。

可搭配的次要模块（消融用，别当主卖点）：
- 小目标分支 P2/4（樱桃番茄小）；C2PSA/注意力增强全局上下文；轻量化（C3Ghost/SCDown）做速度-精度 Pareto（参考 S-YOLO [A3]）。

### 小论文 2（检测 + 采摘点关键点）可选主创新
1. **检测 + 关键点多任务（YOLO-Pose 式）**：果实框 + 采摘点关键点联合预测，端到端，避免两阶段误差传导。
2. **遮挡/朝向感知关键点**：引入可见性建模 + 朝向分类头（借鉴 Hu 2024 [B5]），提升被遮采摘点稳定性。
3. **关键点表征改进**：热图 + soft-argmax / DSNT 亚像素回归，替代直接坐标回归（更稳）。

可搭配：细长果柄方向场表征；2D 关键点 + 单目深度估计粗略 3D（不强求点云，降低门槛）。

> 注：你横向课题已积累"YOLO 实例分割 + ROI 热力图关键点 + soft-argmax + 蒸馏"的工程经验，这套**方法学可直接迁移到番茄**（换数据与任务定义即可），上手快。

## 五、实验与消融计划（论文骨架）

**小论文 1**
- 数据：LaboroTomato(分割) + 自标外观类别；划分含"遮挡子集"专门评测。
- 对照：Mask R-CNN / YOLOv8-seg / YOLO11-seg baseline → +你的主创新 → +次要模块。
- 指标：mask mAP50、mAP50-95；外观分类 Acc/F1；**遮挡子集 vs 全集掉点幅度**（突出抗遮挡）；参数量/FPS。
- 消融：amodal 头有无、多任务损失权重、注意力/P2 分支、轻量化档位。

**小论文 2**
- 数据：公开番茄图像上自标采摘点关键点 + 朝向。
- 对照：两阶段(检测→关键点) vs 端到端多任务；坐标回归 vs 热图 soft-argmax。
- 指标：box mAP、关键点 OKS mAP50/50-95、采摘点像素误差(均值/中位)、朝向分类 Acc；FPS。
- 消融：可见性建模、朝向头、关键点表征、不同 sigma 下 OKS 敏感性。

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| 被审稿人判"YOLO 增量改进" | 主创新落在 amodal 遮挡 / 统一多任务 / 裂果畸形稀缺子项，并设遮挡子集等针对性实验 |
| 自标数据量/泛化被质疑 | 公开集打底 + 市场补拍 + 数据增广；报告跨来源验证 |
| 采摘点关键点无公开标注 | 在公开图像上自标（无需进场）；把"自建采摘点标注集"作为贡献点之一 |
| 番茄方向已较热（成熟度刷点拥挤） | 明确**放弃成熟度**，转向遮挡/采摘点/畸形等未饱和子问题 |
