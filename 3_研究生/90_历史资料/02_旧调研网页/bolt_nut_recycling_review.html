废弃螺栓螺母收集分类视觉课题调研

面向工厂废弃紧固件回收的视觉课题。推荐把任务定义为“大类检测 + 实例分割 + 标定尺寸测量 + 规格判定”，核心输出包括螺栓/螺母/垫圈/螺钉类别、直径或孔径、长度、是否可回收分拣。

1. 课题意义

这个课题有工程意义，但论文表述要避免只写“垃圾分类”。它更准确地属于工业废弃紧固件的视觉分拣与尺寸测量。工业级废弃物视觉分类综述指出，低成本 RGB 传感器结合深度学习有潜力支撑可扩展的材料分类和分拣。Nuts&bolts: YOLO-v5 and image processing已经证明 YOLO 检测加图像处理可用于紧固件识别和空间尺寸估计。

实用价值：工厂废弃件往往混有螺栓、螺母、垫圈、螺钉、破损件和非目标金属。人工分类受经验、疲劳和安全风险影响。视觉系统能把“能不能回收、分到哪一类、规格是多少”变成稳定输出。

2. 任务是否可做

可做，但必须控制场景。RGB 单相机可以完成平面输送线上的大类检测和直径估计；若零件严重堆叠、竖立、互相遮挡，二维视觉很难保证毫米级测量。论文里应把应用边界写清楚：经振动盘或输送带初步摊平后的废弃紧固件。

输出二维 RGB 是否可行实现方式
大类检测可行YOLOv8/YOLO11 检测或实例分割
螺母孔径 / 外接尺寸可行，需标定分割内孔和外轮廓，像素到毫米换算
螺栓杆径和长度可行，需零件平放旋转框、骨架线、边缘拟合
螺纹牙距较难，但可作为加分项侧视图或高分辨率局部边缘分析
材质/合金类别RGB 不稳需要光谱、磁性、重量或人工规则辅助

3. 已有研究支撑

文献已有成果对本课题启发
Nuts&bolts: YOLO-v5 and image processing based component identification 利用 YOLO-v5 按头部和侧向形状识别航空装配紧固件，并估计空间尺寸和螺距。 这是本课题最直接支撑：检测负责类别，传统视觉负责尺寸。
Image-based detection and classification of screws and nuts using YOLOv4 使用 MVTec Screws 数据集做螺钉、螺母检测分类，包含长度、宽度、直径、颜色和头部差异。 说明细粒度紧固件分类有数据和方法基础。
Machine Vision for Sorting 比较 YOLO、SSD、Faster R-CNN 分拣螺母、螺栓、螺钉、垫圈和轴承，YOLO 更适合实时任务。 你的 baseline 可以照此设置。
Computer vision algorithms for measurement and inspection of screw threads 提出视觉系统测量螺纹多项特征，可标定为公制和英制单位。 支撑“尺寸测量”不是主观设想。
A cost-effective method for automatically measuring mechanical parts 面向机械零件的低成本平面尺寸自动测量。 支撑用单相机和标定板进行低成本尺寸估计。
Machine vision system for damage detection in M12, M14, M16 hexagon nuts 使用 OpenCV、PLC 和摄像头对六角螺母规格和损伤进行分拣。 支撑 M 规格判定和工业分拣链路。

4. 最推荐的小论文题目

推荐题目：面向工业废弃紧固件回收的轻量化检测分割与尺寸判定方法

不要拆成“大类检测”和“直径判定”两篇。检测一篇不够，直径测量单独一篇又像工程项目。最稳是合成一篇：检测分类解决“是什么”，实例分割解决“在哪里”，尺寸测量解决“规格是多少”，拒识机制解决“重叠或不可测”。

5. Baseline 和网络创新

主 baseline：YOLOv8n-seg 或 YOLO11n-seg。相比纯检测，实例分割能提供更稳定的外轮廓和内孔区域，便于计算直径。Mask R-CNN 可作为经典对照，EfficientDet/BiFPN 可支撑多尺度特征设计。

模块解决问题创新写法
Rotated/Oriented box head螺栓、螺钉细长，普通水平框包含大量背景方向归一化后再测长度和直径
Instance mask + hole mask螺母需要区分外轮廓和内孔螺母双轮廓约束，输出外接尺寸、内孔直径、对边距
Dimension head像素分类不能直接给规格增加直径/长度回归头，和传统几何测量做融合
Calibration-aware loss论文要体现机械专业优势像素误差换算为毫米误差，优化 MAE(mm)
Overlap reject堆叠零件不能准确测量输出可测/不可测，保证分拣可靠性

6. 数据采集与标注

这个课题数据最容易自己做，不建议买数据后写“自采”。可以买废旧螺栓螺母作为实物，然后自己拍摄，这样论文中“自采数据集”是成立的。若购买的是别人已经拍好的图片数据，则不能写成自采，只能写“公开/委托数据”。

采集项建议标注
零件类别螺栓、螺母、垫圈、螺钉、破损件、其他金属class、bbox、mask
规格M3、M4、M5、M6、M8、M10、M12，先选 5-7 类直径值、规格标签、长度值
姿态平放、旋转、轻微重叠、油污、锈蚀方向角、遮挡等级、可测性
标定每批图像放标尺或棋盘格，固定相机高度像素/mm 比例、相机编号
快速方案：用俯视相机 + 黑色哑光背景 + 环形/漫反射光源 + 标尺板。每个规格用游标卡尺测 20-30 个样本作为真实值。先做单层摊平场景，重叠场景作为鲁棒性测试和拒识实验。

7. 难点与解决方法

痛点原因方法评价指标
规格差异小M6/M8 这类差异在图像中可能只有少量像素高分辨率拍摄、标定、局部 ROI 超分辨率或边缘拟合直径 MAE、规格分类准确率
金属反光高光会破坏边缘和内孔分割偏振片、漫反射光、曝光锁定、HSV/灰度增强强反光分组 AP 和 MAE
堆叠遮挡重叠后真实边界不可见，尺寸不可测实例分割 + 遮挡等级 + 不可测拒识拒识后测量合格率
脏污锈蚀废弃件外观变化大锈蚀增强、颜色归一化、跨域测试新批次泛化 mAP
二维缺少厚度单相机无法知道高度和材质论文边界限定为平面几何规格；厚度/材质作为未来工作明确任务边界

9. 最终总结

该课题适合机械专业学生快速做出“视觉 + 工业测量”的论文。整体架构是：用目标检测解决大类识别，用实例分割解决零件轮廓和内孔，用相机标定解决像素到毫米转换，用几何测量和尺寸回归解决直径/长度判定，用拒识机制处理重叠、反光和不可测目标。最终目标是让系统输出是什么零件、规格是多少、该分到哪个回收盒。
