# 001 YOLO11n-seg 基线结果分析与改进方向

> 本文档针对 `1_results/001_yolo11n_seg_AdamW/` 这次基线结果，结合**前向传播 vs 标签审计**的实测误差，给出后续改进方向。
> 日期：2026-07-12 ｜ 研究决策以 `3_研究生/柑橘套袋视觉_完整研究执行计划.md` 为准；本文只保留 001 的预实验误差证据。

---

## 1. 基线配置与结果

- **模型**：`0_orange_yaml/001_yolo11-seg.yaml`（**原版 YOLO11n-seg**，无架构改动，nano）
- **数据**：`200orange_wuxi_seg.yaml` → `data/test`（941 张：train 659 / val 188 / test 94，单类 `orange_immature`）
- **训练**：AdamW，300 轮跑满，imgsz 640，batch 4，lr0 0.001，seed 42

**验证集指标（best @ epoch 240）**：

| | Precision | **Recall** | mAP50 | mAP50-95 |
|---|---|---|---|---|
| Box | 0.914 | **0.737** | 0.822 | 0.671 |
| Mask | 0.900 | **0.737** | 0.814 | **0.644** |

**一句话诊断**：**高精度、低召回**（P≈0.90 / R≈0.74）——模型很保守，报出来的基本对，但**漏掉约 26% 的果**；且 mask 从 mAP50(0.81)→mAP50-95(0.64) **掉 0.17**，说明**掩膜边界质量一般**。训练已收敛（best@240，最后 60 轮 recall 反而略降 0.737→0.718，轻微过拟合），召回天花板卡在 ~0.74。

## 2. 前向传播 vs 标签审计（回应"漏标"怀疑）

用 `vis_pred_vs_gt.py` 在 **val 集最密集的 12 张**上跑 best.pt（conf 0.25），逐张对比 GT(绿) / 预测(红) / 疑似漏标(黄)：

**总计：GT=220，预测=156，疑似漏标=11，漏检(GT无预测)=76**

### 结论（明确回答你的怀疑）

1. **漏标确实存在，但是次要问题**：只有 11 个模型可见的漏标候选，集中在少数图（`IMG_20260706_105159` 一张就占 5 个——模型检出了 5 个没标的果，从对比图看确有真果未标）。**建议人工复查这几张**：`IMG_20260706_105159`(5)、`IMG20231120161107_BURST006`(2)、`IMG20231120161204` / `IMG20231120161728` / `IMG_20260706_105119` / `IMG_20260706_104206`(各1)。
   - ⚠️ 注意：模型是在这批标签上训练的，会**继承标注盲区**——它也学会忽略你漏标的果。所以"模型可见的漏标"是**下限**，真实漏标可能更多（尤其小/重遮挡果）。若要彻底排查，需人工过一遍或用更低 conf 再扫。

2. **真正的主要矛盾是"漏检"（低召回）**：模型漏掉 **76/220 = 34%** 的已标注果。两大驱动：
   - **① 小目标 / 宽景图（最狠）**：`IMG_20260706_105149`（GT=23 只预测 8，漏 15）、`IMG_20260706_105623`（GT=22 只预测 4，漏 17）都是**宽景 + 果实极小**的图，640 下小果只有几像素，模型只抓住中间一簇、其余全漏。
   - **② 同色哑光果**：哑光深绿批次（颜色线索弱、纹理更重要）漏检明显高于光泽黄批次，支持进一步量化果实与局部背景的颜色/纹理相似度。

> 一句话：**你怀疑的漏标是有的（次要），但这次基线暴露出的头号问题是"小 + 同色果的漏检"**——而这恰恰是你论文创新点要打的靶心，是好消息。

## 3. 修订后的结论

001 的 34% 漏检率来自“验证集中最密集的 12 张图”这一难例子集，不能替代全验证集 Recall 0.737。论文中必须明确统计范围。

当前 train/val/test 存在同一连拍序列跨集合的问题，因此 001 不能直接作为论文最终 E0。下一步先完成 group-aware 数据划分，再按统一协议重跑 YOLO11n-Seg。

方法路线以主计划为准：

1. 用轻量频率纹理块 CFTB 保留浅层小目标纹理；
2. 用 CABI Loss 强化高伪装和相邻粘连边界；
3. 在 small、dense、adhesion、high-camouflage 和跨批次子集上验证；
4. 不再采用 P2、SFM、注意力简单堆叠作为主创新；
5. 验证集用于模型选择，测试集仅在方法冻结后评测。
