## 一、基准说明与统计口径

1. **权威数据来源**：全部指标提取自每个实验目录下的 `results.csv` 与 `args.yaml`；主指标统一取各模型在验证集上 **Mask mAP50-95 达到最高峰值** 所在 Epoch 的同轮完整指标（包含 Box 与 Mask 的 Precision, Recall, mAP50, mAP50-95）。
2. **基线参照标准**：
   * **YOLO11n-seg** (`001_3_yolo11-seg_adamw`)
   * **复杂度**：Params = **2.843M**, GFLOPs = **10.36G** (输入 640×640)
   * **Box 指标**：Precision = 0.9130, Recall = 0.7054, mAP50 = 0.7944, mAP50-95 = 0.6402
   * **Mask 指标**：Precision = 0.9218, Recall = 0.7016, mAP50 = 0.7864, mAP50-95 = **0.6208** (0.62076)
3. **训练参数**：统一 300 轮训练，输入尺寸 640×640，优化器 AdamW，学习率 lr0=0.001。

## 四、核心机理解析与论文收敛建议

### 1. 为什么这些改进能够带来突破性提升？
1. **大核分离卷积池化（F14 SPPF-LSKA，+5.52 pt）**：
   柑橘树冠中，果实可见区域常被细长树枝与叶片切割成**深凹形或断裂多连通域**。传统对称池化核（如 5×5、9×9）难以关联被遮挡的远端区域；而 LSKA 的水平与垂直条带大核感受野天然适配条带状遮挡，将断裂区域作为同一果实完整提取。
2. **内容自适应上采样（F17 CARAFE，+5.09 pt）**：
   传统插值在幼果模糊边缘易产生伪影；CARAFE 根据局部特征内容动态生成重组核，精细重构高频边界，显著拉升严格 IoU 下的 Mask mAP。
3. **轻量局部卷积与专家路由（F05 FasterNet / F64 MoCE，+4.83 ~ +5.10 pt）**：
   部分卷积（PConv）剔除冗余通道计算，MoCE 动态分流不同尺度的复杂特征，**在 2.67M~2.70M 参数下实现大幅涨点，完全避免了过拟合**。

---

### 2. 为什么多模块全家桶与 Full 策略会严重掉点？
1. **Full 策略的多损失目标梯度冲突**：
   同时施加 NWD、Copy-Paste(0.3)、Dice(0.5)、Boundary Loss(0.2) 和 Freq Loss(0.1)，导致在 941 张图像的小样本数据集上梯度相互抵消。后续研究应保持 Baseline 训练协议，对单个损失做单变量消融。
2. **全家桶堆叠的优化困难**：
   SXQNet-V1 与 F53 堆叠了过多特征增强与注意力机制，导致浅层特征被反复扭曲，梯度反向传播路径恶化。

---

### 3. 硕士论文最终收敛与推荐方案
* **首选主线模型（精度与轻量化兼备）**：`F14 SPPF-LSKA`（3.12M / 10.58G，Mask mAP 0.67599）与 `F64 C3k2-MoCE`（2.67M / 10.03G，Mask mAP 0.67178）。
* **高召回候选网络**：`G10 Hybrid (Baseline策略)`（Mask mAP 0.67681，Mask Recall 0.7675）。
* **端侧极速部署候选**：`F45 Edge-Nano`（1.42M 参数）与 `F04 HWDown`（2.58M / 9.70G）。
