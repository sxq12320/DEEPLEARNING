## 2. 建议 1 核对：PR 骤降与数据增强

### 2.1 PR 曲线观察（G00，`MaskPR_curve.png`）

- P≈1.0 维持到 R≈0.65；R∈[0.65, 0.88] 持续长下坡；R≈0.88 之后垂直贴地。
- results.png：recall 在约 epoch 75 后平顶在 ~0.75，precision ~0.93 但逐 epoch 抖动剧烈（val 仅 193 图，单个 FP 即显著摆动）；val loss 无上升——**收敛受限是能力/数据上限，不是过拟合**。

### 2.2 骤降的三层机理（缺一不可）

1. **画图约定伪影**：`ultralytics/utils/metrics.py::compute_ap` 在最大观测召回处追加 precision=0 并补到 R=1，曲线末端的垂直落零部分是 AP 积分端点处理，不代表某阈值让预测全部出错（E_V10 评审已记录）。汇报时建议展示 `citrus_pr_diagnostics.py` 导出的不补零诊断曲线。
2. **真实召回天花板**：conf→0 时最大召回整图 **0.898**、细切片+trusted-mask 融合 **0.957**。约一成实例在任何置信度下都不可达。
3. **低置信度背景 FP 涌入**（曲线中段下滑的真因）：conf=.25、IoU=.5 时整图漏检 211/1049，其中 **tiny FN=126（≈60%）**；切片评估把 tiny FN 降到 61，但背景 FP 由 136 → 369。即"为多召回而降阈值"的代价是误检——PR 中段下滑正是这个交换过程。

### 2.3 增强方向：对，但要对准漏检画像

已被内部验证保留的：copy_paste=0.3（V8_02=71.58、V8_03 几何+CP=71.80 为 V8 最高；V9 除对照组外全员 cp=0.3）。

可继续做的单变量消融（当前 G00 配置 copy_paste=0、mixup=0、multi_scale=0、scale=0.5、erasing=0.4、mosaic=1.0）：

| 候选改动 | 理由 | 风险 |
|---------|------|------|
| `scale` 收紧下限 / 贴入目标最小像素保护 | ±50% 缩放会把 <16px 目标压没，人为制造不可学样本 | 尺度多样性下降 |
| `erasing` 0.4→0 消融 | 随机擦除对小目标可能是纯伤害 | 无 |
| `multi_scale=0.5` | 覆盖单图尺度比（中位 2.7 / P90 7.7） | 显存/时延 |
| `mixup` 小概率 | 背景-果实混合先验 | 掩膜边界噪声 |
| 切片样本进训练（SAHI fine-tune 思路） | E 系列"切片混合输入"已是雏形；SAHI 文献：仅切片推理 +5~7 AP，+切片微调累计 +12~14 AP | 需统一评估口径 |

**结论**：同意师兄。增强应明确针对"tiny 目标存活率"而非泛化增强；同时必须配 FP 抑制手段（见 §4），否则 PR 中段不会抬。

## 3. 建议 2 核对：P2 层与蒸馏

### 3.1 内部证据

- V7_01_p2 = 71.13 vs 同系控制 70.86（+0.26，温和正收益）。
- G 系列 p2b 为旧数据冠军（67.68），T02 同协议复测 67.12——优势缩水但未归零。
- V9/V10 已定调：**不新增稠密 P2 检测塔**（保住 8400 候选@640 与 FLOPs），改为 (a) P2 细节特征进掩膜解码路；(b) V10 假设 3：**仅训练期存在的 P2 前景辅助分支**，从可见掩膜直接构造监督，不依赖 TAL 先分配——这正是"训练加 P2、推理去掉"的零成本版本。

### 3.2 文献蒸馏方案（供选型）

| 方案 | 出处 | 内容 | 与本课题契合点 |
|------|------|------|---------------|
| 训练期辅助头（aux head） | YOLOv7 aux / YOLOv10·26 one-to-many 头 | 训练时多头富监督，`fuse()` 后删除，零推理开销 | V10 aux P2 已走此模式；最便宜的"蒸馏" |
| **FGD** Focal+Global Distillation | TPAMI'23（arXiv:2111.11837），+3~4 mAP | 前景/背景分离蒸馏 + 全局关系 | 正对"低阈值背景 FP"痛点 |
| **CWD** 通道级蒸馏 | ICCV'21（arXiv:2011.13256），+5.8 mIoU | 通道维 KL 对齐，稠密预测专用 | 适合 proto/mask 分支 |
| **MasKD** | CVPR'22（arXiv:2205.14589） | 可学习 receptive token 定位关键像素 | 小目标友好 |
| **MGD** | ECCV'22 | 掩码生成式特征蒸馏 | 检测/分割通用 |
| **LD** 定位蒸馏 | CVPR'22 | 蒸馏 DFL 框分布 | 保定位、小目标框回归 |
| **EFPN+FTT** | — | 超高分辨率 P2 级 + 跨分辨率特征蒸馏 | "P2 教师→浅层学生"的直接先例 |
| 通道变换蒸馏 | arXiv:2303.13212 | Mask R-CNN +2.8 mask mAP | 实例分割实证 |

### 3.3 推荐路线（成本递增）

1. **先做免费版**：V10 训练期 P2 前景辅助（已在设计内，零推理成本，直接监督"没被 TAL 分配的 GT"）。
2. **再上真蒸馏**：teacher = V9_05 + P2 头 + 切片微调（容量拉满，整图+切片双模式）；student = T05 lite 头路线。损失组合：FGD（颈部 P3/P4/P5 特征）+ CWD（proto/mask 通道）+ LD（DFL 分布）+ 质量分数 KL。工程量中等：需在 fork 加 teacher 前向与多层对齐损失。

## 4. 建议 3 核对：主攻召回

### 4.1 现状数字（证据充分）

- 全部 70+ 个有效 run：P≈0.90–0.95，R≈0.70–0.77，P-R 缺口约 15pt。
- V9 审计（conf=.25, IoU=.5, 统一 640 栅格）：漏检中 **tiny 占 60%**；切片后 tiny FN 减半但背景 FP 翻倍。
- R90（P≥90% 处召回）≈ 80.6；最大召回 0.898（整图）/ 0.957（切片）。

### 4.2 抓手排序（按本课题证据强弱）

| 序 | 抓手 | 内部证据 | 代价 |
|---|------|---------|------|
| 1 | 切片推理常态化 + 切片微调 | 细切片 +9~10 AP（最大单项） | 时延 329→448ms；背景 FP 翻倍 → 须配 §4.2-5 |
| 2 | 分配器覆盖 tiny GT | `--tal-min-pos`/GA-TAL 已在 fork；NWD-RKA 文献 AI-TOD +4.3 AP | 小 |
| 3 | NWD 小目标回归 | loss.py 已实现 32px 门控 blend；V6_05 fine_nwd=71.18 | 已就绪 |
| 4 | 训练期辅助监督兜未分配 GT | V10 假设 3 | 仅训练期 |
| 5 | 低分 FP 抑制：背景质量分支 | V9_07=71.74，背景 FP 326 为系列最低 | 小 |

### 4.3 汇报口径建议

单报一个 R 说服力弱。建议结果表加列：**R@P90（P≥90% 处召回）、max recall、tiny 检出率（/161）、APs/APm/APl、背景 FP 数**。

## 6. 建议 5 核对：改结构/损失 vs 改模块

同意，用本课题数据精确定义"结构"：

| 改动类型 | 本课题证据 | 判断 |
|---------|-----------|------|
| 即插即用模块（注意力/换 block） | F 系列 30+ 变体旧数据 +0.5~1.5；T 系列同协议复测几乎全部归零（T02/T03/T08 被 T04/G00 支配） | 增益多不稳健，最低优先级 |
| **信息流结构**（分辨率/路由/头部配置） | V6 细 GT 栅格 + 细原型：AP ~67.7 → 70~71.4（+2~3，单代最大跳变）；V9 掩膜专用颈；V10 细节传输 | 真正有效的"结构"= 分辨率与路由分配 |
| **损失/监督** | 几何约束、tiny dice、背景质量、NWD：单项 +0.1~0.5，稳定正向可叠加，直接作用于错例类型 | 主线之一 |
| 输入/评估分辨率 | 细切片 +9~10 AP | 单项最大 |

精确表述：**收益排序 = 输入/掩膜栅格分辨率 > 监督覆盖与分配（损失、assigner、辅助头）> 特征路由结构 > 即插即用模块**。

论文叙事建议：主打"极端尺度跨度 + 绿上绿低对比 + 条状遮挡深凹"三痛点的量化与针对性设计，比"加了个注意力"更像论文。
