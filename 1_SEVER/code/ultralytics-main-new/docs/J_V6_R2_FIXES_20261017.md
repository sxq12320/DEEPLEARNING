## 已修复的确定问题

| 问题 | 修订 | 证据边界 |
|---|---|---|
| 可见点被当作bbox中心 | 存在性cell仍由可见点分配，offset改为GT框中心相对cell的无界偏移 | 凹形合成反例旧解码IoU约0.404；新合同精确round-trip，不代表真实AP变化 |
| 小框训练/解码尺寸不一致 | 删除至少一scout cell的尺寸下限，两端统一normalized最小宽高1e-5 | 小于下限仍截断，不称任意尺度无损 |
| collision迁格后相邻正格互删 | 删除3×3局部峰值硬门，改存在性阈值＋稳定cell topK | 相邻不同分数正格可达；可能引入更多重复/FP，需正式比较 |
| source1输入与推理语义不同 | 新候选训练coeff=0，score取对应assigned scout cell概率 | GT扩框训练域与预测框推理域差仍存在 |
| gain采样位置/基准不一致 | 只监督有对应cell的source1，在该cell读取gain，基准是零logit | 在线同样本Brier代理，不是相对global收益、VOI或AP保证 |
| 旧权重同shape静默加载 | train/resume/val/predict、直接后处理及YOLO.load检查三项持久语义标记 | 不可手动补标记伪装兼容；旧J90全局控制可独立验证 |

未分配cell的source1局部mask/quality/identity/gain监督按unknown处理；原global检测和分割监督仍保留。标注外负监督遵循普通完整标注假设，并未新增抗漏标学习。
