# J_V2 深化重审：从信息、表达、监督和执行预算入手

审查开始：2026-10-03；补充截至2026-10-04。研究对象是RGB未成熟柑橘的**可见实例**，不是补全被叶枝遮挡的完整果形。
本文件把代码事实、数学性质、历史观察、未验证假设分开。不存在“数学已证明模型会涨点”的结论。

## 一、首先承认先前推理不足的地方

原方案从“目标小”直接跳到P2，从“颜色近”直接跳到局部对比，
从“参数少”直接跳到共享塔与窄原型。它们是可测试的启发，不是充分因果解释。
深化审查发现两个确定缺陷，以及三个尚未证明的风险：

| 性质 | 证据 | 处理 |
|---|---|---|
| 确定表达限制 | J36 nearest×2后仅1×1，任意系数的2×2原型logits相同 | 新J41/J44解码器单项修复，保留旧图 |
| 确定成本归因错误 | loss和EV6先把proto放大到GT input/2 | 改正成本文档，验证方法不变 |
| 分配混杂 | 加P2也让TAL最小资格窗口16→8px，topk仍10 | 不声称四倍正样本；先记录增强/分配 |
| 头部混杂 | 共享尺度卷积同时合并三任务塔、回归隐宽64→32 | 只称整体窄头，不能独立归因共享 |
| 识别与排序风险 | 高频也增强叶脉；class分数不等于mask质量，box NMS先于mask | 用叶片FP与阶段漏检诊断，不保证颜色混淆已解决 |

历史索引覆盖311 CSV/297去重运行/485当前YAML，但不是每个历史训练Git版本的逐行复核。
J00/J01同组scratch结果只支持约0.967点mask AP50–95差，且P下降；J02–J10组合/压缩未追回容量。
同权重global/fine证据支持整条切片管线有收益，但约3倍耗时。不可把不同初始化、划分、验证栅格的峰值混排。

## 二、从本质拆解：五种瓶颈不能由同一个模块解释

### 1. 输入中是否还有可辨别证据？

设原图为I、缩小输入X=D(I)、目标Y。若Z=T(X)是灰度或梯度，

\[
\mathcal I(Y;[X,T(X)])=\mathcal I(Y;X)\le\mathcal I(Y;I).
\]

灰度不增加来自相同RGB的新观测；它可以改变有限网络的归纳偏置。
平均池化把两种相反2×2棋盘都映射为0.5，是不能由后级确定变换区分的反例。
但不能外推成“所有stride卷积必丢相位”：足够通道的滤波器组可编码子像素相位。
因此先区分原图缩放的信息问题与当前解码器利用保留信息的问题。

**数据所要求的顺序**：先在train/val记录global/coarse/fine及增强后的实例存活、可见面积、短边与mask栅格存活，
再决定输入预算。静态GT有候选中心，不等于增强后还存在有效监督。test留作冻结终评，不用来设计方法。

### 2. 候选与分配是否让小果得到有效学习？

固定全部匹配规则，为GT建立累计条件的嵌套集合G0⊇G1⊇G2⊇G3⊇G4，
分别为总GT、粗空间资格候选、排序保留、几何可匹配、最终一对一TP。每阶段追踪同一个候选见证。

\[
R=\frac{|G_4|}{|G_0|}
=\frac{|G_1|}{|G_0|}\frac{|G_2|}{|G_1|}
 \frac{|G_3|}{|G_2|}\frac{|G_4|}{|G_3|}.
\]

这是计数链式恒等式，**不假设独立**；中间集合为空时报告计数和R=0，不计算未定义比率。
增加候选不保证R增长：一个更高分、同框、低mask IoU的叶片候选，可以在box NMS中删除原来的正确果候选。
现有TAL的box质量也不等于mask质量；tiny Dice只作用于已分配实例，不能监督零正样本果。

[QueryDet原文Table3](https://arxiv.org/pdf/2103.09136)的纯高分辨率消融AP 37.46→36.10、APs 22.64→21.94，
修正监督分布后才改善。它反证“只加P2充分解决小目标”，不是预测我们的柑橘分数。
当前P2网格位置33600相对原8400为四倍；资格窗口和topk机制使监督数不按这个比例增加。

### 3. 找到果后，掩膜是否能够表达真实可见形状？

共享原型装配为L=CP，未裁剪logit秩≤K；不能据此说K=32最多分32个实例，
因为实例crop和二值化不服从相同秩约束。
更直接的旧J36限制是：

\[
P_{c,2i+a,2j+b}=w_c^\top z_{i,j}+b_c,\quad a,b\in\{0,1\}.
\]

四个相位相同，与系数数量、tiny loss无关。实际模块测试最大块内差严格为0。
在固定ROI包含完整块的局部反例中，一个前景像素和三个背景像素无法由该块的共同阈值分开。
这不是所有真实果实的IoU上界：box裁剪和块间双线性插值仍会产生边界。

J41/J44改为低栅格h→4K逐点卷积，再PixelShuffle：

\[
P_{c,2i+a,2j+b}=w_{c,a,b}^{\top}z_{i,j}+b_{c,a,b}.
\]

初始化四相位重复旧权重与bias，因而初始函数相同；训练时参数独立。
取四bias为[1,−1,−1,−1]可构成旧模型不能表达的局部模式，只证明表达空间扩展。
初始化依据[ESPCN，CVPR2016](https://www.cv-foundation.org/openaccess/content_cvpr_2016/html/Shi_Real-Time_Single_Image_CVPR_2016_paper.html)
和[ICNR初始化研究](https://arxiv.org/abs/1707.02937)，不是新的超分辨率发明。
ICNR式重复只避免初始相位差异，不能保证训练后无棋盘伪影；新增相位也不创造丢失的RGB信息。

遮挡叶枝使可见mask深凹；接触果要求保留小间隙。补圆、凸包、统一连通约束会与真实标签冲突。
[PointRend](https://arxiv.org/abs/1912.08193)进一步提醒：同点边缘必须结合实例条件，
共享边缘本身不能判定属于哪一个果。若原型仍不足，下一步应检验低成本实例条件细化，不再盲目增加注意力。

### 4. 为什么薄、小、遮挡会同时伤AP和R？

令真值/预测区域面积为A/B，对称差e=|G△M|，则精确地：

\[
\operatorname{IoU}=\frac{A+B-e}{A+B+e},\qquad
\operatorname{IoU}\ge t\iff e\le\frac{1-t}{1+t}(A+B).
\]

相同绝对像素错误，在A+B很小时更容易越过匹配阈值，所以不只是“置信度低”，
已经检测到的候选也可能因mask IoU不足被计为漏检。
对足够光滑、无拓扑变化的边界小法向扰动δ(s)，一阶对称差近似∫|δ(s)|ds；
故可见区域周长/面积较大时误差敏感。该近似有光滑与小扰动条件，不能替代离散像素上的精确统计。
应同时报告tiny、低solidity/凸包缺损、近邻间隙和split/merge，不仅按完整果直径归类。

### 5. 低参数能否真正低延迟？

四相位修复末层：旧MAC=4HW·hK，新MAC=HW·h(4K)，卷积MAC相同；
h=K=32时全模型仅多3168参数，但布局、激活与kernel效率仍需实测。
当前mask_ratio2下，每实例重建MAC=32·320²=3,276,800；300实例约0.983G MAC，
不在常见只前向GFLOPs中完整计入。P3原型换低栅格，没有改变这个损失/验证成本项。

存在一个可严格核验的算子机会：对同样的线性插值U，C·U(P)=U(C·P)，梯度也等价。
先粗栅格合成logits再插值可减少矩阵乘法，但插值通道从K变成实例数M，可能增加读写。
sigmoid、阈值、crop必须保持在相同共同栅格之后；本轮只测试恒等式，**没有修改I系列验证器**。
未来需单列实现对照与GPU逐像素核验，不能偷换评估口径来追求速度。

## 三、颜色混淆不能用一个高通“证明解决”

D=I−A抵消常量偏置，但叶脉、光斑和果边都不是DC。5×5平均的频率响应可为−1/4，
相应D响应1.25；取允许的残差gain=.2、Q=identity，白噪声方差成为1.4224倍。
因此“边缘更亮”不等于果叶更可分。RGB主路保留，局部对比只能是可撤回实验项。

零初始化有界gain也不是稳定性或保真定理。投影可任意放大，语义与细节可能相消，refine没有范数界。
只有另外证明Lip(h)<1等条件，才能对x+h(x)给出双Lipschitz距离界；当前网络不满足已验证的这些前提。
不能把单次前馈冠名闭环控制或宣称控制原理证明收敛。

人工叶片误报复核、低对比真果子集与同候选预算对照才是颜色混淆的证据。
单类混淆矩阵“背景”不自动等于叶片；先建立小规模验证难例标记，避免凭图感受判断。

## 四、PR要修漏检机制，不修绘图端点

横轴是Recall，不是置信度。AP积分的零端点包括不可达召回段；本轮不修改compute_ap。
当前实际代码在最后观察到的Rmax处再次加入precision=0，再加入(1,0)；
所以即使所有已输出预测的观察precision都是1，只要Rmax<1，图也可以突然归零。
已用实际compute_ap的合成反例测试，而不是只看截图猜测。
2026-10-04核查的[Ultralytics上游metrics.py](https://raw.githubusercontent.com/ultralytics/ultralytics/main/ultralytics/utils/metrics.py)
也采用相同补点，不能据此认定是我们的模块造成绘图bug；上游main可变，不作为历史训练代码版本证明。
**零尾的外形是补点行为；Rmax为什么不足仍是要诊断的模型/数据/后处理问题，两者不能混为一谈。**
固定候选、几何、NMS/ties与保留集合，同一个严格单调分数变换保持排序，TP/FP序列与AP不变。
固定conf截断或跨尺度不同变换可能改变保留集合，必须另行解释。

正确目标：观察到的Rmax、R@P≥0.90、共同固定conf的P/R、tiny匹配与叶片FP。
不要求所有曲线画到R=1；“美化成正常形状”不是可用的研究目标。

## 五、修正后的最少实验，而不是再堆十个无法归因的模块

| 顺序 | 对照 | 能回答的问题 | 不能声称 |
|---|---|---|---|
| 1 | J20/J29 | 同划分、scratch、AMPFalse的官方/I20锚 | 复现旧服务器不同协议峰值 |
| 2 | J36/J41 | 同来源/stride的原型复制限制修复 | 同训练轨迹；AP必涨 |
| 3 | J41/J42 | P2来源+stride2输出联合收益与成本 | 纯stride消融 |
| 4 | J42/J43 | 主干—颈部通道预算压缩代价 | 只改主干、GPU一定更快 |
| 后续 | J38/J44，J34/J35/J36 | 窄图解码修复；loss/对比逐项归因 | 组合优势全部属于某一个模块 |

初始函数相同不代表优化轨迹相同：旧末层梯度累加四相位，新末层分别更新。
保留统一AdamW/学习率，不额外用不同优化器偷偷补偿；若改训练参数必须编号并单列实验。
共享三任务的冲突仍是风险，暂不同时大改优化器、分配、decoder，否则无法解释结果。
如果候选不足，处理输入/分配；候选存在但mask不足，处理表达；好mask被抑制，处理排序/后处理。
每种方案都需要该阶段证据，不能先选热门模块再反推问题。
