## 🔍 痛点与方法取舍

tiny为共同640栅格面积<256的诊断桶，共161个；不是COCO AP_S。
下表均conf=.25、mask IoU=.5，并不代表在高精度操作点下的tiny召回。

| 模型 | 全局tiny匹配 | fine融合tiny匹配 | fine融合背景错误 |
|---|---:|---:|---:|
| 00 control | 26/161 | 89/161 | 346 |
| 02 fine | 31/161 | 93/161 | 422 |
| 06 fine+cp | 36/161 | 102/161 | 510 |
| 07 full | 31/161 | 99/161 | 399 |
| 08 phase | 34/161 | 85/161 | 388 |

1. **漏检仍未解决。** phase全局826/1049匹配，223个漏检中127个来自tiny；
   但从全局转fine融合，tiny增加51个，背景错误119→388。继续追求高召回必须同时控制误检。
2. **phase值得保留，但不是所有目标上的冠军。** 相对dense，全局严格AP略低、fine融合严格AP更高，
   fine融合tiny却少8个。选择phase作下一轮底座是精度/资源候选取舍，不是显著性或最优性结论。
3. **copy-paste有条件保留。** dense上fine融合tiny 93→102，背景422→510；
   control上则背景346→325。效果依赖底座，不能统一称“必涨”或“必增加误检”。
4. **NWD不默认叠加。** phase+nwd较phase的全局与融合严格AP都下降；dense+nwd又有部分改善。
   属混合证据，不存在已经估计出的“噪声带”，也不等于统计上证明无用。
5. **已匹配不等于边界准确。** mask_or_localization只计未达到IoU=.5匹配的预测，
   不能排除IoU=.75/.95下的边界失败；边界诊断是匹配子集上的双侧band均值，不是官方Boundary AP。
6. **背景错误不等于已确认叶片。** 绿色混淆仍是假设；需要逐例区分叶片、枝条、重复/切片残片。
   不引入强制圆形、凸包填充，保护条带遮挡产生的真实可见凹口。

PR末端补零不是目标函数。phase全局rmax=.893，仅表示conf≥.001、max_det=300和当前NMS下的上限；
不是任意阈值下永远不能检出。fine融合P≥.90的召回phase为81.506%，control为79.981%，
这比观察曲线尾部是否平滑更有部署意义。

phase有速度潜力，但这些是不同时间运行的记录；推理降幅与每轮耗时差距明显不一致，
不据此宣称保证加速。固定硬件、预热、交错重复计时后再定论；切片全过程数百毫秒也需算入部署成本。
高分辨率细节对掩膜质量有帮助这一方向有RefineMask依据，但本实现不是其多阶段ROI网络复刻。[^1]

## 🔧 本次对 V7 的实际修改

检查时发现现有V7已由其他修改切到phase底座并重排05/06；本轮保留并验证这些改动，
不是再次声称新写了一套主干。主干仍为已有EV3深层+YOLO早期结构，未借本次结果凭空重造。

新增关键修正：`EV7SegmentationLoss`只对TAL的尺度元数据排序。
检测特征顺序仍[8,16,32,4]，但小框候选扩张应读取最细4和次细8，而不是原来的8和16。
例如6px宽小框，旧路径会因小于8而扩到16；在P2路径中不应按该阈值扩张。
宽2px框按次细8扩张，不再一律16。没有变更真实GT框、回归目标、特征顺序或预训练塔索引。
历史V6与其他模型损失不变。标签分配结合分类与定位的依据来自TAL/TOOD思想；
本修复是当前接口的尺度语义纠错，不是新的TOOD算法，也不保证提升召回。[^2]

| V7模型 | 当前内容 | 要验证的作用 |
|---|---|---|
| 00 control | phase解码锚点，与V6_08同图 | 跨轮复现与统一参照 |
| 01 p2 | phase+窄P2+尺度正确的分配 | 小目标检测覆盖 |
| 02 deform | phase+16通道DCN细节采样 | 可见凹边界质量与延迟代价 |
| 03 pmce | phase+低/高频残差上下文融合 | 背景误检抑制假设 |
| 04 boundary | phase+边界/邻域联合损失 | 轮廓与邻接分离 |
| 05 cp | 与00相同网络，copy_paste=.3 | 训练增强的增益/误检代价 |
| 06 p2_pmce | phase+P2+PMCE | 检测覆盖与背景辨别组合 |
| 07 full | phase+P2+DCN+PMCE+几何 | 全组合收益是否抵过成本 |

几何最小面积仍是256输入像素，mask_ratio=2不自动放宽该门槛，不宣称它解决极小实例。
质量打分已存在，不再增加重复质量模块；NWD保持0；不换优化器以免混杂。
修正后的源码注释、协议和报告不再使用“噪声带内”“候选饥饿已排除”等无依据表述。
八份YAML保留系列目录和官方入口，新结果目录使用EV7R2，防止与昨日旧实现混跑。
