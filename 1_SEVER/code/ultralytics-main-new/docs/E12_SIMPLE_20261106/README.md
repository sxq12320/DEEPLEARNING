## 2. 切片到底有没有用

固定网络和78训练配方，切片训练相对整图训练：

| 相同验证方式 | ΔAP50 | ΔAP50–95 | ΔRecall |
|---|---:|---:|---:|
| global：单整图 | +0.772 | -0.104 | -2.560 |
| fixed_box：多视图按框合并 | -2.549 | -2.390 | +2.008 |
| crossmask：跨视图掩膜合并 | +0.449 | -1.867 | +3.835 |
| trustedmask：边界可靠性处理 | +2.613 | +3.314 | +3.146 |

结论是训练视图与后处理存在明显交互，不能简单归结为切片全正或全负。P01同权重从global到trustedmask的AP50–95为68.363→78.212，这个差值来自推理流程，不是新增网络的结构收益。模型强弱必须先在相同推理方式下比较。

旧批量入口：训练期每轮是原图EV6验证；训练后另运行整图和全图+九细切片及合并控制；仅显式开启evaluate-test时才对预设主模型评估test。现有回传全部标注val，不能当test报告。

PR横轴是Recall，不是置信度。末端归零需要区分绘图补点和实际召回上限；不能通过修改曲线或把曲线补点当实测性能解决。新实验保持原指标实现，主要比较AP和固定精度下召回，不承诺消除绘图端点。

## 3. 精简范围

恢复标准YOLO11n主干、标准PAN、标准Segment基础预测层、标准分割损失、原分类置信度。去掉EV3深层替换、持续细节交换/注入、非对称PAN、stride2细化、质量分支及重评分、边界/邻近/小目标Dice等辅助项。训练和验证默认都不切片。

只检验两个独立假设：

- D：直接把标准P2特征投影成原型残差，补充掩膜细节。1×1卷积→16通道深度卷积→1×1输出32个原型残差；不建立独立长期高分辨率主干。原型仍为stride4，不用升分辨率制造混淆。
- S：仅复用自有E12的 `EV12RecognitionCorrection`，在P3/P4做共享预测特征校正，不继承EV11/EV12复杂头和自定义损失。已有移除对照没有证明它必要，因此是可丢弃的候选，不预先写成贡献。

两条路径零残差初始化。标准分割头权重相同且eval模式下，初始输出与标准头一致；测试同时验证新路径可获得梯度。零初始化不保证训练后更好，新增分支仍需比较。

数学关系仅用于解释实现：原型 $P'=P+D(C_2)$，掩膜logit为 $m_j=a_j^T P'$。D关闭即精确回到标准原型；分类/框不直接读取D，但训练中仍通过共享主干发生梯度耦合，不能声称完全解耦。该机制无法恢复输入缩放已经抹除的像素，也不保证解决极小果实漏检。

## 5. 直接运行

上传整个当前代码目录，打开 `RUN_E12_SIMPLE.py`，设置DATA、PROJECT、DEVICE，点击VSCode运行，或执行 `python RUN_E12_SIMPLE.py`。

- 默认四组依次运行，300epoch预算，seed42、cache=True。所有组统一历史78配方：scratch、AMP=True、AdamW、lr0=.001、mask_ratio4、dropout.1、copy_paste0、patience100。早停可能导致实际轮数不同，汇总记录完成轮数。不得再让基线与消融使用不同配方。
- 训练输入原图；每轮val为原图EV6；最终best_mask权重再次按原图EV6评估。没有调用任何切片准备、切片推理或质量重评分函数。终端打印TRAIN/VAL/TEST模式。
- 汇总 `WHOLE_RESULTS.csv`，明确 `inference=whole_single_view`。指标为0–1比例，乘100读百分点。它与旧public640后验诊断不是同一评估过程，不直接比较其数值；本组内部统一EV6。
- 默认EVALUATE_TEST=False。用val选择方法，固定方案后改为True可对相同已训练权重整图评估test，跳过已完成训练。不要按test选择模型。
- DRY_RUN仅查看队列；SMOKE单轮写入独立_SMOKE目录，本地使用小样本data.yaml。中断不会启动下一组，有有效last.pt可续跑。改变训练配置需新PROJECT。

## 6. 停止添加复杂度的判据

先四组筛选，候选必须在同配方下改善主要Mask AP50–95且Recall不过度退化，再三seed复跑基线和候选，报告均值/标准差与逐图配对不确定性。若S无稳定收益，删除S；若仅D有用，最终模型就只保留D。若所有都无效，保留标准网络，转向标签复核/目标尺度诊断，不继续包装微小差异。

切片研究单独成表，后续仅对选定权重比较整图与预先固定的切片推理；不能用十次前向的结果声称单次网络提升。当前工作证明的是代码与实验可检验性，不证明论文创新已成立，更不保证精简后保留旧模型全部高分。
