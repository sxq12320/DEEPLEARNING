# SAGE V6：依据 V5 完整结果重分配主干、融合与掩膜预算

日期：2026-09-05。状态：实现与本地功能验证完成，尚无 V6 正式精度结果。不是已证明涨点的方法。

## 结果如何改变设计

完整九模型表见 `../reports/sage_v6_20260905/V5_RESULTS.md` 和同名 CSV。九次均为 300 轮、seed42、AMP=false；比较采用最佳 Mask AP50–95 同一行的其他指标，不能拼接各指标独立峰值。

| V5 模型 | Mask AP50–95 (%) | 同轮 Mask AP50 (%) | 判断 |
| --- | ---: | ---: | --- |
| SAGE30 官方对照 | 66.826 | 82.652 | 公平比较锚点 |
| SAGE42 语义细节 | 67.147 | 82.311 | 小幅严格 AP 收益 |
| SAGE51 细节 relay | 67.218 | 82.610 | 本批严格 AP 最高，但仅比42高0.071个百分点 |
| SAGE50 延后上采样 | 65.492 | 81.874 | 相对42下降1.655个百分点 |
| SAGE52 双路径 | 65.497 | 82.307 | 相对51下降1.721个百分点 |
| SAGE55 双路径+几何 | 66.102 | 82.361 | 能补回部分损失，仍不及对照 |

两组消融一致反对默认 late_proto：不能为了降低计算，把掩膜原型的高分辨率空间处理一并削掉。relay 的收益很弱；本地统一验证中，30与51的极小目标低阈值召回均为46.41%，不能声称它解决了极小果漏检。52的该召回为49.67%，却损害严格 Mask AP，说明召回与形状质量必须分别检查。分裂/合并代理显示51可能有价值，但仍需人工复核与多种子实验。

历史边界沿用 `../reports/research_reset_20260905/RESEARCH_RESET.md`，本次没有重新跑全部历史权重。不同数据集、AMP、初始化和协议的 G/T/Light 等结果不可合并排名。先前42的波动约0.355个百分点，已经大于本批relay收益。SAGE52每轮219秒，而同结构加损失的53–55仅约15–16秒，属于需排查的运行异常，不能直接作为结构固有成本。

PR右端零线有评估插值/补零因素：超出模型实际达到的召回范围，并不代表该区间有真实观测点。需要提高实际召回、检查低置信度误检和掩膜匹配，而不是把曲线改好看。混淆矩阵的框匹配也不能代替掩膜边界诊断。

## 结构与有序消融

| YAML 简称 | 相对上一项改变 | 参数 M | GFLOPs@640 |
| --- | --- | ---: | ---: |
| SAGE60 | 原样保留51结构作为复现对照 | 2.323 | 10.097 |
| SAGE61 | 单程自上而下融合，撤掉颈部往返；投影相加代替宽拼接 | 2.128 | 9.203 |
| SAGE62 | 四个主干 C3k2 阶段换成窄通道残差阶段 | 1.784 | 8.770 |
| SAGE63 | 主干内增加 stride4、16通道持续细节流，与P3/P4交换 | 1.794 | 8.910 |
| SAGE64 | 在63相同拓扑上对四处跨尺度输入做选择性调节 | 1.794 | 8.916 |
| SAGE65 | 与64相同推理结构，仅加可见边界和相邻实例监督，各0.1 | 1.794 | 8.916 |

所有模型保留 native Proto 高分辨率细化和细节relay，不再启用late_proto。62–65确实替换了主干四个C3k2阶段，但仍保留YOLO的卷积入口/降采样、SPPF、C2PSA及分割体系，不冒称完全脱离YOLO。61同时改变融合块与拓扑，因而它只检验整套颈部设计，不能单独证明“相加优于拼接”。63同样检验完整持续细节结构，不是单算子消融。

核心假设：主干保留窄高分辨率流，避免细节只在末端补入；深层语义通过有限幅度残差交换参与细节判断；把节省的颈部预算留给原型掩膜。果实与叶片的区别应在可见轮廓、上下文和实例分离中验证，不能仅凭颜色混淆的叙述确认有效。

禁止把有遮挡的可见掩膜强行圆化、凸包化。后续按 solidity/凸包缺口、邻实例间距、图内尺度跨度分桶，报告严格Mask AP、极小实例召回和分裂/合并错误。当前新方法尚未完成这些正式指标。

## 文献思想与迁移边界

- [Lite-HRNet, CVPR 2021](https://openaccess.thecvf.com/content/CVPR2021/html/Yu_Lite-HRNet_A_Lightweight_High-Resolution_Network_CVPR_2021_paper.html)：借鉴持续高分辨率表示，不照搬姿态网络；作者代码 https://github.com/HRNet/Lite-HRNet 。
- [DDRNet](https://arxiv.org/abs/2101.06085)：借鉴窄高分辨率与低分辨率语义流的交换；本地参考 `C:/Users/33836/Desktop/github/DDRNet/segmentation/DDRNet_23_slim.py`。
- [PIDNet, CVPR 2023](https://arxiv.org/abs/2206.02066)：借鉴细节与语义分工及受引导融合，作者代码 https://github.com/XuJiacong/PIDNet 。不是复制其语义分割头，也不是声称本实现为PID控制器。

实现为任务适配，不是上述论文的官方复现。选择门与小增益初始化属于受控残差注入：没有时域误差反馈、积分器或稳定性证明，不能把它写成真正闭环控制创新。经典残差瓶颈、双分辨率、门控本身也不构成已确立的新颖性；论文贡献须由任务机制与公平实验证明。

## 成本与初始化

下行交换先对窄通道特征池化，再扩通道；上行先低分辨率投影，再上采样。无新增Mamba、unfold或自定义CUDA依赖。CPU合成微测中60/62/64训练步约404/374/407ms；64参数比60少约22.8%，GFLOPs少约11.7%，但不能声称训练明显更快。65约491ms，额外监督明显耗时，默认不跑65。64和65推理图相同，单次CPU推理差异是计时波动，不应归因于训练损失。

数据详见 `../reports/sage_v6_20260905/cpu_benchmark640_poolfirst.json`。CPU、batch1、640、20次测量，不含数据加载、优化器、NMS和验证，不能替代服务器GPU吞吐。另一个不带poolfirst的文件是优化前记录，不是最终图测速。

全部从同一 `yolo11n-seg.pt` 加载可匹配权重，新主干参数独立初始化，不可能与原主干拥有相同预训练覆盖。63–65显式映射移动后的同类Conv/SPPF/C2PSA；family标记防止训练器重建时二次错位映射。每次批量训练保存实际加载记录，初始化差异仍是跨主干比较的限制。其他历史模型映射行为不变。

## 今晚的决策与后续

默认结构队列60–64、各300轮seed42，顺序由固定种子打乱但逐个串行。保留60是为了验证这次服务器协议，不是新增第二个官方基线。65单列可选。若成本紧张可选priority=60/62/64，但会失去部分消融解释力。

完成后先检查同数据、AMP和初始化记录，按严格Mask AP选型，再兼顾AP50、真实GPU延迟和困难子集。只对胜出模型与基线做42/43/44三种子确认。若62/63/64没有超过60，不叠更多注意力掩盖失败；应回查细节流是否保留有效信息，以及掩膜分辨率/实例匹配是否才是真正瓶颈。
