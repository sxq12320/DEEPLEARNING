# V9_05 网络框图说明

最终交付是 `V9_05_architecture_verified.svg`（可编辑矢量）及同名 PNG（4500×3100）。早期图像生成草稿的尺寸及连线没有全部符合实现，因此最终图按源码手工构造 SVG，并由 Sharp 渲染。`prompt.txt` 保存最初的图像生成提示，不能代替最终矢量图的源码。

选取 V9_05_tiny_overlap：它是当前 V9 训练验证 Mask AP50–95 的优先候选，AP50=84.907%、AP50–95=71.918%，参数2,229,608、THOP约10.219 GFLOPs/640视图。不同评估方式的赢家不完全相同，不能将其称为所有指标均最强。

图中四部分分别表示整体架构、语义引导细节、相位细掩膜解码、训练目标。主图将主干的C3/C4/C5输出合并画成一个输入接口；金字塔框中的加号表示拼接并随后通过C3k2，圆圈加号才表示残差相加。C5保留直接进入预测头的路径，未增加P4到P5的底向上重建。D是16通道stride4细节，检测仍然只有stride8/16/32三层。

深层仅EV3DeepStage内部使用FasterBlock/PConv混合器，浅层仍是C3k2。V9_05没有启用额外mask neck、compact prototype、DCN、P2检测头或V10新模块。图中的phase分支将stem重排到stride4，融合后再通过PixelShuffle生成stride2的掩膜残差。

质量评分分支用于校准类别分数，实际预测器以检测特征和mask系数为输入，并在训练中停止这两类输入的梯度；图中为清晰起见将其抽象为prediction towers之后的ranking框。其系数是0.5+0.5q，不直接改变mask像素。

建议论文图注：Overview of the V9_05 citrus instance segmentation model. A hybrid deep stage and asymmetric pyramid supply three detection scales. A semantic-guided narrow detail stream jointly refines candidate features and mask prototypes, while a phase-aware stem pathway provides stride-2 prototype residuals. Visible-boundary, neighboring-instance, tiny-instance and positive mask-quality objectives supervise training. Tiled inference is performed outside the network.
