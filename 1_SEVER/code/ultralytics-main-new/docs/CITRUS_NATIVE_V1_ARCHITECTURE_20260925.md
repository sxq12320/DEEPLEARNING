# 从 YOLO 转向独立实例分割：Citrus Native V1 架构方案

状态更新（2026-09-25）：本文原为设计稿，**I48–I53 已在 `I_V4_series/` 实现为独立模型的首批消融**；模型主体见 `ultralytics/nn/modules/citrus_native_segment.py`，损失见 `ultralytics/utils/citrus_native_loss.py`，入口见 `RUN_CITRUS_I_V4_NATIVE.py`。保留 I40–I47 作为原 YOLO 系对照。实际实现没有逐项覆盖下文所有设想（例如稀疏局部掩膜精修和质量校准尚未实现），不可把设计稿中未实现的内容当作已完成实验。借用的是 Ultralytics 训练/验证接口与标注读取，不借 YOLO 主干、PAN、TAL、框回归或 Segment 头。**尚无正式精度结论。**

## 1. 实验事实与问题边界

- 清洗数据 `orange_yolo_grouped_dedup_20260820`：965 张图、5,890 个可见果实实例，train/val/test=676/193/96；分组和跨 split 内容审计已通过。逐个统计标注文件时，最多一图有 46 个实例，所以对象槽位不能按“每图十几个果实”设置。
- I_V2 五个旧划分、单 seed、50 epoch 对照的 Mask AP50–95 为 0.69566–0.69701；P2 检测头的增益没有形成可确信结论。它们不能作为新划分下的正式基线。
- I20 的旧划分原图诊断中，实测最大 Mask Recall≈0.9047、R@P≥0.90≈0.7502；配对 fine 切片分别≈0.9714、≈0.7865，但尾部实测 Precision≈0.0202，且历史报告中的推理中位时间约从 138 ms 增至 417 ms。切片能提高覆盖，但复杂叶片会制造更多误报。不同模型/切片协议的数值不得混排。
- PR 曲线横轴是召回，绘图补 `(recall=1, precision=0)` 不等于“置信度 0.85 时精度归零”。后续要比较实测 PR 点和固定精度工作点，而不是修饰绘图。
- 第一篇仅用 RGB，输出**可见果实实例**。没有视频时不做动静分离；没有叶片类别标注时不声称监督了叶片分类；不凭果实圆形先验补出被遮挡部分。

## 2. 生物视觉类比：双向组织，不是强行串行

用户提出“先把场景分层、再理解对象的空间与形态，必要时重新解释”。合理的可计算版本是：场景级初步组织和局部对象线索**并行发生**，对象发现会反过来更新场景表征。关于人类视觉的综述也强调场景与对象处理的并行及双向作用，而非严格的固定顺序。[Peelen 等，Nature Reviews Psychology 2024](https://www.nature.com/articles/s44159-023-00254-0)

本设计因此有两个防止早期误判锁死的装置：稠密候选路径始终读原始细节特征；另设可学习的全局后备对象槽。初始前景概率只作**软引导**，不能把某个像素硬删掉。网络的“反复解释”限定为两次轻量对象—场景更新，不冒称人类神经过程、PID 控制或稳定性证明。

## 3. 完全独立的模型数据流

```text
RGB [3,640,640]
  │
  ├─ 新建轻量编码器：F2 [24,320,320]（细节）
  │                   F4 [32,160,160]（场景与掩膜像素）
  │                   F8 [64, 80, 80]（对象上下文）
  │                   F16[96, 40, 40]（全局语义）
  │
  ├─ 场景组织：可见前景 S、实例交界 B、局部候选 E
  │                         │
  │            64 个细节候选 + 32 个可学习后备槽 → 96 个对象表示 Q0
  │                         │
  │      Q0 读 F8 上下文，写入 F4 场景 → Q1 读修正后的场景
  │                         │
  └─ Q1 × F4 → 每对象初始掩膜与存在置信度
                     │
          仅对候选掩膜的局部区域采样 F2，修正可见细节
                     │
         最终各实例掩膜、掩膜质量、由掩膜派生的框与数量
```

图中的 `F2/F4/F8/F16` 是空间步长标记，不是 YOLO 的 P2/P3/P4/P5 检测金字塔。主干用自定义宽度较窄的残差深度卷积层；没有 C3k2/CSP、SPPF、PAN、YOLO 的 Detect/Segment 类、TAL 正样本分配、DFL 或 NMS。卷积是通用算子，不把所有常见算子的使用都包装成新发明。

### A. 初步场景组织：可见前景与实例边界

F4 上同时学习前景并集 `S(x)`、实例交界 `B(x)` 和候选证据 `E(x)`。S/B 的目标直接从训练集的可见实例掩膜生成；不会生成不存在的叶片标签。B 包含果实外轮廓及相邻实例的分界，但不强迫边缘为圆形，也不对遮挡缺口进行凸形补全。

F2 是窄通道、高分辨率信息通路，训练和推理都保留。S 的错误只影响软引导，不会乘零删除 F2/F4 中的像素。

### B. 把像素组织为独立果实

在 F4 上选择 `E(x)` 的前 64 个局部候选位置，读取其特征形成对象表示。再加入 32 个可学习的全局后备表示，共 96 个候选；这是基于清洗数据单图最多 46 个实例设定的容量，而不是预测的果实数。

局部候选不要求落在几何中心。训练时对每个实例的**可见区域**使用多实例学习式候选目标：至少一个区域内位置应有较高响应。候选仍可能堆在同一个果实上，训练时通过实例一对一匹配给重复候选分配“无对象”目标。后备表示可尝试找回初步候选遗漏的果实，但它自身也可能不收敛，必须单独做消融。

这里借鉴的是 [SparseInst 的实例激活与一对一匹配](https://openaccess.thecvf.com/content/CVPR2022/html/Cheng_Sparse_Instance_Activation_for_Real-Time_Instance_Segmentation_CVPR_2022_paper.html) 和 [FastInst 的候选驱动对象表示](https://openaccess.thecvf.com/content/CVPR2023/html/He_FastInst_A_Simple_Query-Based_Model_for_Real-Time_Instance_Segmentation_CVPR_2023_paper.html)。SparseInst 作者也指出其小目标表现仍受高分辨率特征限制；因此本任务不能只照搬其低分辨率实现。我们本地已有两者作者仓库，用它们核实对象表示和匹配的接口，但不复制完整网络。

### C. 两次轻量对象—场景更新

第 1 次：对象表示读取 F8（80×80）上下文，生成低分辨率的候选掩膜。对象表示根据软掩膜向场景 F4 写回有界残差；这个写回从零增益初始化。

第 2 次：对象表示再次读取更新后的场景，但注意力至少保留一部分全图权重：

`A = (1-α) · A_full + α · A_mask, 0 ≤ α ≤ 0.7`。

因此第 1 次掩膜错了，第 2 次仍有访问未被选中的区域的路径。α 的上限是工程防漏措施，不是理论最优值。对象到场景、场景到对象的双向信息流比只在 YOLO 颈部添加一个反馈门更符合此处“重新解释”的核心设想。FastInst 论文讨论了错误掩膜限制造成次优更新的问题；本设计选择软保底混合，并需实验证明其有效性。[FastInst 原文](https://openaccess.thecvf.com/content/CVPR2023/papers/He_FastInst_A_Simple_Query-Based_Model_for_Real-Time_Instance_Segmentation_CVPR_2023_paper.pdf)

为了训练速度，对象查询主要访问池化后的上下文 token 和自身附近的小窗口；不在 F2 的 320×320 上运行全局注意力，也不进行第二次完整主干前向。

### D. 先形成实例，再精修局部可见掩膜

每个对象表示与 F4 的像素嵌入点积，生成对应的初始掩膜。全部 96 个对象的 160×160 掩膜约为每图 246 万个 logits，FP32 单份约 9.8 MB；batch16 的这一张量约 157 MB，尚未计梯度和其他激活，服务器上必须实测显存。

对有希望的对象掩膜，再从 F2 的对应局部区域采样高分辨率纹理、轮廓，只修正该区域的可见 mask。这个思路与 [PointRend](https://arxiv.org/abs/1912.08193) 和 [QueryDet](https://openaccess.thecvf.com/content/CVPR2022/papers/Yang_QueryDet_Cascaded_Sparse_Query_for_Accelerating_High-Resolution_Small_Object_Detection_CVPR_2022_paper.pdf) 的“把高分辨率计算留给需要的位置”有关，但本方案是实例掩膜的区域修正，不是复制点渲染或全图切片。对于初始区域没有覆盖到的目标，局部修正无能为力，这属于必须量化的失败情况。

数量是超过阈值且去重后的对象个数；边界框由最后的掩膜派生；不设置独立框回归。实例之间的一对一匹配在训练时减少重复预测，推理仍应审查是否需要轻量去重，不能先声称完全无需后处理。

## 4. 损失与分数

1. `L_scene`：可见前景和实例界面的平衡 BCE/Dice；空图作为纯背景参与训练。
2. `L_evidence`：每个 GT 可见实例区域至少存在一个高证据点，加背景惩罚；禁止把面积小于某阈值的 GT 丢弃。
3. `L_set`：一对一 Hungarian 匹配后计算存在/无对象概率、实例 mask BCE+Dice 和交界处局部误差。匹配代价在 stride8 的掩膜图上计算，匹配后的损失在 stride4 原图上计算，避免为全部 `96×46` 对象对建立巨大的高分辨率代价张量。
4. `L_review`：对象掩膜的加权并集与场景 S 的一致性，小权重、延后启动；防止“前景图很好但实例一个也没有”的脱节，同时避免早期错误前景使所有对象一起塌缩。
5. `L_detail`：仅对已匹配对象的局部可见 GT 做细节修正；小实例按面积适度加权并设上限。训练不填充遮挡区域。
6. 掩膜质量分数作为独立可选消融：分类或对象存在分数不必等于掩膜质量，[Mask Scoring R-CNN](https://openaccess.thecvf.com/content_CVPR_2019/papers/Huang_Mask_Scoring_R-CNN_CVPR_2019_paper.pdf) 提供依据；但极小掩膜 IoU 对少数像素波动敏感，不能直接让质量头系统性压低小果实分数。

除存在概率外只有 `orange_immature` 一个实例类别。“颜色相似的叶片”通过场景负区域、局部形状/纹理及上下文建模；没有叶片 GT 就不能声称模型学到了被直接监督的叶片类别。

## 5. 真正需要验证的实验

| 组 | 结构差异 | 应回答的问题 |
|---|---|---|
| N00 | 从头训练的小型独立对象掩膜基架 | 框架本身能否收敛，作为本系列对照 |
| N01 | + stride2 窄细节通路 | 极小目标可见像素是否被保留 |
| N02 | + 场景前景/界面辅助任务 | 显式分层是否帮助发现与分离 |
| N03 | + 32 个全局后备对象表示 | 初始候选漏检能否恢复 |
| N04 | + 双向更新与软注意力保底 | 对象—场景再解释是否有效 |
| N05 | + 仅局部的细节修正 | 高 IoU Mask AP 和边界是否改善 |
| N06 | + 质量分数校准 | 高精度工作点召回是否改善，是否伤害小果实 |

这张表是**实验设计**，不是已经存在的脚本或模型。N04 是核心结构假设；N05/N06 是性能机制，不与 N04 一起上线首轮。若 N00 从头训练不稳定，先解决初始化/训练，而不是把结果归咎于“生物思路错误”。

同一清洗划分、640 输入、相同可解释的增强和评估预算。独立网络可能无法直接继承 YOLO 的 COCO 权重；主架构对照需同时提供 YOLO11n scratch 对照，预训练版本单列。固定 AMP、轮数、seed 和切片模式；最终候选与匹配 baseline 各训练 42/43/44 三个种子，报告均值±标准差。

先进行：图像形状/多实例标签/空图读入测试 → 每个输出的梯度测试 → 单 batch 过拟合 → 1–3 epoch 真实 smoke → 单 seed 50 epoch 的 N00–N04 筛选。每轮记录真实 GPU 显存、每 epoch 时间、推理延迟、Params 和真实算子计算量。*目标*是总参数不高于约 3M、同设备推理速度接近或快于当前轻量基线；这不是实现前能保证的指标。若局部高分辨率修正或 Hungarian 匹配显著拖慢训练，先根据 profile 缩减对象槽位、匹配分辨率或 refinement 预算。

主指标：Mask AP50–95、AP50、固定 Precision≥0.90 下 Recall、按输入像素尺寸分组的小果实 Recall、叶片背景 FP/图、实例 split/merge、遮挡凹口/边界误差、端到端延迟。原始 PR 观察点与 AP 插值曲线分别保存。验证只用 val，test 在定稿后一次性报告。全图与切片应各自成套评估，不能混用切片 AP 与全图延迟。

## 6. 决策与当前界限

**推荐将 Citrus Native V1 作为独立研究支线，与当前 I_V4 YOLO 系实验并行。** I_V4 是对照与经验来源，不继续在它的 YAML 上伪装成“全新网络”。新支线要有独立的 `nn.Module`、损失、训练、实例匹配与 COCO 风格评估入口；可以复用数据读取工具，但模型推理不依赖 Ultralytics。所有模型参数目标和增益都要以真实训练与速度测试为准。当前只有设计稿，没有新的可运行网络或任何涨点结果。

文献思想分别有明确出处：对象发现/一对一实例见 SparseInst、FastInst；伪装目标背景相似见 [SINet](https://openaccess.thecvf.com/content_CVPR_2020/html/Fan_Camouflaged_Object_Detection_CVPR_2020_paper.html)；细节分配见 PointRend/QueryDet；分数质量见 Mask Scoring R-CNN。最终论文若主张结构创新，必须证明“双路径找果实 + 软保底的双向对象—场景更新 + 稀疏细节修正”的组合有独立、稳定收益，不能把文献思想拼接本身当作已证实创新。
