# J11 数学推导文档：配图契约

- 任务：中文 LaTeX 数学推导 PDF；J11 为未证明精度最优的综合候选，不冒充已训练冠军。
- 后端：沿用已有 Python/Matplotlib 工作流；全部新图为原创矢量示意或有来源的数值图。
- 物理宽度：170 mm；正文图中文字不小于 7.6 pt，数学下标实际字形不小于 5 pt。
- 输出：PDF、可编辑 SVG、600 dpi PNG；LaTeX 内直接嵌入 PDF，禁止截图替代数学排版。
- 风格：蓝色=细节/主方法，紫色=上下文/融合，灰色=对照，橙色=边界/限制。
- 架构总览：精确复用先前程序生成的 J11 通俗版架构 PDF；配图不改变科学含义；详细张量图重新绘制。
- 不确定性：历史图来自两个单 checkpoint 的冻结权重配对诊断，没有跨 seed 方差，因此不捏造误差棒。
- 数据集：正式 grouped_dedup 的 train/val 静态 letterbox640 几何；旧 paired 诊断成员不同，仅支持机制假设。

| 图 | 一句话结论 | 面板与证据角色 | 必须公开的限制 |
|---|---|---|---|
| 1 结构总览 | 识别和轮廓细节走不同路径 | 已有简明架构，精确复用 | 未证明强于同协议 J00 |
| 2 小目标误差 | 相同像素偏移对小掩膜更严苛 | a 解析 IoU；b 静态数据尺寸分层 | 方形示例不是模型成绩，数据分层不是召回 |
| 3 相位重排 | 重排可逆，随后压缩未必可逆 | 2×2 像素到四通道的原创流程图 | 不是完整主干无损证明 |
| 4 竞争融合 | 竞争加权是凸混合，可能保留也可能稀释 | a 算子流程；b 权重变化的解析示例 | 权重为人为指定数学示例，非训练热图 |
| 5 差分上下文 | 共享常量被消去，变化信息不保证有利 | a 两个概率分布；b 常量和变化值读取示例 | 非真实叶片响应，无语义保证 |
| 6 解码分流 | 浅层支持原型，实例仍依赖检测候选 | 原型/系数合成的原创结构图 | P1/P2 不是额外检测头 |
| 7 历史证据 | 同权重多视图召回提升伴随延迟代价 | a tiny recall；b 相对端到端耗时 | 旧集、单 checkpoint、切片与合并共同变化；不是 J11 成绩 |
| 8 PR 解释 | 观测召回上限与绘图零端点应分开 | 手工数学示例，明确标注非实验 | 不修改评估器或实际 PR 曲线 |
| 9 梯度预算 | 有界辅助梯度仅在明确条件下保主目标一步下降 | 解析下降条件图 | 未来建议，J11 未实现；不是 AdamW 或全局收敛证明 |
