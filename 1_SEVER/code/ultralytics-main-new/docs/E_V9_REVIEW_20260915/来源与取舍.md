# 文献与本地代码取舍

本次是围绕V8证据的工程研究，不宣称完成全部视觉文献的系统综述。研究结论优先来自作者论文与官方实现。
阅读桌面仓库并不意味着直接拼接其模块；下面记录具体借鉴层次和舍弃理由。

|材料|此次核读的本地代码|可借鉴之处|没有搬来的部分|
|---|---|---|---|
|[SparseInst，CVPR2022](https://openaccess.thecvf.com/content/CVPR2022/html/Cheng_Sparse_Instance_Activation_for_Real-Time_Instance_Segmentation_CVPR_2022_paper.html)，[代码](https://github.com/hustvl/SparseInst)|github/SparseInst/sparseinst/{encoder,decoder,loss}.py|实例识别与共享mask特征分流；BCE补充Dice|不换成IAM稀疏实例查询/匈牙利匹配，避免把其已知小目标短板引入当前工程|
|[Gated-SCNN，ICCV2019](https://arxiv.org/abs/1907.05740)，[代码](https://github.com/nv-tlabs/GSCNN)|github/GSCNN/network/gscnn.py的forward与shape gates|语义指导细节分支，形状信息单独处理|原代码在forward做CPU NumPy/Canny并硬编码.cuda；不移植这种会同步CPU/GPU的实现|
|[RefineMask，CVPR2021](https://arxiv.org/abs/2104.08569)，[代码](https://github.com/zhanggang001/RefineMask)|github/RefineMask的refine_mask_head，已有V6/V8阅读记录|分阶段补充细粒度信息，不因检测语义压缩而丢mask边界|不增加逐实例RoI多阶段高成本解码；不是其网络复现|
|[PIDNet，CVPR2023](https://arxiv.org/abs/2206.02066)，[代码](https://github.com/XuJiacong/PIDNet)|github/PIDNet/models/model_utils.py，前次阅读记录|语义/细节职能分离及有界修正的设计线索|不把一次门控前馈称为PID控制、闭环控制或稳定性创新|
|[FastInst，CVPR2023](https://github.com/junjiehe96/FastInst)|github/FastInst/fastinst/modeling/pixel_decoder/fastinst_encoder.py|先压通道再融合、像素解码器与实例解码器分工|不迁移Transformer迭代query，当前没有证据值得承担训练与依赖成本|
|[VarifocalNet，CVPR2021](https://arxiv.org/abs/2008.13367)，[代码](https://github.com/hyz-xmaster/VarifocalNet)|github/VarifocalNet/mmdet/models/losses/varifocal_loss.py|质量感知排序必须考虑正负样本；负目标为0|V9沿用MSE质量头加保守hard-negative项，不冒称VFL原式，也不更改主分类损失|
|[Generalised Dice，DLMIA2017](https://arxiv.org/abs/1707.03237)|与SparseInst dice_loss交叉阅读|类/区域失衡时研究重叠损失的动机|本次是每tiny实例平方分母Dice，不是广义Dice原式或医学结论直接外推|
|[SGDR，ICLR2017](https://arxiv.org/abs/1608.03983)|本仓库现成cos_lr调度|单独测试余弦衰减|仍AdamW、无warm restart；09结果不算架构独立贡献|

桌面Plug-play集合重点核读：

- `3. Block（功能模块）/Multi-scale AwarenessFusionModule.py`：注明来源为MAGNet RGB-D显著目标检测，不是本任务实例分割。
  其多尺度分组思路可参考，但多核调制、深度输入与多次投影不直接移入本网络。
- `(TIP2024) CGAFusion.py`：PixelAttention内已sigmoid，CGAFusion又sigmoid，门控范围因此被压到约[0.5,0.731]。
  这只是本地摘录代码行为，不据此指控原论文错误。V9使用一次softmax，避免无意双重压缩。
- `(TPAMI 2024) FreqFusion.py`和github/FreqFusion已有核读：频率与空间对齐思想有用，但CARAFE/采样和多分支开销不直接引入。
  V8的上下文主干并未证明收益，因此不再借其名增加大核/频域堆叠。

V9实现是针对既有检测器的新掩膜路径及可控监督组合。它不复制这些仓库的类，也不声称拥有它们的全部理论或实验结论。
文献依据支持“值得检验”，不保证涨点；正式论文需要引用原作、给出自身差异和逐项消融。

精读范围：本次新增精读SparseInst encoder/decoder/loss、FastInst pixel decoder、GSCNN forward、VFNet loss及上述集合融合代码；
RefineMask/PIDNet/FreqFusion等复用前次已读代码与来源记录。没有声称逐行精读桌面上所有仓库。
