# 全标签整图网络收敛与 R_MINIMAL 候选

日期：2026-11-11。状态：新候选已实现，工程验证见本目录 VALIDATION.json；未完成正式训练，精度未知。论文新颖性未获确认。

## 结论

不继续把 G10、SAGE、V12 的整套结构叠加。以原版 YOLO11n-seg 为唯一消融零点，保留原版骨干、原版候选塔、原版原型解码器及原版损失，仅设置 A/B 两个可独立开关的结构因子。目的在于用小预算检验“颈部裁减 + 预测前浅层证据入口”能否改善精度—成本权衡。

这版是研究候选，不是已经超越 G10 的模型；也不是新的频域/相位理论。已有操作的任务化结构设计是否足以支撑论文，仍取决于稳定收益、失败边界和近邻比较。不能因为只剩两个改动就自动称有创新。

## 核查范围与数据口径

前序全目录审计扫描了370份训练CSV、356个去重运行，筛出193个完成训练且满足现有全标签/无切片条件的记录。完整原始审计在 `E:/mastercode/_work/results_full_audit_20261110/`；本轮继续核对了 G10/SAGE/V12 的实际模型和逐层开销，以及旧失败模型代码、科研论文、研究计划和正式数据。

旧成绩只作为设计证据，不能混成同协议的正式排行榜：旧 orange_yolo 划分存在分组泄漏风险，且初始化、AMP、掩膜网格、best选择不同。本轮正式数据固定 grouped_dedup，train/val/test 为676/193/96图、4120/1181/589实例。测试只冻结成员/哈希，未用来选择方案或评价新模型。

min8 的准确含义：将图像按长边640缩放后，删除标注外接框短边小于8像素的实例标签；不删整张图片，不是切片，也不是将这些区域设置为ignore。旧val的1049→990说明评价目标集合变了。旧表78.79/62.99的all→all是全标签基线；82.10/65.95是同模型改用min8评估，不能作为全标签基线。新R00沿用原版架构，但新的预训练/正式分组/全标签选best协议需要重新得到分数，不能直接抄78.79。

## 数据真正显示的困难

统计在整图长边640坐标中完成，仅分析train和val；原始图片/标注未改动。

| 诊断 | train / 4120实例 | val / 1181实例 |
|---|---:|---:|
| 外接框短边<8px | 234 | 104 |
| 外接框短边<16px | 836（20.3%） | 243（20.6%） |
| 灰度CNR<1 | 2949（71.6%） | 849（71.9%） |
| polygon solidity<0.8 | 281 | 117 |
| 2px内存在另一标注实例 | 1329 | 387 |

train中238/676图、val中69/193图的最大/最小实例短边比>4，单图尺度跨度并非少数情况。
CNR为果实内部与外部3px环带的灰度均值差绝对值/环带灰度标准差，环带排除全部已标注果实。它只是灰度低对比代理，不是RGB特征不可分的证明；漏标仍可能影响环带。solidity是凹形代理，不等于人工遮挡标签；邻近代理不是split/merge错误。没有在此声称解决遮挡、拓扑或输入降采样的信息损失。原图IMG_0221可见密集小果及叶枝遮挡，但单例不替代统计。

## 科研论文怎样影响选择

本地已提取六篇相关PDF，精读FreqFusion与Lite-HRNet Plus相关方法段，另核对WaveDH/DCNv4方法片段，筛读MRI跨尺度边缘引导与DCDR-UNet。没有声称读完科研文件夹所有论文。源路径和页数见 `PAPER_INDEX.json`。

- **FreqFusion**：特征融合同时涉及目标内部一致性和边界细节，不能由“小果困难”直接推出应该只回填高频。因此去掉早期方案的固定高通滤波，不引入其完整三部件系统。[原文](https://arxiv.org/abs/2408.12879)
- **Lite-HRNet Plus**：高分辨率路径和融合本身也有成本；启发保留窄接口而不是宽双流，其人脸关键点结果不等于柑橘分割证据。[原文](https://arxiv.org/abs/2308.12133)
- **WaveDH**：小波子带引导上下采样服务于去雾重建，不据此推断小波必然改善实例识别。结合本地复杂频域组合弱结果，本次不移植整套频域路径。[原文](https://arxiv.org/abs/2404.01604)
- **DCNv4**：论文的动态聚合与访存优化提醒FLOPs不等于速度。本次不引入额外可变形算子依赖，更不把它的性能结论挪到本网络。[原文](https://arxiv.org/abs/2401.06197)
- MRI多对比超分与HDR恢复论文的输入/目标不同，暂不引入边缘真值或新恢复损失。
- **SPD-Conv**早已采用space-to-depth+卷积；本项目SAGEV5/EV11也已有P2→P3回传，SAGEV4R有语义门控，EV2有高通/上下文门控。因此pixel_unshuffle、门控和relay均列为复用，不包装为原创算子。[原文](https://arxiv.org/abs/2208.03641)

## 两个改动，四组主消融

A：复用SAGE40的非对称颈部。删除最后P4→P5重建，layer20/21/22用Identity占位，P5预测直接读骨干layer10。保持原版其它层编号与可匹配预训练参数。

B：一个预测前浅层证据接口。原版C2→8通道Conv-BN-SiLU→pixel_unshuffle2；与P3的8通道投影共同生成一个空间sigmoid门；窄证据通过1×1线性投影和零初始化通道gain加到P3。随后仍由原生预测头同时产生框、类别、mask系数和prototype。门控不是目标概率，也不保证过滤叶片。

| 组 | A | B | 参数/M | GFLOPs@640 |
|---|---|---|---:|---:|
| R00_baseline | 关 | 关 | 2.842803 | 10.3558 |
| R01_asym | 开 | 关 | 2.316211 | 9.9326 |
| R02_relay | 关 | 开 | 2.846012 | 10.4173 |
| R03_asym_relay | 开 | 开 | 2.319420 | 9.9942 |

R03相对原版参数-18.4%、GFLOPs-3.49%；相对G10参数约-27.8%、GFLOPs约-31.3%。静态成本下降不等于实测更快。相对SAGE42成本几乎同级；精度需重新测，不能直接写67.5或更高。
B新增3209参数、约0.06154G卷积/常规层计数。FLOPs口径跟随Ultralytics/THOP，未完整计入sigmoid/tanh/重排与内存搬运开销。必须结合目标GPU端到端实测延迟。

仍是P3/P4/P5共8400候选、32个stride4原型。没有增加骨干替换、持续细节流、高通、相位竞争、P2候选塔、边界/邻居损失或老师。B的内部投影/门控共同构成一个待检验接口；四组只能证明整个B的作用，不能宣称每个内部操作都有独立贡献。

零增益使R02初始化与R00等价、R03与R01等价；A本身不是函数等价。新接口第1步gain获得梯度，随后project/detail/gate开始更新，再随后context得到梯度。这种启动延迟已通过测试。

## 一份运行入口

上传整个最新 `1_SEVER/code/ultralytics-main-new/`，运行 `RUN_CITRUS_MINIMAL_ABLATION.py`。不能只上传入口文件，因为它复用共享训练引擎及新增模块。

建议先做一次四组50epoch筛选：

```bash
python RUN_CITRUS_MINIMAL_ABLATION.py --epochs 50 --device 0
```

默认服务器数据 `/data/sxq/datasets/orange_yolo_grouped_dedup_20260820/data.yaml`；可用 `--data` 改。默认GPU为1，上例显式选0；默认脚本预算300，上例显式选50。当前为科研筛选，不预先保证涨点。

筛选成功后，四组主消融采用同一300epoch预算，必须换新目录：

```bash
python RUN_CITRUS_MINIMAL_ABLATION.py --epochs 300 --device 0 --project /data/sxq/results/CITRUS_MINIMAL_300_01
```

最终仅基线与胜出候选做三seed确认：

```bash
python RUN_CITRUS_MINIMAL_ABLATION.py --only R00_baseline R03_asym_relay --epochs 300 --seeds 42,43,44 --device 0 --project /data/sxq/results/CITRUS_MINIMAL_FINAL_01
```

如果四组已有可复用的seed42正式运行，可分别保留其冻结结果，再只运行43,44；不可混用50epoch结果。50epoch筛选可能受收敛速度影响，不把短筛选失败当作永远无效，也不以选中后重复调参掩盖选择偏差。

所有组统一：官方预训练、640整图YOLODataset、现有全标签、train/val mask_ratio2、AMP=False、同训练配方；全标签val MaskAP50-95选择best_mask。普通YOLO训练增强保留；没有切片数据集、切片推理或多视图。

输出 `FULL_LABEL_RESULTS.csv` 含AP50、AP50-95、Recall、总体R@P90、best_epoch、Params、GFLOPs、batch1延迟；`effective_runtime.json`记录实际图像/标签数量；`suite_protocol.json`冻结数据/权重/源码/配方；完成运行跳过，可恢复last.pt；旧目录不同协议会拒绝覆盖。CPU smoke的精度与速度都不用于论文。

## 预先规定怎样判断，而不是继续堆模块

筛选线暂定：R03相对R00同预算单seed的AP50-95至少+0.5个百分点、Params/GFLOPs均不增加，才值得优先进入最终复跑。这是为避免追逐旧0.071点级小差异而设的工程选择线，不是统计显著性或期刊标准。还必须分别看R03−R01、R02−R00，防止把A带来的提升算给B。若R01在精度/成本/延迟上支配R03，优先保留R01，不为保住B继续加模块。最终结果仍报告三seed均值±标准差及不确定性；若速度没有提升，就不能称“又快又高”。

四组之外暂不添加新结构。四组可检验整个A/B和交互，不能证明内部门控必要性或比仅修改decoder好。若B无稳定收益，保留轻量A或者回到已验证SAGE42，明确候选失败，不再加注意力补故事。

困难子集诊断在正式模型完成后进行：先全部GT与预测以maskIoU0.5一对一匹配，再按短边、CNR、solidity、间隙汇总；不能删除其它真果后将其预测当FP。总体P90阈值仅在val选择再锁定到test，不可达到时记NA。当前入口输出总体PR指标，**尚不自动输出困难子集召回、split/merge或BoundaryF1**，这些不属于本次已验证产物。

使用现有全标签不等于人工认证完整；正式论文test结论前仍需处理已有漏标审计。不得自动把凹形可见掩膜圆化或补成amodal。
