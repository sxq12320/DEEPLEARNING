# 七组统一运行入口

用户要求保留原来的原版/SAGE42/V12_06/对比度候选比较，同时加入两因子新网络。
入口为 `RUN_CITRUS_ALL_COMPARE.py`。原两个入口继续保留，统一入口只复用一个原版基线。

| 运行名 | 模型 | 用途 |
|---|---|---|
| R00_baseline | 原版 YOLO11n-seg | 两套比较共用的基线 |
| S42_sage42 | SAGE42 | 历史强模型在统一协议下重训 |
| V06_v12 | V12_06 | 历史强模型在统一协议下重训 |
| C01_sage42_contrast | SAGE42 + 局部对比度入口 | 原先提出的候选，默认已包含 |
| R01_asym | 原版 + A 非对称颈部 | 主消融 |
| R02_relay | 原版 + B 窄浅层回传 | 主消融 |
| R03_asym_relay | 原版 + A + B | 主消融 |

主消融仍为R00/R01/R02/R03四组。SAGE42、V12_06及C01不叠加到R03。
C01只相对SAGE42多一处入口改动，不能称其相对原版只有一处改动。

上传整个最新主代码文件夹，在其中运行：

```bash
python RUN_CITRUS_ALL_COMPARE.py
```

默认GPU 1，每组300 epoch、seed42、batch16、workers4，七组顺序执行，总预算2100 epoch。
不需要 `--include-candidate`，C01默认已加入。数据/输出/GPU/预算等可修改入口顶部或用CLI覆盖。
Windows默认使用工作区正式数据；服务器默认路径见入口顶部。

全部统一为：正式grouped_dedup数据、现有全标签、640整图、官方预训练、AMPFalse、
train/val mask_ratio2、全标签val MaskAP50-95选best_mask；无切片、无min8。
现有标签完整性未获人工认证。此协议与旧78.79分scratch运行不同，需要重训基线。

如果先筛50轮，单独输出到新目录：

```bash
python RUN_CITRUS_ALL_COMPARE.py --epochs 50 --project /data/sxq/results/CITRUS_ALL_SCREEN_01
```

仅跑原先四组也可以：

```bash
python RUN_CITRUS_ALL_COMPARE.py --only R00_baseline S42_sage42 V06_v12 C01_sage42_contrast --project /data/sxq/results/CITRUS_OLD4_COMPARE_01
```

同一个目录内不允许改模型队列、预算、seed或源码后混跑；换新project。已完成的匹配运行跳过，
中断从可恢复last.pt继续。默认新project不会覆盖两个旧入口的结果。

全部结果汇总到项目目录的 `FULL_LABEL_RESULTS.csv`，记录AP50/AP50-95/Recall/R@P90、
best_epoch、Params、GFLOPs及batch1端到端延迟。保留实际数据成员与标签数量、初始化迁移、
源码/权重/数据哈希和运行环境记录。CPU短训练仅验证流程，不证明精度或GPU速度。
