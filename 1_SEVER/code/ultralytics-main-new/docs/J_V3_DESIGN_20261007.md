# J V3 设计：特权高分辨率老师 × 不完整标注学习（2026-10-07）

> 状态：已实现并通过契约测试与 CPU smoke；**未做任何正式训练，不宣称精度提升**。
> 证据等级：下文所有诊断数字来自旧 `orange_yolo` 划分 + 单个历史模型 I07（或 I07+I02）的探索性分析，只用来决定研究方向，不能写成论文结论。

> **2026-10-09证据修订：** 用户已确认无法确定`fp_fine_human_labels_filled.csv`是否经过逐项人工复核。以下旧文中的“人工复核100个”“51个漏标”“72%精度”“约13–14%系统漏标”均撤回为未经确认的候选统计，不得作为真实漏标率、阈值校准或因果结论。原始CSV保留不改；J3仍可作为未验证的监督实验，而不是已证明的纠错方法。

## 1. 为什么不再改网络结构

| 观察（探索证据） | 数字 | 含义 |
|---|---|---|
| 漏检发生在哪一步 | global 漏检 203 个：分数不足 112（55%，中位分数 0.03）、无候选 86（42%）、掩膜不达标 5、NMS 抑制 0 | 问题在「发现与打分」，不在掩膜解码或后处理 |
| 高分「误检」的真实身份 | 100条待确认记录，缺少可信人工复核来源 | 只能形成复核候选，不能推断真假或遗漏率 |
| 全量标签审计（965 张，I07+I02 × global/fine） | 模型预测与标签不一致的候选清单 | 不能按未经确认的人工精度外推漏标数量 |
| 待复核候选的尺寸分布 | 高置信预测不一致候选81%小于32px（640尺度），已标实例约42% | 候选选择存在模型偏差；未确认真假，不能推出小果真实漏标率或遮挡结论 |
| 结构改动的效果 | SAGE/E/I/J 几十个臂多在 ±1 pp；I V1 十臂的 s50 都在 15.2–16.6 px | 结构改动没有碰到瓶颈 |
| 原图像素的价值 | 重新拟合I V1：global s50约15.2–16.6px，fine约7.8–9.2px | 指定协议的描述性响应变化，不是信息论识别下界 |

需要检验的监督假设是：若确有漏标，未标果实会被当作背景监督，也会影响评价中的误检统计。目前未确认此假设，低分候选亦可能来自尺度信息不足或背景混淆；PR横轴是召回而非置信度，尾部补零不能证明标签污染。J51只能与训练集人工复核及受控对照共同检验，不能据此宣布所有结构改进无效。

## 2. 方法

部署网络就是 **YOLO11n-seg**（与 J20/J00 图完全相同，参数量、FLOPs、延迟不变；保存的权重是原版 Ultralytics 可直接加载的普通 checkpoint）。J V3 只改训练监督。

### 2.1 特权老师（`citrus_j3_teacher.py`）

- 老师 = 同项目的 J50 锚点（seed 42），训练完即冻结，所有学生 seed 共用同一个老师，便于把方差归因到学生。
- 对**每张训练原图**：global 视图 + 3×3 fine（0.4）窗口，从原图像素裁剪（E V5 uniform 窗口，mask-aware 跨视图合并，边界权重 0.5）。这是学生在测试时拿不到的信息，即 Learning Using Privileged Information（Vapnik & Vashist 2009；Lopez-Paz et al., ICLR 2016）意义上的特权信息。
- 与已有标注重叠的实例（mask IoU ≥ 0.5，或覆盖任一方面积的 ≥ 50%）直接排除：它们是已标注果实、部分预测或合并预测，不是漏标。
- 分档：
  - **high**：score ≥ 0.6，并且被一个独立的第二视图印证（fine 老师用 global 单次推理或水平翻转推理；global 老师只能用翻转推理）；
  - **mid**：其余 score ≥ 0.25 的实例。
  - 阈值是暂定工程值，未获得可核验的人工精度校准；记录在每份输出里，不在test上调。正式伪标签实验前需独立train复核样本校准。
- 只读 train 图；train 与 val/test 有交集时拒绝运行。输出 `pseudo.json` 使用原图归一化多边形坐标。

### 2.2 标签可信度编码（`ultralytics/utils/citrus_j3_loss.py`）

每个实例带一个浮点 `cls` 编码，能和类别号一样穿过 Mosaic、透视变换、copy-paste 和重叠掩膜排序：

| 编码 | 含义 | 在损失中的作用 |
|---|---|---|
| `0` | 人工标注 | 与原版完全相同 |
| `1 + w`，w∈(0,1] | 伪正样本 | 参与任务对齐分配；分类目标、框/DFL、掩膜项都乘以 w |
| `3 + s`，s∈[0,1] | 忽略区 | 不当正样本；锚点中心落在其中且未被分为正样本的，从背景分类损失里删除 |

只有 `0` 编码时，损失与 `v8SegmentationLoss` 逐位相同（契约测试 `test_gt_only_loss_identical_to_stock`）。

### 2.3 数据注入（`citrus_j3_data.py`）

- 训练仍用 J V2 的多尺度视图（global/coarse/fine 概率 0.5/0.25/0.25，每轮长度 = 原图数）。
- 老师实例按每个视图的窗口裁剪，规则与 GT 相同；裁剪后变成不连通或带洞的，降级为忽略区（矩形）。
- 重叠掩膜里**忽略区最先绘制**，真果与伪果在重叠处保留自己的像素（`J3Format`）；J50 锚点仍用原版 `Format`。
- 只在内存中注入；准备好的视图缓存、val/test 和共享切片代码都不改。

## 3. 实验臂（`citrus_j3_suite.py`）

| 臂 | 伪标签策略 | 老师 | 回答的问题 |
|---|---|---|---|
| J50_noisy_anchor | 无 | — | 起点，同时是冻结老师的来源 |
| J51_ignore_only | 全部候选设为忽略区 | fine | 只是不再惩罚可能的真果，S1 型漏检和小果 AP 会不会改善？（检验因果链） |
| J52_privileged_hard | high = 全权重果实；mid = 忽略 | fine | 硬伪标签能带来多少 |
| **J53_privileged_soft** | high 按老师置信度加权；mid = 忽略 | fine | **主方法** |
| J54_global_teacher_soft | 同 J53 | global | 对照：去掉特权像素后还剩多少？用来区分「特权信息」与「普通自训练」 |
| J55_naive_selftrain | 所有 ≥0.25 候选当全权重果实，不设忽略带 | fine | 对照：三档设计是否必要 |
| J56_privileged_soft_960 | 同 J53 | fine | 可选成本臂：分辨率（不是结构）对 <8 px 的作用 |
| J59_clean_label_oracle | 无，但 train 标签人工清理 | — | 上限；论文核心数字 = J53 追回 J50→J59 差距的比例 |

套件：`main` = J50–J55；`ladder` = J50–J53；`controls` = J54+J55；`final` = J50+J53；`oracle` = J59；`resolution` = J56。

## 4. 判定规则（训练前登记）

前提：val/test 已人工清理（否则找回的果仍被记为误检，方法的收益显示不出来）。主指标：干净 test 上的 mask mAP50-95；同时报告分尺寸 AP、S1/S0 漏检计数、PR 高置信段、Params/FLOPs（各臂相同）。

1. **因果链**：J51 相对 J50 的 S1 型漏检减少，并且 <32 px 的 AP 上升 → 支持「漏标压低分数」。如果 J51 ≈ J50，这个假设不成立，回到诊断。
2. **特权信息**：J53 − J54 > 噪声地板（J50 三个 seed 的标准差）→ 收益来自原图像素，而不只是自训练。否则，方法只能表述为面向不完整标注的自训练，不能声称特权信息。
3. **三档设计**：J53 ≥ J55，并且 J53 的误检率低于 J55。
4. **软与硬**：J53 和 J52 的差距若在噪声地板以内，采用更简单的 J52 作为主方法。
5. **最终**：J50 和最终方法各跑 3 个 seed（42/43/44），老师固定为 J50 seed 42；报告均值 ± 标准差和 J59 差距追回比例。

## 5. 风险与边界

- 640图中的小果证据可能受缩放限制；当前数据不能推出“小于8px绝对学不会”。J56是分辨率–开销对照，不是识别定理。
- 老师可能把叶片当成果，但其真实错误率尚未人工核实；忽略带也可能删除必要的负样本监督，必须设对照。
- 老师必须只在本划分的 train 上训练过：`TEACHER="auto"` 自动使用同项目的 J50；显式指定老师时运行器会打印警告，`mining_record.json` 会记录老师的训练数据路径。
- 旧100条候选表的人工来源未确认；先在train独立人工复核老师候选，不将自动表当作人工真值。推理阈值若用val选择，需提前登记且不使用test。
- 新意边界：稀疏标注检测（Calibrated Teacher AAAI'23、SparseDet ICCV'23、Co-Student ECCV'24、S²Teacher AAAI'26）大多在 COCO/VOC 上随机删标、做框检测；多尺度老师（MixTeacher CVPR'23、SED CVPR'22）用的是同一张图的缩放；ScaleKD（CVPR'23）做小目标蒸馏但不处理漏标。J V3 可能的新意在于：漏标是自然发生且偏向小果和遮挡果的；老师拥有原图像素这一特权信息；任务是实例掩膜；部署零开销。**以上来自一次针对性检索，正式写作前需要系统查新。**

```text

顺序：J50 → 冻结的 J50 老师在 train 原图上挖掘（_teacher_<mode>_<sha>/pseudo.json）→ 学生臂。
每个运行目录：j3_protocol.json（静态配方 + 老师/伪标签 sha256）、j3_injection.json（实际注入计数）、

```
