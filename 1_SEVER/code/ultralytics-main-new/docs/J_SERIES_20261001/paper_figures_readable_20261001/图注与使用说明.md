# J11 通俗版网络架构图

本图对应 J11_synthesis 综合候选，尚没有正式训练结果证明它是 J 系列最优模型。这里简化的是表达方式，不是重新设计网络，也不把设计目标画成已经实现的性能。

## 一句话读图

果树图像 → 提取颜色、明暗、边缘和环境线索 → 汇合不同尺度的信息 → 定位果实 → 结合保留的细节描出每个果实的可见轮廓。

蓝色虚线表示浅层细节绕过后续降采样，直接参与掩膜解码；它不是独立的高分辨率主干。紫色虚线表示浅层预测的前景提示，仅软调制分类分支，不直接硬删候选，也不调制框回归及掩膜系数分支。

## 中文图注

图 X. J11 柑橘幼果实例分割候选网络的简化结构。RGB 图像在入口补充亮度与局部对比线索，经顺序主干提取浅层细节和深层上下文。来自不同尺度的特征经投影、尺寸对齐与逐位置竞争加权，分别生成 P3、P4、P5 输出。三个尺度各自预测边界框、类别置信度和掩膜系数；浅层前景提示仅用于分类输入的有界软调制。掩膜解码器结合 P1、P2 细节与 P3 语义生成共享原型，随后与实例系数组合，输出每个果实的可见区域掩膜。图中将重复尺度分支合并展示，完整层次与连接以 YAML 和实现代码为准。本图不是全遮挡轮廓补全或多主干结构，也不包含实测精度或示意预测结果。

## English caption

Figure X. Simplified overview of the J11 candidate for immature citrus instance segmentation. RGB images are augmented with luminance and local contrast cues before entering a sequential encoder. Early features retain spatial detail, while deeper features supply context. Projected and spatially aligned features undergo per-location competitive fusion to produce separate P3, P4 and P5 outputs. Independent per-scale towers predict boxes, class scores and mask coefficients. A shallow foreground cue provides bounded soft modulation of classification inputs only; it does not directly gate box regression or coefficient prediction. The mask decoder combines P1 and P2 detail with P3 semantics to construct shared prototypes, which are combined with instance coefficients to obtain visible instance masks. Blue dashed connections denote the detail bypass; purple dashed connections denote class-only guidance. Repeated scale-specific branches are collapsed for readability. The diagram represents a candidate architecture, not an experimentally established optimum or an amodal segmentation model.
