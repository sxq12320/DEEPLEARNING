## 集合仓库的具体问题

阅读了直接桌面的CGAFusion、GlobalFusionModule、Moga Block，以及原作者FreqFusion实现。
CGAFusion来自去雾任务，含空间/通道/像素多重注意力；集合实现PixelAttention内外重复sigmoid，若照搬会改变门控范围。
GlobalFusionModule源自RGB-D显著性任务，并存在全局N×N注意力，不能直接塞进640输入的P2路径并宣称轻量。
这两个文件都不作为V8默认算子。Moga按通道分组的分工值得学习，但仍需真实速度和实例分割消融。
仓库标题/文件名不等于“都是CVPR验证过且适合柑橘”。例如FreqFusion是TPAMI，LSKA并非CVPR；目标任务、协议和实现版本需要分别核对。

## 对51页指南的辩证阅读

已提取阅读指南的架构范式、案例与41–51页模块设计建议。它提示局部/全局、空间/频率、串并联分工，可作为构思清单；不是方法有效性的实验依据。
尤其不能采用“替换算子再取名字就成为创新”“有涨点加故事就保证一区”这种推论。原始论文必须准确引用，负结果也必须保留。
第10页把DCT/iDCT表述为小波变换，在概念上不准确：离散余弦变换与离散小波变换不是同一变换。
V8采用的是有历史对照的结构路径调整，不由该指南的排列组合公式决定设计。并未依照它给网络堆叠FFT、Mamba和多重注意力。

## 被排除的方向

- 全量替换轻量backbone/所有refiner：历史SAGE单向压缩有损失，初始化覆盖也大幅改变；本次仅C4阶段单独实验。
- 默认密集P2：V7单加P2配对AP和tiny命中均降低，且候选增加到34000；暂不加。
- 默认DCN/PMCE：各指标收益分裂且含额外成本；作为已有备选保留，不删除历史代码。
- 把绿色阈值当切片指导：此前没有充分收益证据；继续无指导的固定预算混合切片。
- 凸包、圆形强先验：会伤害真实深凹可见掩膜，可能错误合并邻果。
- 新优化器和一批损失同时更换：会破坏因果归因；此次固定AdamW和已有mask/box损失，新增组合明确编号。

没有形成“首次”“最优”“超越基线若干点”的证据。适合论文的贡献需要最终控制组、消融、多seed、外部比较和真实部署开销共同支持。
