# I V1 设计文档 — 同步双原型掩膜解码（Synchronized Dual Prototypes）

日期：2026-09-20 ｜ 状态：实现完成，待筛选实验 ｜ 前序审查：`docs/I_V1_REVIEW_20260920/reviewer{1,2,3}.md`

## 1. 从 V12 证据到本设计

V12 三份独立审阅的一致结论：**尚未达到投稿成熟度**——单 seed 筛选、train/val 成员与正式
`orange_yolo_grouped_dedup_20260820` 清单不一致（V12_03 有 94 组跨 split 交叉）、缺同协议官方基线。
但 V12 内部比较留下了两条可复用的受控证据：

- **V12_03（识别路由）**：背景误报最少（global 108 vs V12_02 的 144）→ 分类端语义校正有效。
- **V12_04（共享路由）**：fine 栅格 AP50-95 ≈ 78.31% 最高 → 把校正分摊到全部预测塔代价可控。
- **未解决的问题**：极小果召回没有同步改善；掩膜解码器仍是单一原型路径，"是什么"（果 vs 叶/枝）
  与"在哪里"（小果定位、凹边界）在同一条 P3+P2 细节通路上耦合。

I V1 把 V12 验证过的"任务分流"假设**推进到掩膜原型解码器**：
细节原型（V10/V11 已验证的 P3+P2 通路，保小果与边界）之外，增加一条 **P4 语义原型**
（上下文尺度回答"果实证据在哪里持续存在"），再用**逐位置门控**在两个原型之间仲裁。

## 2. 模块（`ultralytics/nn/modules/citrus_i_v1.py`）

| 模块 | 来源思想 | 本任务的适配（≠原作者完整模块） |
|---|---|---|
| `IV1StripContext` | SegNeXt MSCAN（NeurIPS22）多尺度条带卷积注意力 | 只保留 5×5 局部 + 1×7/7×1 + 1×11/11×1 分解核；P4 仅 40×40@640，不复制全套核组；无作者权重 |
| `IV1AnchorContext` | PKINet CAA（CVPR24）锚点条带注意力 | 只借平均池化→条带因子→sigmoid 的分解；无 Inception 分支、无 PKIBlock 其他组件 |
| `IV1SemanticProto` | RefineMask/SFM 的"语义证据参与掩膜"思想 | 不是 RoI 级融合，是解码器内的第二条原型基：P4→上下文→上采样→32 基 |
| `IV1ProtoSync` | 任务分流（TOOD 动机，V12 同源） | 逐位置 sigmoid 门（非空间 softmax——位置之间不竞争）；观察细节流+两原型+其差异 |

**零初始化纪律**（与 V11/V12 相同）：`mix` 标量初始为 0（lead 臂除外），
`combined = proto_d + tanh(mix)·gate·(proto_s − proto_d)`，初始逐参数等价 V12 父模型。
I06 的 feedback 同样 `tanh(gain)·dw(proto_d − proto_s)`，零起点、有界——**不是 PID 控制器**，
无循环状态，无稳定性证明，相关措辞保持保守。

## 4. 预期失败模式与停止判据

- **I08 失败（语义原型单独撑不起小果）** → 佐证细节原型不可替代，保留。
- **I02≈I00** → "多一条原型"无收益，04 的门控若是有效才是机制性证据而非参数效应。
- **I04≤I03** → 逐位置仲裁无意义，回到标量混合或放弃该方向。
- **I09≥I04** → 分类路由与解码器门控冗余，二选一以省延迟。
- **全线不涨** → 原型层假设证伪，回到 V12_03/04 作为论文候选，转入正式协议复跑。
