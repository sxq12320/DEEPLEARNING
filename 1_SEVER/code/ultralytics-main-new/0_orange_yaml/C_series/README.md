# C 系列：柑橘可见掩膜拓扑解耦

## 设计结论

C 系列不是继续堆叠注意力模块。它把当前任务拆成两个相互制约的掩膜需求：

1. P3 语义原型负责把条带状叶片/枝条遮挡后的多个可见片段维持为同一个果实实例；
2. 少量 P2 细节原型负责深凹可见边界和相邻果实之间的窄分隔带；
3. 每个实例原有的 mask coefficient 自行选择语义/细节原型比例，适应同图极端尺度跨度；
4. 一个四状态拓扑图（局部背景、果实内部、可见边界、相邻实例分隔带）同时约束 P2 细节，不再叠加多套彼此竞争的辅助损失。

检测头仍只使用 P3/P4/P5。P2 不增加密集检测层，只进入掩膜原型路径和一个零初始化的 P2→P3 残差，因此 C03/C04/C07 仍保持 nano 级计算量。

## 模型矩阵

参数量和 GFLOPs 使用 `nc=1`、640×640 输入；迁移率是从本地 `yolo11n-seg.pt` 可直接按键与形状复用的参数元素比例。

| 编号 | 角色/改动 | Params | GFLOPs | 直接迁移率 | 是否优先 |
|---|---|---:|---:|---:|---|
| C01 | 原 G10 在清洗数据上的精确复现控制 | 3.214M | 14.54 | 80.0% | 是，解释 G10 |
| C02 | 原 B06 精确锚点 | 2.778M | 9.82 | 94.9% | 是，复核 B06 |
| C03 | 语义/细节双原型 + 四状态拓扑监督 | **2.692M** | **9.71** | **97.9%** | **核心方法** |
| C04 | C03 + 仅一次早期 Haar 下采样 | 2.672M | 9.45 | 97.3% | 是，主干消融 |
| C05 | C03 + CARAFE | 2.833M | 9.98 | 93.1% | 次要，颈部消融 |

C01、C02、C09 是历史控制组，不是 C 系列创新。按照要求，批量脚本不包含原版 YOLO11 再训练；B00 的同协议结果 0.6140 作为既有参考。

## 训练顺序

1. 先运行全模型 3 epoch smoke，确认服务器环境、数据路径、前向、反向和保存流程。
2. 先筛 C03、C04、C07；若资源允许，再筛 C05、C06、C08。
3. 同时跑 C01、C09，回答“G10 是旧数据优势还是结构优势”。C02 可直接复用 B06 结果；只有协议发生变化才重跑。
4. 只有结构胜出后，才在固定 C03 上比较 topology loss 的 0、0.05、0.10、0.20。
5. 候选必须同时满足：Mask AP50-95 高于 B06 的 0.6186、末段不明显回落、召回不塌陷、参数/GFLOPs/实测延迟满足轻量化。单 seed 至少提高 0.005 才进入三随机种子复验。

这些模型目前只通过工程验证，尚未训练，不能预先声称精度提升。
