# CitrusB v2：由完整 S 系列结果重新筛选

2026-08-27 的版本不再沿用原 B02-B09 的长驻 P2 双流、反复 PagFM、P3/P4 注入和 mask-quality
乘法。那些结构没有 S 系列实验证据，而且旧版 CPU 延迟最高达到基线约 2 倍。新版只围绕 S 结果支持的
三个因素做可解释的因子组合，所有模型继续使用完整的 YOLO11 PAN。

| ID | 主干 A：RepContext | 颈部 N：P3 ScaleFusion | 头部 H | 训练监督 | 目的 |
|---|---:|---:|---|---|---|
| B00 | 0 | 0 | 原始 Segment | 无 | 清洗数据基线 |
| B01 | 0 | 0 | Lite | 无 | 精确复现 S04 |
| B02 | 1 | 0 | Lite | 无 | 验证 S01 的召回收益能否与 Lite 共存 |
| B03 | 0 | 1 | Lite | 无 | 单独识别 S09 中尺度融合的贡献 |
| B04 | 0 | 0 | Lite + 推理期拓扑原型细化 | boundary + query | 单独识别拓扑头贡献 |
| B05 | 1 | 1 | Lite | 无 | 主干/颈部交互 |
| B06 | 1 | 0 | Lite + 推理期拓扑原型细化 | boundary + query | 主干/头部交互 |
| B07 | 0 | 1 | Lite + 推理期拓扑原型细化 | boundary + query | 颈部/头部交互 |
| B08 | 1 | 1 | Lite + 推理期拓扑原型细化 | boundary + query | 三因素完整组合，偏严格 AP |
| B09 | 1 | 1 | Lite + 仅训练期 B/Q 辅助 | boundary + query | 轻量高精度对照；未实现召回平衡 |

设计依据：S04 是精度、参数量和速度的 Pareto 最优点；S01 的当前代码复评得到最高 mask recall
ceiling（0.887）；S09 具有最高训练峰值 mask AP50-95，但选定点 recall 较低；S02/S07 说明 LSKA
及其组合没有正收益；S05 说明删除 PAN 反馈是明确负收益；S08 说明“全部模块 + 全部损失”不会自动叠加。

B08 与 B09 是关键对照。两者主干、颈部和轻量预测层相同；B08 在推理时用 P2 改写 mask prototype，
B09 只在训练期使用 P2 边界/微小目标监督，部署图不包含该辅助支路。完整 300 epoch 实验表明 B09
Mask AP50-95=0.61361、P=0.92770、R=0.69263：它比 B00 少 5.1% 参数和 8.7% GFLOPs，但没有超过
B00 的严格 AP，也没有保持高召回。因此文件名中的 `recall_balanced` 仅是历史假设，不是实验结论。
