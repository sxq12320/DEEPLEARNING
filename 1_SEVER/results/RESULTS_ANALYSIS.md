## 3. 关键模式（数据说话）

1. **赢家画像**：P5 全局上下文（SPPF_LSKA / FarFormer / RFB）+ 上采样质量（CARAFE）+ 高效块（C3k2_Faster / C3k2_WT）。"看得更远、恢复细节、算得更省"有效；"治暗治糊"的频域/亮度模块（DFEM/LIAM/MWCA/LumiFormer）只到中游。
2. **输入域前端全部伤迁移**：TGP 0.614、HVI+DFEM 0.620、含 LCE 组合垫底。ep5 指标为证：正常 run ep5≈0.42–0.55，SXQNet-V1 ep5=0.009、F53=0.164——前端改变输入分布使 COCO 预训练作废。
3. **全家桶垫底 ≠ 架构死刑**：SXQNet-V1/F53 在 300ep 截断时仍 +0.010/10ep 直线上升（best 在 ep230/293）——是欠训练+迁移崩坏，不是模块冲突。
4. **recall 天花板 ≈0.74 无人能动**：全部 40 run 挤在 0.72–0.77。瓶颈在分辨率与正样本分配（P2 头崩了没数据、GA-TAL 没开），不在特征提取。
5. **mAP50 0.82 vs mAP50-95 0.66 的 16pt 鸿沟**：高 IoU 匹配崩塌 = 估计标注的天花板，需 SAM 精修解决。
6. **SPD 进组合即掉点**：F03 单体 0.6631，F25/F28 组合 0.647–0.649。

## 5. 训练侧改进（实现已审查，实测 0/10）

审查结论：接线正确；默认关闭=stock 数值一致（单测背书）；Lion 实现标准。
三个注意点：① FFL 的 FFT 未裁剪到实例 bbox（背景稀释小果高频信号，建议 crop）；② Lion beta1 用了 momentum=0.937（论文 0.9，写明即可）；③ NWDWise 尺度门限是特征格单位（设计如此，论文需写明）。

| 项 | 针对难点 | 启用 |
|---|---|---|
| GA-TAL | recall 天花板（<16px 正样本饥饿） | `--tal-metric NWD --tal-min-pos` |
| NWDWise（原创） | 估计标注噪声+微小框 | `--iou-type NWDWise` |
| FFL | mAP50→50-95 鸿沟 | `--freq-loss 0.1` |
| WIoU v3 | 标注噪声 | `--iou-type WIoU` |
| Slide | 难正样本 | `--slide` |
| Lion | 显存 | `--optimizer Lion --lr0 0.002` |
| M 配方 | 暗/小 | `--aug-preset dark_smallobj` |
| SAM 精修 / 切片推理 / 权重汤 | 数据侧/上界/免费涨点 | `refine_labels_sam.py` / `predict_citrus_sliced.py` / `soup_weights.py` |
