# Triage 标签

技能内部使用五个标准 triage 角色，此文件将角色映射为本仓库实际使用的标签字符串。

| 技能中的角色 | 本仓库标签 | 含义 |
|---|---|---|
| `needs-triage` | `待评估` | 维护者需要评估此 issue |
| `needs-info` | `需补充信息` | 等待提交者补充更多信息 |
| `ready-for-agent` | `AI可接手` | 规格清晰，AI agent 可独立处理 |
| `ready-for-human` | `需人工处理` | 需要人类实现 |
| `wontfix` | `不予处理` | 不予处理 |

当技能提及某个角色时（例如"打上 AFK-ready 标签"），请使用此表中对应的标签字符串。
