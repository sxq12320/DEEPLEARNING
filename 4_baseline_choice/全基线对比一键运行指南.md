# 柑橘幼果实例分割全基线对比一键运行指南

本文档用于第一篇论文的 baseline 对比。原则是：所有模型使用同一份数据划分、同一份 COCO mask 评估脚本，先跑 2 epoch smoke，确认环境和数据没问题后再跑正式 300 epoch。

## 1. 必跑基线清单

| 类别 | 模型 | 入口脚本 | 说明 |
| --- | --- | --- | --- |
| YOLO | YOLOv8n-seg | `run_yolo_baselines.py` | 旧一代 nano YOLO 对照 |
| YOLO | YOLO11n-seg | `run_yolo_baselines.py` | 当前主 baseline 和消融基线 |
| YOLO | YOLO26n-seg | `run_yolo_baselines.py` | 新 YOLO 系列实时对照 |
| Two-stage/FPN | Mask R-CNN R50-FPN | `run_maskrcnn.py` | 推荐用 Torchvision 版，最稳 |
| One-stage/FPN | SOLOv2-Light R18-FPN | `run_mmdet.py` | box-free 实例分割，对比 YOLO 是否依赖框 |
| One-stage/Neck | RTMDet-Ins-tiny | `run_mmdet.py` | 轻量高效实例分割，对比 YOLO neck/head |
| Transformer | RF-DETR Seg | `run_rfdetr.py` | Transformer 系列实时分割参考 |
| Semantic+Instance | U-Net + Watershed | `run_unet.py` | 语义分割转实例辅助基线 |

不建议第一轮同时加入 DeepLabV3+、SegFormer、Mask2Former。它们会拉长实验线，先把上表跑完，再决定是否作为扩展实验。

## 2. 数据格式

原始数据保持 YOLO polygon segmentation 格式：

```text
orange_yolo/
├── train/images, train/labels
├── val/images, val/labels
├── test/images, test/labels
└── data.yaml
```

每个标签文件一行一个实例：

```text
0 x1 y1 x2 y2 x3 y3 ... xn yn
```

一键脚本会自动调用 `scripts/prepare_dataset.py`，把数据转换成：

```text
datasets/citrus_prepared/
├── yolo/
├── coco/
├── rfdetr/
└── semantic/
```

YOLO 用 `yolo/`，Mask R-CNN、SOLOv2、RTMDet 用 `coco/`，RF-DETR 用 `rfdetr/`，U-Net 用 `semantic/`。

## 3. Windows 本地运行方式

所有脚本都只改顶部 `USER SETTINGS`，然后直接运行。

第一次统一使用：

```python
RUN_MODE = "smoke"
```

smoke 成功后再改为：

```python
RUN_MODE = "train"
```

如果要训练完立刻在 test 上评估：

```python
RUN_MODE = "all"
```

各模型入口：

```powershell
cd E:\mastercode\4_baseline_choice
python run_yolo_baselines.py
python run_maskrcnn.py
python run_mmdet.py
python run_rfdetr.py
python run_unet.py
```

## 4. 服务器环境建议

不要把 Windows 的 conda 环境复制到服务器。只复制：

```text
4_baseline_choice/
orange_yolo/
```

然后在服务器上分别建环境。

YOLO：

```bash
conda create -n citrus-yolo python=3.10 -y
conda activate citrus-yolo
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install ultralytics pycocotools tqdm pyyaml pillow
python run_yolo_baselines.py
```

Torchvision Mask R-CNN：

```bash
conda create -n citrus-maskrcnn python=3.10 -y
conda activate citrus-maskrcnn
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements-torchvision-maskrcnn.txt
python run_maskrcnn.py
```

MMDetection，用于 SOLOv2、RTMDet、MMDet Mask R-CNN：

```bash
conda create -n citrus-mmdet python=3.10 -y
conda activate citrus-mmdet
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements-mmdet.txt
mim install "mmcv>=2.0.0,<2.2.0"
mim install "mmdet==3.3.0"
mkdir -p third_party
git clone -b v3.3.0 https://github.com/open-mmlab/mmdetection.git third_party/mmdetection
python run_mmdet.py
```

RF-DETR：

```bash
conda create -n citrus-rfdetr python=3.10 -y
conda activate citrus-rfdetr
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install rfdetr pycocotools tqdm pillow pyyaml
python run_rfdetr.py
```

U-Net + Watershed：

```bash
conda create -n citrus-unet python=3.10 -y
conda activate citrus-unet
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements-unet.txt
python run_unet.py
```

服务器路径需要在每个 `run_*.py` 顶部改：

```python
SERVER_SOURCE_DATASET = Path("/data/citrus/orange_yolo")
SERVER_PREPARED_DATASET = Path("/data/citrus/citrus_prepared")
SERVER_OUTPUT_ROOT = Path("/data/citrus/runs/...")
SERVER_EVALUATION_ROOT = Path("/data/citrus/runs/evaluation")
```

## 6. 实验顺序

推荐顺序：

1. `run_yolo_baselines.py` smoke。
2. `run_maskrcnn.py` smoke。
3. `run_mmdet.py` smoke，确认 SOLOv2、RTMDet、FPN 配置能正常跑。
4. `run_rfdetr.py` smoke。
5. `run_unet.py` smoke。
6. 全部 smoke 成功后，再跑正式 300 epoch。

正式论文不要只报一次结果。最终方法和 YOLO11n-seg 主 baseline 至少跑 3 个 seed：`42, 3407, 2026`，报告 mean ± std。
