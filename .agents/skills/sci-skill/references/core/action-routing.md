# Action routing

Use local SKILL.md policy and existing authorization. Determine what can be executed with available inputs and tools, then do it.

- PROMPT: perform the task directly; produce a prompt only if requested or useful for a real handoff.
- MANUAL: a necessary step is unavailable to the agent; explain the barrier, concrete user steps and evidence needed.
- HYBRID: complete accessible work, then identify the bounded user action needed. Do not classify executable local experiments as manual merely because they require an actual run.

Assess data sufficiency before acquisition, check adequate download/API/export alternatives before crawling, preserve provenance and verify substantial collection with a pilot. Human review is needed for unresolved author decisions, not every cleaning transition.

Result figures require real inputs, Python/R execution and traceable output; write/run code within the task and verify before claiming success. Explain any remaining execution barrier.

For requested explanatory figures and local insertion, use existing authorization, render and inspect. Propose extra work when it changes scope. Publication, purchases and other consequential external actions require adequate authorization; never infer final author acceptance from rendering.

Stage advancement depends on evidence and critical deliverables, not a forced output card.
