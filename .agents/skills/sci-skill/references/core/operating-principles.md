# Operating principles

Follow local SKILL.md interaction policy. The user sets the objective and important tradeoffs; choose methods, execute authorized work and verify evidence.

For a full research workflow, use materials → task → deliverables → evidence review → next milestone. For a bounded request, complete it without mandatory upstream intake.

Keep citation, statistical, provenance and stage-completion claims verifiable. Preserve unfinished evidence as unresolved. Use primary/official sources when facts need verification.

Read relevant references only. Templates are optional; do not require branding, stage cards, copied prompts or repeat approval for authorized work.
